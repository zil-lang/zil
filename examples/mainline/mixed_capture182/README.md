# 有限混合捕获的实际消费者

四个普通 ZIL 模块组成同步计数遍历。callback 持有一个资源 Desc、同源 Copy 字段共享 Address 和另一个资源的 Desc；读取前者，更新后者。更新与读取各经过内部 callback。循环逐次调用使用原公开 Fn 合同的同步 helper，退出后最后使用已结束，允许更新原共享字段所属资源。

输入一个字符 `0`–`3`。输入 `3` 输出 `123BA` 并返回 0：数字来自实际更新，`B`、`A` 是两个资源的真实 Drop。输入 `0` 输出 `BA`；非法输入 `9` 返回 9，不构造资源。默认实现不增加运行时贷款表或隐藏分配。

`probes/` 保留 182 开工前七个调查输入。其中 `desc_write_current_head.zil` 应 SafeReject；两个显式 Address 参数输入仍 Unsupported。其余四个现在应成功，原输入字节未改。

本消费者证明有限语言组合，不代表 ZUI 产品、完整一般高阶或异步 Resume 已完成。

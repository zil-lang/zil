# Store 子项原地更新

这个四模块消费者验证受限独占窗口的真实用途：构造带资源和 ByteBuffer 的完整子项，用运行时索引逐项更新 Copy 布局元数据，经 `&mut Item` helper 再借用，然后用共享窗口读取结果，最后结束所有窗口并扩容。

输入为一个 ASCII 数字 `0`–`4`。例如输入 `3` 输出 `abcABC`：前三个小写字符来自修改后的元数据，后三个大写字符来自原始资源的析构，证明写入改变实际字段而没有转移或覆盖资源头。其它输入退出 9。构造或后续扩容失败沿 `Fault.Memory` 路径清理已取得的责任。

`store_at_mut` 只开放当前 Store 元素的 Copy 字段及已支持的 Copy 投影。窗口不返回、不直接捕获；元素资源、完整 Package 复制、孔洞及并发/外部长期保存不在该合同内。该消费者不是 ZUI 框架或完整语言验收。

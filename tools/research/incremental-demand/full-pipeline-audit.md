# Current private-edit pipeline implementation

This continues `ff81e07961077613907ce4d3b9cf650defccfd1d`; it does not supersede or hide the earlier measurements, failures, or withdrawn mismatched-CGU ratios. The work remains on an isolated research branch. New reuse is selected by the existing, default-off `producer_reuse` switch. Main is unchanged.

The implementation changes actual consumers. A successful function-cache counter alone is insufficient. The driver regression `actual_function_products_reach_analysis_and_independent_verification` exercises a **length-changing** private edit and checks actual CFG work 1 executed/4 reused, candidate work 1/4, independent flow proofs 1/4, fresh-oracle equivalence, unchanged whole-input proof authorization, an error, and recovery. Native machine equality, CGU/object products, final link, output recovery, and exact diagnostic rendering have separate executable tests. Full fixed-workload measurements are recorded separately once completed.

The original `zil_db::ReactiveGraph` is still the BodyKey graph. The later stages now have their own actual function/dependency/result consumers and retained work products; this is **not** a claim that a single central reactive graph schedules every phase. The inspection-only `FunctionProduct`/`AnalysisFunctionResult` APIs must not be presented as schedulers by themselves. Whole-project driver construction keys and conservative PrivateImplementation dependencies remain, as do some global traversals and supported-domain fallbacks. Consequently the implementation is not yet minimal and no blanket Rust parity claim follows.

The Rust comparison remains tied to the official commits and actual moved paths in [pipeline-audit.md](pipeline-audit.md#official-rustcargo-fixed-source-comparison): rustc `58cf8f9c35b355199727627d07ae34a4e2846d67`, Cargo `5f94df4789f005f9a352888e8355ffc645b7ed0e`. Rust also collects/partitions a crate and rebuilds affected CGUs as units; its persistence includes whole-cache work. Cargo's new-process freshness and ZIL's resident request timing are separate boundaries. The matched CGU16/O2/jobs1 protocol, native outputs, actual unit content/membership/reuse, all parent histories, errors and recovery remain mandatory.

Initial failures retained in `out/runs/full-pipeline-*`: compile migration diagnostics; Analyze test checkpoint captured the wrong successful epoch (full-field assertion retained after correction); explicit cache directories were mistakenly guarded as files, preventing real publication (fixed at the guard API and tested); strict lint diagnostics. They are not compiler-performance observations. Local paths are not durable evidence until the new raw archive has been pushed and independently recovered.

模块私有正文编辑的当前边界是：变化模块重新生产，未变模块复用产物和稳定版本；只有实际变化的分面继续进入消费者。当前版本证据绑定真实源码、项目/模块来源、名称与import/可见性/候选环境、目标、上下文和ID/源码映射条件。节点身份不混入源码内容；输入有效性没有被省略。普通调用读取签名；CT、trait/泛型、资源与闭包超出已证明的scalar复用域时保留完整路径。

预算没有因复用而放宽。仅把可重放的node/work需求与语义环境分开，其他Limits仍精确绑定；原owner→trait→map收费次序保持，额度不足从原入口执行，失败首诊断不被缓存receipt抢先改写。恢复旧内容缓存能力保留。独立Verify每个当前成功请求仍执行；来源证明和fresh对拍另外证明产物对应当前Source，Verify不替代这项证明。

SourceMap carrier只持map Arc，不反向持有CachedLower/Core，避免保留旧映射时额外保活历史Core。测试逐值比较真实完整Map和Debug/实际artifact，另以Weak检查替换缓存后旧Core owner释放；没有伪空map或删条目。raw Expand公开返回签名和公共IR/schema保持原状。

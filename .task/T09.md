## 输入与前置

T08 完成的高阶/清理/CFG能力；W1 的机器资源链；实际平台 API 和冻结目标支持表。

## 实现与交付

SABI/静态帧、显式动态递归、PendingExit、取消/异常、真实同步和全部外部完成根；源类型与核验、frame和runtime一致。

T08 Done 后才接手 analyze 等相交功能目录。所有系统用户在发布前登记，准入与关闭线性化；cancel、active=0或旧通知都不能单独授权释放。具体 OS 适配进入受审计可信模块，设备模拟不代表真实 DMA 验证。

## 接口交接

输入产物：`schema.v1`、`runner.v1`、`w1-integration.v1`、`higher-order.v1`。输出产物：`sabi-completion.v1`。字段与可信访问方式见 `spec/interfaces.json`。产物名存在不等于已完成，交接须附实际版本、源码提交与构建证据。

## 完成条件

- 源码挂起形状产生实际帧与SABI，结果责任只转交一次。
- 取消、失败、panic和drain均等待真实使用者归还及no-future保证；模型和实际平台证据分开。
- 所有新增操作在 types/analyze/verify/lower/runtime 中具有对应消费者；不靠runtime补未经检查的资格。

## 本单边界

不改所引用规则和profile。不把 IR 夹具、手工 lowering 或依赖策略检查冒充真实源码贯通；不恢复旧世代方案、不隐式加入 GC/RC/锁/堆盒。共享 schema、根 Cargo/工具链、其他写集变更须由集成者记录关联变更，不能以实现便利暗改接口。任务仍为 Planned；实际基线与派工条件满足后由验收方改为 Ready。

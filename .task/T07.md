## 输入与前置

T05 VerifiedModule 只读接口、B0 Layout/LIR schema 和实际目标 profile。

## 实现与交付

在 B0 锁定的 LLVM 主原生 profile 真实发射布局、管理 ABI、初始化与清理；可消费已核夹具，不以手写 C 充当 ZIL 贯通。

Desc 不变为宿主 Rust 引用，不默认 noalias/dereferenceable。机器属性必须由已核合同与目标规则支持。其他后端保留后续支持边界，不把 C 与 LLVM 失效指针规则混用。

## 接口交接

输入产物：`schema.v1`、`runner.v1`、`target-profile.v1`、`verified-ir.v1`。输出产物：`resource-lir.v1`、`native-resource.v1`。字段与可信访问方式见 `spec/interfaces.json`。产物名存在不等于已完成，交接须附实际版本、源码提交与构建证据。

## 完成条件

- 真实机器产物与已核输入的初始化/布局/清理事件一致。
- 责任记录自身释放顺序安全，部分构造与错误边没有二次析构。
- 未支持目标能力明确拒绝；属性/ABI变异在实际产物检查中被发现。

## 本单边界

不改所引用规则和profile。不把 IR 夹具、手工 lowering 或依赖策略检查冒充真实源码贯通；不恢复旧世代方案、不隐式加入 GC/RC/锁/堆盒。共享 schema、根 Cargo/工具链、其他写集变更须由集成者记录关联变更，不能以实现便利暗改接口。正式状态以本文件 JSON 为准；已有独立准备实现不解除依赖或全包验收条件。

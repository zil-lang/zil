## Implemented contract and integration

Root accepted the general literal design on 2026-11-06. Shared schema/Wire are 43;
Typed instruction tag139 is `StaticUtf8 { bytes: Vec<u8> }`. No additional public
Type was introduced. Program-static provenance uses explicit `HoldRoot::Static`
(tag3, no external ID), independently reconstructed from validated producers.
All current Typed/type/life fingerprint domains migrated from V42 to V43.
Verified exported result origins now retain `static_storage: bool` independently
of parameter positions, with verified call-contract hash domain7. Empty parameter
sets do not acquire static origin. Public spec registry/text remain root-owned.

Source literal production is general in normal expression formation, known-type
queries and both inference consumers. Two allocation-free spelling traversals
prepay actual byte visits; exact decoded byte capacity and two three-node result
Type trees are prepaid before materialization. Existing scalar escapes are
validated even on caller-built Core input. NUL is allowed, UTF8 is not normalized,
empty literal data has zero length, and no terminating byte is added.

The ordinary `std.string` source module remains responsible for explicit owning
allocation, capacity rejection and cleanup. Literal-only native controls observe
zero allocator calls. Owning controls exercise actual allocation failures and
live-owner balance. Mutable access, local-return escape and pure CT authority
remain rejected. Static-only results inside closure bodies and general stored
borrowed-storage combinations are outside this slice and remain rejected; this
delivery does not imply those general composition goals are complete.

Tests use the existing `cross_function_borrows` target and fixtures under
`tests/language-readiness/G9.3.1`; there is no new Cargo target or gate. Actual
Clang/API O0/O2 Source and module controls, Source-byte and Types work boundaries,
and raw Wire controls are recorded in the final compact receipt. The first CT
fixture expected Unsupported but observed existing SafeReject at Ct; it was
corrected to explicit `&[u8]` and the precise `E-CT-FORBIDDEN` contract, without
changing production admission. The first broad IR test build also exposed the
retained fingerprint oracle's missing new-variant arm; it now explicitly rejects
this new runtime-only operation and binds the current module domain V43.

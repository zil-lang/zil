# G5.2.1.1 · Shared dyn Source/Expand/Types producer

Status: implementation in progress; validation NotRun. Base `f59929378642b684e81729814241b2ae117f5f68`.

This slice reuses the existing Source declaration/provider Catalog and the public
`DynInterface`, `DynVtable`, `MakeDynBorrow` and `CallDynSlot` IR. No schema or
ABI field has changed. Expand canonicalizes `dyn` generic type keys and derives
a complete, conservative shared receiver contract only when every actual
provider body is a single return of a scalar literal or a Copy scalar field of
the actual receiver. Unknown bodies retain `None`; Types rejects them.

Types resolves complete local/project table inventory, maps every actual Core
entry `(module, NodeId)` to the corresponding concrete `FunctionId`, checks the
closed provider body/signature and emits a borrowed dynamic carrier for an
ordinary concrete shared argument. Ordinary method syntax on that carrier emits
the checked slot call. Raw Core dynamic variants use the same admission path.
Public `&dyn` helper identity resolves the actual interface and original stable
declaration identity, then encodes every admitted fixed slot's signature, life
relation and complete closed contract. Relocation IDs only locate rows.
`tests/language-readiness/G5.2.1/dyn-runtime-select.zil` selects two Copy
providers in an ordinary function based on a runtime boolean parameter. The
original `dyn-two-provider.zil` baseline bytes are retained unchanged.

Current validation: targeted rustfmt and `git diff --check` only. Cargo build,
Source CLI, raw/Wire, native O0/O2, budgets, cache and common acceptance are
NotRun; root owns the sole Cargo rebuild window and integration verification.
The typed handoff is `TypedModule.dyn_declarations/interfaces/vtables`, where
each `DynEntry.function` is the real provider `FunctionId`. `MakeDynBorrow`
consumes the real shared concrete address and returns shared `Address<Dyn>`;
`CallDynSlot` consumes that carrier and excludes receiver from `arguments`.
The slot has `requires=[Read(Parameter(0))]`, `guarantees=[]`, `hold=[]`,
`call.reads=[Parameter(0)]`, no writes/effects/cleanup, `result=Value`,
`resume=Local`, and false thread requirements. This is an interface upper
bound; a constant provider reads less.

Analyze, Verify, Lower and native backends remain independently implemented by
the assigned owners. No acceptance claim is made by this slice.

Rust goal check: the current Source/Types evidence improves finite borrowed dyn
expressibility and checks the actual provider instead of a generated spelling.
Independent safety is pending both kernels and raw/Wire controls; runtime and
memory cost, compilation cost, maintenance cost and a repeatable advantage over
same-semantics Rust are unmeasured. Product gates remain unchanged.

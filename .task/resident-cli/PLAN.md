# Explicit resident CLI

Baseline fc6620a3b975258643eb8f9c3ee77d868ff67a69, accepted PR75/76. This is the production-facing next step from the existing resident_session research prototype, not a new backend or cached verification permission. The regular CLI parser remains authoritative; only explicit check/build --resident --json enters the request loop. Each request refreshes source, manifest/lock and syntax lock, obtains a new relative cancellation deadline and passes current independent Verify. Any configuration error must be current, not a prior successful result.

One fixed request configuration per process. Protocol commands compile/clear/stats/quit are bounded to32bytes, includingLF; CRLF supported. No network, file watcher, JIT, program execution or hidden background process. Capacity8..256 controls raw entries, not bytes. Deterministic whole-session eviction every64requests by default, adjustable1..4096, drops additional function/analysis histories too. RSS is observed separately; OS/allocation peaks are not falsely advertised as byte-bounded.

Frozen performance protocol is the previously tested resident eight-case corpus and all mode/history frequencies, five formal cache histories plus warmup. Same release CLI binary supplies both fresh-process and resident arms; the adapter only translates argv and execs that same binary. Full cold startup/IPC/output/eviction included, no renormalization on missingcells. CurrentVerify count and exact generated .text equality required; native outputs and runtime checked. Compare time-for-memory honestly, not to an unmeasured Rustdaemon. Extra repeated edits cross the reset boundary, then explicitclear and malformederror recovery; completecacheinventory retained.

Tests: realCLI edit/recovery/currentdiagnostic, currentVerify perrequest, manifest/pathdependencylock and entrychanges, per-requestdeadline includingzero cancellation, automaticreset/explicitclear, boundedprotocol andinvalidoptions. FullCLI tests both API/reference, driverlibraryregressions, strictlint/fmt. OriginaldefaultCLI checks are not removed.

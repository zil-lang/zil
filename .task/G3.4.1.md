## 保留的工程决策

1. Source 布局提示仅用于推断；实际名义目录、完整 life/class 关系和来源证明仍保留。
   grouped Reference 的私有提示不带入 callee 的 life 名，真实目录不被改写。
2. 内建 Option 的共享 Address Type 实参只按完整内建身份与实际 Some 槽关系开放；
   普通用户名义、可变载荷和未闭合参数不能借形状相似获取权限。
3. None/Some 状态来自真实构造与调用参数关系。只有原完整 CFG 的固定点收敛后
   才冻结 None 事实并重放一次；不能用临时 None 或裁边后的摘要证明再次裁边。
4. BorrowMut 外层载体复用已有 shared-slot 分类，内部共享槽不因此变成可变。
   scalar AddressField 保留实际基址模式；两核对真实 producer 模式/载荷仍精确检查。
5. 机器首片仅空变体/单个共享 thin Address 变体，pointee 为既有 Copy 数据。
   复用 i32 tag、对齐载荷和现有 ABI，实际指针存储工作预付。fat Slice、可变载荷及
   更广形状仍不属于这一机器片；机器形状判断不能代替 immutable Verify 与完整 LIR 绑定。
6. 负控先要求原始正例成功；独核错来源反例从合法 Source Core 只替换真实索引目标，
   重跑 Types 并核类型/结构不变。记录实际 SafeReject 层次，不能用无关前端失败替代安全核验证。

# G5.2.1.3 · Independent Verify shared dyn

Base `f59929378642b684e81729814241b2ae117f5f68`; frozen scope
`changes/G5.2.1-shared-dyn-dispatch.md`. This is a construction slice, not
parent-task acceptance.

Verify now independently checks the finite shared interface and every used or
unused table: declaration/relocation uniqueness, closed slot/member/ABI/life
shape, exact nominal Self, actual FunctionId and receiver signature, and a
restricted real entry CFG. The accepted body can read a scalar field through
its actual shared Self or return a scalar constant; only the proven read-only
contract upper bound is admitted. Every contract component must be present,
including empty cleanup/effect/guarantee/Hold and local resume/thread bounds.
No producer, Types or Analyze proof function is imported.

MakeDynBorrow and CallDynSlot check concrete/interface/slot identities and
typed operands. The existing independent Verify root and loan flow propagates
the concrete source root and parent into dyn borrows, checks active receiver
access at calls, and treats whole local move/replacement against live dyn loans
as a conflict. Ordinary no-dyn budget charges and default limits are unchanged;
dyn metadata and instruction work is additionally charged before checking.

Private raw tests cover a checked entry and call, constant provider, wrong
same-layout nominal Self, unknown effects, unused malformed table, re-fingerprinted
Wire and false Hold. Source/native/Clang/API O0/O2, freshness and exact budget
evidence belong to the parent integration and remain **NotRun** here. Cargo
check/test/clippy/build are **NotRun** pending the root's single toolchain window;
only targeted rustfmt and `git diff --check` were run.

The public DynEntry has FunctionId but TypedFunction has no member-origin field.
Verify treats a fully checked raw table as the actual entry binding. A different
function with the same Self, ABI and independently proven body contract is
another safe raw program; Source Origins/committed witness must preserve the
original impl/default member selection. No untrusted name prefix grants
authority. External C callers can forge any borrowed pointer; native root entry
must continue to exclude dyn parameters. No new public schema is proposed by
this slice.

Rust-goal status: the static IR proof addresses type/lifetime safety within this
finite profile. Runtime/RSS, compilation cost, maintenance cost and a measured
advantage over Rust remain unmeasured; no product claim is made.

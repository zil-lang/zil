## Actual implementation
Intern equal return-cleanup suffixes in a function by (exact drop/StorageDead local, successor). Temporary bounded memory holds one DAG node for equal suffixes instead of repeatedly emitting them. The current DropClosure/ByteBuffer drop emitter and live flags are retained. ScopeExit and scalar StorageDead already lower to no machine instruction and may be omitted only after the current independent verification. Different action order never shares a suffix by mere set equality. Scalar result is privately stored before cleanup and read at the shared return; these slots never escape. Tasks/owner markers and nonscalar returns decline. Unknown actions terminate the shareable suffix; work or node-cap exhaustion discards the whole optional plan. No new noinline/cold/noalias facts. This is current-request hash-consing, NOT a persistent daemon or a Cranelift backend.

## Blaze v2 reference and selected direction
Pinned reference indexable-inc/blaze@a2b689f24c3bca40f4d02a949cd9e5b0adac9e12. README explicitly assigns published speed figures to v1; v2 plan and actual query code must be distinguished. Adopt exact dependency facts/early cutoff, bounded resident state, content-interned results, immutable request snapshots and separate compilation tiers. First remove repeated current work (this patch), then persistent sessions and dependency-indexed machine fragments. A daemon that repeatedly rebuilds one large closure unit is not sufficient.

Proposed development tier: verified ZIL -> backend-neutral ABI/lowered representation -> Cranelift per-function objects, initially explicit opt-in and fail visibly on unsupported lowering. Keep LLVM release/O2 and its generated-performance gate. Do not lower LLVM text into Cranelift or mix debug-speed results into release comparisons. Hot swapping/JIT, lazy checking, shared remote trust and speculative work are NOT implemented here; a checksum alone is not verification authority. Benchmark cold/warm/restarted/evicted daemon modes with exact sources, real edits, peak resident memory and current independent verification before granting any cache result authority.

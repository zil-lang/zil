This branch owns the private Analyze dyn checker and its dispatch, preflight
charges, actual Hold root propagation, and local raw IR counterexamples. It does
not own public IR/schema, Source Origins, Verify, Lower, ABI, common acceptance,
or the concurrent Store analysis slice.

The finite checker requires a checked x64 LLVM target, a closed ordinary trait
method slot and complete
explicit nine-part contract. It independently checks every table, including
unused tables; the exact concrete record Self and entry FunctionId signature;
and the reachable entry body, limited to a shared scalar field read or scalar
literal. A wrapper may follow one actual local `FunctionId` direct call passing
the unchanged shared receiver into another exact-signature finite body; cycles,
foreign, Suspend, unknown calls and unproved effects close. The slot contract is
checked against that body profile. `None` remains unknown. The coercion checks
the actual shared source value, table/interface/result match and a real loan
definition; the existing Hold graph carries the same root into the borrowed dyn
value. Dyn-bearing functions activate the existing actual address window check
against move/replacement/storage death, and a final pass requires the constructed
fat address to retain the source root and every called callee to have a root.
Scalar result grants no borrowed or managed result rights. Dyn checks and new
work charges are skipped
for legacy modules without dyn inventory.

Public Typed IR has no source member-origin relation for a FunctionId. The raw
vtable entry is therefore treated as a binding declaration and independently
verified by its actual Self, signature, CFG and effects; Source Origins retains
responsibility for original impl/default/member binding. This is a deliberate
handoff boundary, not a claim that names or same-layout structures prove origin.

## 真实缺陷与修复

独立审核 `972bf63d767cc9c3df3d76f5941f98cfcfef8c8c` 保留了一个应通过的实际源码：局部可变 Store 最初是新建；一个分支换入给入旧 Store 后返回 Copy 错误；另一分支返回仍然新建的 Store。未实例化模板通过，实际实例却在 Analyze 被判为转发旧责任。原始失败源码、命令和诊断完整保留在 `independent-first-failure`。

实际 Typed IR 表明，这不是错误返回分支进入 CFG 合流。Types 把可变 Managed 槽正规化为单字段 Package；原字段规则将 MakePackage、整个 Package Store、字段替换和字段取出的创建来源粗记为 Incoming。单纯新建可变槽再返回也会丢失来源。

Analyze 现在用预分配的命名字段出生集合保存完整 Package SSA 载荷的直接 Managed 字段来源，并在整个移动、局部转存、实际字段替换和取出时与已有局部字段责任槽交接。Verify 用自己的有界字节矩阵从实际指令独立重建，没有读取生产判定。正常参数、捕获和未知 Package 工厂返回的字段仍是 Incoming；新旧路径的 may 合流保留混合来源，不能获得 create 权限。所有新增形状扫描、分配、查找、复制、合流和字段传递都计入原有预算，默认额度不变。

# CP29 / CP30 完整会话窗口独立复算

审核：cp25_evidence。复算结果为 **Pass（证据完整性和计算一致）**；两项候选都没有建立默认容量下的净性能收益，性能采用结论为 **NoGo**。本审核没有增加编译或 native 性能样本。

## 数据范围与固定算法

CP29 绑定 `a0f38d2bca8f01fc19ff1f2fa0a42c3983c223b8`；CP30 绑定 `1b86175c8728834c20d1bb18ce13a329764e315f`。各自与同源 ee72fd6 基线配对比较，两次窗口的基线采样不同，不能据此直接比较 CP29 与 CP30 的绝对速度。

CP29 使用 `measurements/cp29-session` 的完整 200 个序列；CP30 使用 `/tmp/zil-compile7-cp30-session-recovery` 的完整 200 个序列。原 `measurements/cp30-session` 只有 114/200 个序列且无完成结果，根报告其清理阶段 ENOTEMPTY；审核独立确认不完整及无完成结果，原始前缀全部排除，不拼接、不评分。

每窗 200 个计量序列 × 7 次请求 = 1,400 次编译调用；另有 20 个未计分控制序列，共 140 次持久会话请求与 140 次 fresh 对照。逐项重读了原始 stdout/stderr、命令、返回码、数值类型、7 个精确快照、Success、Verify=1、active=0、控制观察量、manifest 和冻结身份；stderr 非空数为 0。各窗生产汇总的 110 格均独立重算相符，总计 220 格。构建产物、harness、rlib、Cargo feature/profile、工具与 fixture 身份也复核相符。

五个 case 权重固定为 tree4x2 / tree32x8 / tree256x8 / tree1024x8 / retained = **5% / 15% / 30% / 30% / 20%**；四种核心请求 cold / unchanged / private / public = **10% / 35% / 40% / 15%**。每一 paired block 中每格每 arm 两次先取平均，然后每格绝对成本取五个 block 中位数，按固定权重相加，最后才用 B/A 相除。没有平均各 case 的比值，也没有混合 default 与 8192。B 为候选，B/A 大于 1 表示更慢或更占内存。

95% 区间为探索性 whole-block 配对 bootstrap：完整枚举 5^5=3,125 个有序重采样（126 个多重集合及其权重），A/B、所有 case 和请求共用同一组 block，重算相同的加权绝对成本统计量，取线性 2.5% / 97.5% 分位。只有五个区块且运行在共享主机上，区间仅描述本窗的不确定性，不能当成产品总体保证。

## memo 观察与后续候选的边界

CP29 在 default 的 cold/private 中，tree256x8 私有编辑确实复用 2,305 个函数、重检 5 个，tree32x8 为 289/5，tree4x2 为 13/5。也就是说，局部 Builder 复用机制确实命中；真实完整编译组合仍回退，不能用命中次数替代速度结论。

同一窗口的 tree1024x8 与 retained 在 cold/private 都执行了 Types 查询，但当前 memo eligible=false、保留 0、计数 0。它证明未产生 memo，但这些统计不能区分 source_weight 的提前退出与 typed_weight 的后续退出，不据此编造 64 MiB 的精确退出点。8192 还存在整个 Types 查询命中，此时当前 eligible=false/checked=0 可以同时保留旧 memo；不能只读 eligible 推断资格失败。CP32 是基于上述问题提出的新候选，必须另做正确性审计和完整成本窗口，不能继承本窗收益。

## 证据边界与复核入口

本窗只测实际 compile_path 至 Verify；不包括 LLVM 发射、链接和 native 程序运行。fresh 比较的是报告/接口观察量，不冒称本窗逐条比较完整 TypedIR。CP29 作者另有 6 次真实 native 控制，审核已静读源码、原始 IR、ELF、退出码与 stdout，但审核者没有重跑 native；其实际后端为 Clang O0。该证据与会话性能样本分列。

三套会话 harness 的 Rust 源 SHA256 相同；只有 CP29 在被计时 compile_path 返回后多输出 memo 统计，全进程指标包含该成本。baseline 后补同源/同 rlib/同 flags 链接已与原受测二进制逐块字节比较完全相同，SHA256 为 `24683943ee32f3fb4007450b0cf88d2acc7e7cfb3b6fdecf90493df7823d22cd`。历史同时期单独链接命令日志缺失仍保留，不把后补重现改称当时记录。

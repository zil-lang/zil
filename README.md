# ZIL 任务与施工协调

[goal.md](goal.md) 是唯一实时任务看板；[workflow.md](workflow.md) 规定派工、独审、集成、证据与远端核验。领域规则见 [coordination/README.md](coordination/README.md)。本 `goal` 分支独立维护，不合入 `main`。

语言权威、编译器源码、静态阶段合同和真实输入在 [`main`](https://github.com/zil-lang/zil/tree/main)。从 [语言规范](https://github.com/zil-lang/zil/blob/main/_zil_design.md)、[阶段接口](https://github.com/zil-lang/zil/blob/main/spec/interfaces.json)、[构建说明](https://github.com/zil-lang/zil/blob/main/docs/guide/build.md) 和 [产品门](https://github.com/zil-lang/zil/blob/main/validation/product-gates.json) 进入。goal 中的状态不宣称语言或产品验收已通过。

旧施工、研究、收据和生成视图用主线固定提交 [`28b3e37bb4d8a1fe8b146c72cf891fc99de32440`](https://github.com/zil-lang/zil/tree/28b3e37bb4d8a1fe8b146c72cf891fc99de32440) 查找；旧 goal 看板与恢复表见 [`f24d3dbc01427bcb4fc52958148a527eb1754b71`](https://github.com/zil-lang/zil/blob/f24d3dbc01427bcb4fc52958148a527eb1754b71/README.md)。退役分支和实际 WIP 的固定入口是 [`archive/source-history`](https://github.com/zil-lang/zil/tree/archive/source-history) 的 manifest。历史快照不代表当前派工或验收。

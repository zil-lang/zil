# 独立语义对照

## 决策

标量参考模型使用 JavaScript BigInt 定义有界 i32/i64 语义。模型不导入生产 parser、types、analyze、verify、lower 或 LLVM 计算期望值；只把生成出的真实 ZIL 源码交给 CLI，再运行产出的本机程序。输入用十进制字符串保存整数，避免 JSON/JavaScript Number 丢失 i64 精度。

## 范围与约束

标量域目前覆盖检查加减乘、除余、取负、显式 wrapping、闭合算术 `#(...)`、局部绑定、有界循环、短路和条件分支。AST 深度、节点数及循环次数有硬上限。CT 算术失败应返回 `SafeReject / ct / E-CT-ARITHMETIC` 且退出码为 1；native 算术失败当前按 Linux x86_64 的 SIGILL trap 观察。其它信号、无法解析的报告、超时、进程错误和非零正常返回不当作期望算术结果。

热会话与冷会话相同只是缓存透明性证据，不能充当独立语义 oracle。生产的 verify/analyze 互相同意也不能替代这个模型；反过来，BigInt模型通过不意味着资源/完整闭包/ABI得到证明。C1另有独立Python环境模型，范围及实际执行见下节，也不解除verify的安全职责。

## 验证钉单

`tests/oracle/model-check.mjs` 用人工确定的边界值核对模型，避免只看模型和程序一致。72 个固定边界程序加有类型随机程序实际编译并执行。`mutationCase()` 故意让测试发射器把减法改成加法，必须发现同一性质失败、具体动作重放失败、缩减到单动作失败，并在取消变异后通过。这个自检证明测试链能发现该类接线错误，不宣称覆盖所有编译器缺陷。

## 可重放边界

每轮保存 Roam 具体动作、输入源码、预期与观察、编译/运行输出、原始失败和缩减结果，以及编译器 SHA-256、模型/驱动/vendor 摘要、clang 版本、Node/平台和 Git 提交。`--replay` 默认在指定的当前编译器上重放，`--require-compiler-sha256` 可拒绝二进制漂移。没有完整冻结动态链接库和 OS，不称为密封环境重放。

## C1局部环境的独立模型（本阶段已验收）

`tests/integration/closures.py`不导入生产AST/IR计算期望值；以Python中的不可变环境元组描述创建、复制、外部槽位修改、局部选择与重复调用，再把生成的真实ZIL源码送入正式编译器和native。第四轮记录实际执行24正常例与2捕获时序变异控制例，每例O0/O2。控制例必须编译成功且以值差异检出；Unsupported、编译失败、信号、超时或基础设施错误不是控制成功。

实际结果：正常`24`，控制`2`，native执行`52`，断言`182`，状态`Pass`。完整门运行`20261023T025031Z-1b10d976`，受测源码`5ad8bf13701dfc5fa6f40288771a31dbbbfc30ef`；当时收据见evidence/validation/20261023T025031Z-1b10d976/result.json，独立审核见evidence/reviews/014/review.json。固定seed和有界语料不等于穷尽fuzz；当前域不包含默认借入、FnMut、资源、逃逸、闭包正文内嵌套声明、捕获已有闭包环境或dyn。该段是第四轮历史结果；第五轮共享捕获由下面的独立域承担，当前结果从 final-summary 读取。

交接保留每例输入/源码/观察、实际Typed与LLVM产物身份、编译器与harness摘要、源码提交及dirty状态。原失败和修复后运行使用不同RunId；最终结果必须对应冻结源码，不用后来的Pass覆盖早先Fail。

## S0/C2a 共享捕获的独立模型

`tests/integration/borrowed_closures.py` 用 Python 槽位/绑定/载体状态计算期望，不导入生产 AST/IR 求期望；真实 ZIL 源码经过编译器与 O0/O2 native。正常集覆盖局部副本、分支、循环、遮蔽和最后使用后写入；最近反例检查后续仍使用时写入等安全拒绝。另以两项测试发射器变异验证值差异会被实际观察，不能把编译错误当控制成功。

合法只读程序中快照和借入有时具有相同数值，所以还检查 Typed 地址操作和 LLVM 的 ptr 环境/实际读取。独立审核另外破坏 Hold 表、存储激活及环境入口，确认 raw 候选不能自行背书。正式门固定 24 正常例、2 变异控制、4 拒绝例，52 次 native；实际状态、断言和源码身份由当轮收据给出，不能用这些预期数量代替执行结果。

三个语义域与 Rust 会话状态域的责任分开。017 持续 hunt 当前只接编译会话 profile；下一质量包把这些 native oracle 作为协议 worker 接入同一发现/修复队列，不能预先称已覆盖。

# Roam 的位置

## 2026-10-26 当前排程

现有profile/队列以低优先级伴随语言开发，具体反例进入独立修复；不扩平台作为主线前置。本轮只恢复原byte-buffer-native/2并执行24case/48程序的有限窗口，0新发现，工具与配额零变更。不要把这种有限窗口写成对话结束后永久服务，也不要用自然0发现或重复控制注错宣称发现能力充分。旧未保存112/118源码不能仅凭聊天恢复完成状态。


## draft21当前事实

四个实际profile为session、scalar-native、resource-closure-native和byte-buffer-native。最后一个已在098合入独立Rust模型、独立C参考与ZIL/C各O0/O2；不是通用ZIL降C后端。有限hunt、控制注错及完整关闭链有实际证据，但尚不能归因自然生产语义缺陷首次发现给持续Roam。099拥有字段/闭包组合、分配失败与free身份顺序尚未进入该hunt域，仍由专项源/raw/wire/native测试承担。下一扩展复用原操作模型，不另建队列平台；不启动未授权无限任务。具体证据见docs/DRAFT21-ROAM-AUDIT.md。以下轮次说明保留其历史范围。

## 决策

Roam 从当前阶段起作为仓库开发基础设施随 ZIL 施工，采用独立测试包和领域适配器。它不进入语言关键词、类型系统、运行时或生产 Cargo 依赖。用户提供的 TypeScript 原件逐文件保留并校验摘要；目前没有公开发布许可，不发布到 npm/crates.io。

## 约束与动因

语言正确性包含两类不同问题：一次程序的语义是否正确，以及编辑、取消、预算变化、缓存复用等历史是否改变结果。前者需要独立语义模型；后者适合状态路径探索。两者都应从实现初期持续运行，不能等功能齐全后补一层随机输入。

第三轮采用 tools/roam-rs 独立 Rust workspace 直接持有 CompilationSession；normal campaign 不再经过 Node worker / TSV bridge。保持 roam/1、roam-worker/1、seed 动作序列、六态与同 property 缩减；TS 原件仍是兼容参考，独立语义 oracle 仍单独运行。Rust 测试工具的 serde_json 锁与生产工作区分开；不引入生产依赖。Bun 冻结驱动和 native 可执行快照均不等于冻结操作系统、动态库或 CPU，当前实际平台仍为 Linux。

## 不采用的选择

不把 Roam 的通用 BFS 状态键直接设为“当前源码”：相同源码可能来自不同编辑、取消、缓存历史，生产系统中的隐藏状态不由该键代表。短路径在有界深度内枚举具体动作序列；长路径保留固定种子和完整动作。以后引入状态合并，必须先定义等价关系及验证依据。

不把删除式 shrink 称为 BFS 全局最短反例。当前 shrink 尝试块删除、逐项删除和可选动作简化，并保留相同 propertyId 的失败；预算耗尽、不同性质、invalid、error、unsupported、incomplete 均不能变成通过。

## 当前验证与后续

会话透明性以 `tools/roam-rs` 的真实持久化 Rust 会话与独立新会话比较，`tests/roam-rust/conformance.mjs` 校对 TS 参考的协议、16 seed、84 路径/1311 动作和缩减行为；标量语义由 `tests/oracle/` 的独立 BigInt 模型对照真实 native 结果。故障注入仅改变测试域或发射器，不改生产编译器。下一阶段可沿同一接口增加 verifier 候选破坏、资源状态迁移、闭包捕获和清理顺序域；它们需独立模型与明确边界后才登记为已实现。

随机探索和有限枚举提供缺陷发现与回归证据，不替代 ZIL 独立 verifier 的安全职责，也不证明完整语言正确。

## 运行产物

默认运行写唯一 out/runs 目录。成功 journal 在完成 durable ACK 协议后清理；失败原例、缩减例、property、命令和快照身份保留。一次 campaign 只保留一份内容寻址 native 快照。原始产物进入可选审计包，源码包保留小型收据和关键失败反例；不为每次通过复制源码、target 或可执行文件。

## 第五轮：一等工具入口与独立修复队列

公开短入口为 `zil qc`，内部协议名保持不变。Rust `hunt` 支持有限轮数或带停止条件的持续探索，发现非 pass 后发布独立原件并继续。消费者经 claim/token 认领，旧快照重现、当前候选通过、固定与历史关闭回归通过后才追加 closed。工具不自动编辑代码，合作消费者自己负责修复、构建和正式交接。

短期互斥用标准库内核文件锁，保持锁文件 inode，进程终止释放句柄锁；业务 claim 不自动偷取。原例、property、journal、stderr、源码/二进制身份保留，容量有限。一次 run 固定测试二进制，新构建启动新 run；没有跨机器租约或持续服务 SLA。本轮只有限运行验证能力，没有替用户启动无限后台任务。

第五轮时默认 hunt 是会话状态域；当时独立标量与闭包 native oracle 尚未接入持续队列。通用库/语言测试绑定可以后续增加，当前不引入语法关键字或运行时权限。

## 第八轮：实际收益审计与主线优先

当前session和scalar-native均可持续探索；后者是Rust独立整数模型加真实编译/原生执行，复用同一问题/修复协议。闭包、独占权限、公共泛型和IO的有限oracle/反例没有自动成为长期hunt profile。

已核查收据尚不足以把自然生产编译器语义缺陷的首次发现归于持续Roam。过期缓存和减法改加法属于受控注错；host/队列缺陷来自独审；本轮泛型地址投影和混合捕获误拒来自真实应用集成及独立复现。具体证据归属见docs/ROBUSTNESS.md，不把所有测试和审查成果统称为Roam发现。

一等支持指稳定开发命令、协议、复现和交接；当前不需要新增语言语义或生产依赖。此前工具/证据投入偏多，后续优先资源和应用主线，已有门伴随；仅具体缺陷族或重复验证需求证明价值时扩充长期领域。不要求每个新功能先建立一套持续平台。

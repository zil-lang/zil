# Qualified enum actuals and nested physical fields

The original recursive CT Source contains `Choice<life a>` with a `Leaf<'a>`
variant payload. Expand currently rejects the enum lifetime formal before
producing any complete nominal instance. Simply permitting the declaration
would leave its physical payload and caller class relation unrepresented.

Extend the existing stored nominal producer to enum declarations with original
SourceIndex identity, full ordered Type/Const/Life parameter kinds and actuals,
and the actual substituted variant/payload order. Publish a
`LifeNominalKind::Enum` and a `LifeNominalInstance` whose type is
`BorrowedStorage { storage: Enum { name, variants }, life }`. Match every
physical variant field to its original source field position. Physical names
locate already produced children; only the original application and actual
lexical scope establish child classes. Direct Type formals select their full
ordinal before substitution. The producer must preserve distinct class maps
when equal physical child names arise from different source positions.

For each payload, recurse through Tuple and Array semantic element structure
with prepaid clone, key, class and traversal work. A retained child class in a
homogeneous Array maps once through `LifeTypeProjection::Element`; physical
slots need an actual `PlaceProjection` and are rejected if the current path
cannot select them. Variant payload places use
`PlaceProjection::Variant(VariantProjection{variant,index})`. Wrong source
declaration, kind/domain, payload correspondence, missing class mapping,
ownership shapes, cyclic resolution and unsupported projections fail closed.

Publish the same declaration and instance through the existing Core inventory
without a public schema change. Copy registration examines the substituted
physical enum fields; neither an enum name nor a class row grants Copy or
borrow/capture permission. Existing all-Type nominal paths retain their
current instance key, work and byte fees. Types, Analyze and Verify each check
the published enum and physical fields independently.

Nested physical applications such as `Wrap<Leaf<'a>>` and `Wrap<T>` where `T`
is a qualified actual are rebuilt from the original field syntax and the
original complete Type actual syntax. The substituted physical application
must match its original declaration name and arity before the producer records
its direct child relation. This keeps caller classes from the real source
scope even after physical child names have been generated. A compound field
with no complete scoped application fails closed.

When a qualified Type actual appears inside another field application, its
caller lifetime occurrences are resolved against the caller scope before the
outer nominal's formal lifetimes are installed. An unspellable internal token
indexes each captured lexical class during the cloned source application;
the token mapping is scoped to field production and restored on failure.
This prevents a caller `Leaf<'a>` inside `Wrap<T>` from being rebound to an
unrelated outer formal also spelled `a`.

The expression path captures the original source record application before
rewriting its constructor to a physical name. Field hints retain full
Type/Const/Life actuals; a qualified enum constructor specializes that source
application, checks every payload against its actual source field type, then
rewrites the callee to the generated enum namespace. The expression's source
type retains its full actual vector for later pattern checking; the Types
consumer resolves the physical callee through the unique published
LifeInstance. Neither the generated name nor an expected physical name
supplies a new lexical class.

SourceFact runs before physical specialization. Its qualified enum facts use
the actual enum declaration inventory and full argument ordinal, including a
class fact for each lifetime actual. An explicit enum constructor must prove
each full actual from the caller scope and compare its payload against the
source declaration. An unqualified variant infers only facts present in its
actual payload and fails if any required ordinal remains unknown. Free CT
calls with mixed Type/Const/Life formals map the actual full vector by ordinal;
the previous all-Type and short path stays unchanged. Scalar constants carry
their declared domain proof and introduce no lifetime class.

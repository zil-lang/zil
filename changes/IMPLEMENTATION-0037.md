# 037 既有模式条件贯通

沿既有 `Condition = Expr | let Pattern = Expr` 文法实现 `if let` 与 `while let`，新增明确的未核 Core 条件节点。复用普通模式检查和受检查的 payload 读取；Typed CFG、raw wire 与机器指令不新增权限或操作。

条件值每次测试仅求值一次。匹配绑定只存在于成功分支；失败分支、else 与循环外不能引用它们。while let 每次回边重新计算条件，break/continue/return 沿既有作用域清理与借入来源核验。允许无反驳模式，不把条件当作必须穷尽的 match，也不因生成的默认分支而误报重复模式。

闭包约束图接入相同的模式类型关系，也复用于既有 match 的各分支，支持分支内创建闭包和闭包内匹配；穷尽性与冗余分支仍由后续普通模式核验决定。前置走访、模式递归和具体类型复制都受预算约束。CT 源遍历保持运行时模式绑定的遮蔽，依赖函数收集器在克隆前检查 if let、while let 与 match 的完整模式/类型树。原始 CT 执行能力仍由独立 verify 决定。未实现的引用模式与资源 payload 继续明确拒绝。

真实组合回归发现闭包末尾 match 各分支显式 return 后，解析器仍补空 return，导致类型推断把不可达 Unit 与有效返回类型冲突。修复仅识别受预算限制的显式终止路径（完整 if/else、块、match）；不新增 match 尾表达式糖，未明确终止的路径仍保留 Unit，非穷尽 match 仍由普通类型核验拒绝。

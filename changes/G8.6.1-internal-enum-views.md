# G8.6.1 完整 Enum 的内部视图补片

root 在真实 Source 与等价 raw/Wire 定位之后批准本补片。首个缺口是 worker 指令名单未消费 `PlaceTagLocal`；仅将该 empty-path tag 观察换成等价 VariantTagLocal 后，实际 generic BorrowPlaceLocal/ReadAddress 的同 poll 和内部地址跨 yield 已通过现有独立核。这不是外部借入 frame port，也不是部分移动，不能据此一概禁止普通合法投影。

Analyze 与独立 Verify 分别只接 `PlaceTagLocal` 指向实际 local、根为已准入完整普通拥有 Enum、path 为空的情况；不是全局开放 mixed tag/projection，也不开放 ErrorUnion/Package 等未准入根或非空 path。实际现行 tag、成功 guard、loan/重写失效及唯一 root debt 仍由各自 ordinary Sum/loan 和 Task frame 消费者重建。内部 view 指针必须从真正稳定帧的 Enum payload 地址产生，帧和真实 tag 保持到最后使用；取消只结算封闭帧内部责任，不向外返回或保存该地址。外部借入输入/port、拥有 Sum 输入/结果、部分 Sum、活 view 期间的 move/drop/retag、非 i32 结果仍闭。

必要 Source 是同 poll 只读与实际 view 地址跨 yield 的两种时序，各用运行时未知 flag 选择同型 Left/Right 载荷，分别完成/取消；完整 i32 结果带不同分支常数并实际检查，生命周期输出和退出码同时核验。Wrong tag、漏成功 guard、活 view 时移动/改 tag 由独立 raw/Wire 近邻拒绝。mutable 只先探针，无完整实证不升级。稳定 frame pointer 由 g1 非作者核实，Verify/Source 由 g8 非作者核实；新指令 root/type 检查在当前预算付费，不改公共 schema/Wire/ABI 或默认额度。

同时修正先前机器证据的观测范围：首轮60次只观察生命周期 trace/退出码，main 丢弃了 drive 的 i32，不能据此声称已验证完整 worker 结果。最终矩阵必须在 Ready 及普通 Direct 返回处真正比较值；Pair 用非交换表达式检验字段，prepared 嵌套同时检验 Token.code 与 child 结果。旧60次保留为前一证据层级，不与最终矩阵叠加。

这里的 retag 边界特指实际 view 仍活着时改写其根、或使用已失效的旧 tag 观察；不把 view 结束后的普通完整 Enum Drop/Store 重初始化列为统一禁令。本轮实际 retag Source 近邻先遇 Types 形状拒绝，不能据此声称其已消费 Analyze loan 检查；精确 typed/raw/Wire 邻居由独立 Verify 记录。

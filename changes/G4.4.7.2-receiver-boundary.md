# G4.4.7.2 deferred receiver 边界

root实际派工，D保留的旧CT5反例在nongeneric Reader own Type+Life+self receiver body CT路径误落CT-only scalar helper已删除后的unknown scalar。当前runtimeCT成员尚无独立实际member入口认证，需在真实deferred receiver处保留明确Unsupported，不提高成员资格或放宽来源门。

按实际function.params长度先付工作量，只有deferred=true且真实self参数才返回原精确generic function specialization诊断；无self的static namespace成员保持原路。旧Source反例与诊断断言不改。构建/原生复验由root/D作者统一调度。

# 函数初始化语义子查询复用

基线：3d6babe17ee9d0a2f62d123063fb7af6a0886612。父任务为编译专项，生产写集限 zil-analyze；driver Session 接线由同专项持有者完成。

当前 Analyze 每次修改都重算所有函数的初始化固定点。该子分析只读取函数入口、局部数量、参数编号、块编号、控制边、每条指令对应的初始化读/写/移除操作；不读取常量数值、callee 正文、类型布局、源位置或函数名。将这一精确语义投影作为内容键，复用成功的初始化 BlockPlan、前驱和可达性表。投影相等形成传播屏障，即使原始函数正文或源偏移改变，未变化的初始化子结果仍可复用。此处是内容查询，不以遍历函数编号或源偏移冒充稳定声明身份。

缓存只保留最近一次完整成功 Analyze 中使用的不同投影；本次新结果在整个 Analyze 成功后发布，失败不发布半成品。当前模块仍先完整 preflight，retained、scopes、callable、helpers、资源效果与holds仍在当前模块重算；每个完整请求独立 Verify。缓存从不保存错误、诊断、Verified 或安全授权，不序列化。

每个成功子结果携带原算法精确逻辑费用。命中且余额充足时扣除原费用；不足时执行原算法，保持最先耗尽的上下文及与当前源绑定的诊断。缓存查找及表示复制属于实现开销，不能改变原规则费用或默认预算。完整费用/N−1/fresh、常量/控制边/初始化操作变化、源位置变化、错误恢复、资源效果与容量控制必须覆盖。

此片不宣称完整单函数 Analyze、Types 或跨进程语义缓存。效果必须区分初始化子分析重算次数、完整 Analyze/Verify/请求时间和缓存保留内存，并由新分布真实源码验证；函数 CFG 很小或不重复时可能无净收益。

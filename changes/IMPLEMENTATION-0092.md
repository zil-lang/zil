# 092：借入切片公共表示与原生执行

父任务 B0，规范及公共接口为 schema16；公共声明已在19cedd4a先冻结，实施依据见PROPOSAL-0090-0092-SLICES。此文在后端实现前提交。

普通切片窗口按 `{ ptr, i64 }` 传参、保存、返回和重借，无堆分配；只支持已有checked x64 LLVM Linux/Win64目标。源数组或切片的引用资格由独立Verify建立，lower/backend继续绑定完整VerifiedModule，不从复制的fingerprint取得权限。

AddressSlice先取基底和长度、将已求值整数端点扩展为i64，检查lo<=hi<=len后才作GEP和减法，负有符号端点由无符号比较拒绝。AddressIndex对切片先检查index<len，随后按实际元素机器类型计算地址；Unit等零尺寸元素用aggregate-field布局，不能生成void GEP。SliceLength提取长度，不改变静态活性规则。Reborrow保留全部指针/长度位而不新增运行时管理层。

源码消费者为普通多模块序列处理：不同静态数组共用运行时长度接口、动态子范围更新与嵌套切片、参数来源返回及别名冲突拒绝。实际O0/O2执行和独立Rust同语义观察覆盖正常值、空区间、边界trap、端点求值顺序及既有资源清理；原始编译命令、阶段产物和输出按run目录保留。该消费者不施工ZUI、不宣称动态Vec/String或平台留存生命周期完成。

限定测试与独立非作者精确审核后才能进入正式集成。公共wire新的类型/操作及所有可选端点必须纳入指纹；旧/未知版本拒绝。全部失败保留，最终测试与未测边界以真实收据为准。

The old `fnonce-helper-next/give-f.zil` gives an ordinary Value F. §86–92 explicitly disallow give for ordinary Values; it must remain a nearest rejection. F is transferred by ordinary Value movement. Actual Managed give inside F or a declared Managed companion is the legitimate scope.

For cycles, retain accepted DAG proof as the exact old path. Only non-limit graph/profile rejection enters a cyclic consumer, with no limit retries. Analyze uses a forward input-state worklist; Verify independently recomputes predecessor states in bounded fixed-point sweeps. Both preserve actual parameter provenance, local activation, SSA transfer and per-role settled debt; equal types grant no identity. Reachability, actual blocks and SSA definitions checked, unsupported effects remain closed. Cyclic StorageLive is valid only at a definitely inactive empty nonparameter slot, and resets activation for that dynamic iteration; a consumed original owner cannot be resurrected. No unbounded path enumeration.

Source acceptance includes loops before/after consumption, nested branches/loop transfers, multiple different and same-type runtime environments, selected invocation versus unused destruction, actual Drop side effects and lending final-use controls. Hostile neighbors cover duplicate consumption/backedge, activation omissions, parameter/SSA substitution, wrong resource teardown identity and environment escape. Existing raw/Wire, N/N−1/fresh/retry and old exact fees remain mandatory. Machine observations require real Clang/API O0/O2 and actual cleanup counters; stage-only results cannot stand in for those. No runtime Box/RC/lock/global registry is added.

Rust four goals: safety and ordinary expression composition are targets, not yet evidence; inline layout is retained, comparative runtime/RSS/compile/maintenance and a product-level net breakthrough remain unmeasured. Existing product conditions are unchanged.

# G3.3 qualified callback environments

C40's rich callback consumer admits only capture-free Fn. Extend this private
consumer to finite inline scalar captures, with actual Fn/FnMut/FnOnce mode
adaptation, exact construction operands, capture reads/writes and independent
role equations. No implicit allocation, ABI/schema version or default budget
change is needed: existing concrete closure environment instructions carry the
actual inline fields and receiver locations.

The nearest counterexamples are a shared entry writing its capture, a mutable
call through a shared/immutable receiver, repeated consumption of one actual
FnOnce parameter, and the same concrete closure checked under incompatible
role class equations. Every environment instance retains its own local/SSA
identity. Missing enclosing Fixed context remains rejected, rather than being
freshened for each invocation. Owning/address captures, lending results and
arbitrary state/cleanup require their separate actual consumers.

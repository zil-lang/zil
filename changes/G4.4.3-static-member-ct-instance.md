## root授权的私有链施工合同

仅原始 nongeneric struct host 的 static、显式完整 Type/Const/Life CT-only member；不新增receiver、generic host、runtime generic body CT相位或generated支持。callee身份必须是本请求不可变AST里实际host节点和实际member节点，经原SourceIndex遍历得到的完整module/top-host/member位置；限定callee路径只作普通名字解析，不能把名字/Span当身份。`Left.make`/`Right.make`或不同模块的同名`Maker.make`保留不同原符号；完整向量含穿插参数的原ordinal、未使用参数也不得抹掉。abstract定义检查和actual调用分别消费，不由实例成功授信。

拟复用Compiler原free函数行，新增member行及host定位映射只在新scope分配；member行、映射、原AST遍历、路径比较、完整向量clone/key和调用scope扩展均在当前工作/node/temporary-bytes/depth余额预付，旧无member路径不新建旁表。Frozen调用账须从实际member重新核nongeneric host、static签名、完整原参数及parent-origin关系；canonical symbol key继续编码原host identity和完整member路径，不只存callee短名。

# Actual closure context transport

The current syntax has no expression identity beyond diagnostic Span. A parallel table joined by Span, a generated name or coincident traversal number would associate unrelated closures. A pointer key is also insufficient across AST relocation, cloning and allocation reuse.

The proposed request-local syntax marker is only a relocation reference. The actual producer overwrites incoming raw markers, assigns a fresh table entry while processing that exact closure, and binds it to the actual original declaration context. Core lowering consumes the marker on that same node and attaches the entry to the freshly minted Core expression and creator IDs. A parser, generated syntax or cache cannot establish completion by supplying a number. Missing, duplicate, orphan and wrong-creator entries reject. Transforms after assignment must carry genuine lineage or fail closed; cloning must not silently share a one-use row.

The initial producer is restricted to life-only free-function Definitions with genuine input-derived capture grounding. A source life uses its full original ordinal. Type-local class0, an anonymous outer Address and a declared life parameter remain distinct. Types reconciles logical source capture selections with actual inferred LocalId/capture slots before forming the joint Parameter/Capture/Result contract. Each kernel derives persistent Fixed facts from each actual environment; only Invocation is fresh at a call.

Complete source scope identity is separately retained in the root-published Core/Typed tables and semantic cache keys. Runtime permission comes from actual captures, roots, modes, loans and cleanup, never the marker or identity table. Full mixed actual vectors and generated scopes are not inferred from the first profile. This proposal changes no default quota or product threshold and is not an acceptance record.


## Finite Core boundary, no unused runtime identity table

The first source profile is an original free-function life-only Definition.
A paid request ledger binds its actual creator, expression and elaboration
occurrence to the original declaration identity, full generic order, source
P/R proposal and actual creator-input anchors. Anonymous header classes keep
`source_parameter=None`; no synthetic source life parameter is invented.
Types must resolve those input anchors against actual captured places and
jointly canonicalize Capture/Parameter/Result before producing the existing
Typed contract. It must reject unused, duplicate, wrong-owner or ungrounded
rows, and preserve exact header/loan obligations. Core transformations preserve
or explicitly retire/rebase rows with their actual nodes. A nonempty table is
currently Unsupported until that formation consumer is installed.

The independent architecture review found no current runtime consumer needing
a duplicate source-identity Typed table: both kernels reconstruct actual
MakeClosure environments and the complete relation; semantic caching rejects
storage_life and incremental function caching rejects this closure/Tag
profile. Thus source names are erased only after actual joint formation.
Wire42/Typed/CT5 remain unchanged. The unimplemented instantiated/generated/
member/mixed vector and independently escaping callable identity profiles
remain G4.4/G3.3 follow-ups; the earlier full-table draft is not a delivered
schema. This changes no default allowance or runtime representation.

## Actual lowering and snapshot preflight checkpoint

CoreLower now records the minted creator ID before lowering its body and the
outer closure expression ID after lowering its body. The same request ledger
consumes each event with the actual module/item origin, then reconciles after
all modules. Two real Source-to-Core cases pass, including distinct creator
identities and complete-request N=6080 / N-1 / fresh retry. This is not Typed
or native acceptance; the formation consumer remains closed in this checkpoint.

The early Types inference boundary rejects unconsumed nonempty contexts before
Core cloning. CT snapshot copies traverse and charge all context rows, text,
paths and finite life parameters before allocation. Pure CT query selection
rejects a selected runtime-context creator and retires rows of unselected
creators. A raw 4096-byte context and over-depth path exercise the preflight;
old empty-context fixture cost remains 5 nodes / 14 work. No metadata produces
execution or loan authority. Syntax transport uses a four-byte index with MAX
reserved for absence; equality still ignores transport, and actual producers
must reject MAX as an allocated slot. This restores the old AST size without
adding a new heap allocation or suppressing strict Clippy.

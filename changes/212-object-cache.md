# 212 显式、可信、本地的原生对象缓存
依据：ZIL-ARCH 19.4（当前核验授权、对象action key、产物内容身份分离）。
新增CLI `--object-cache DIR`，只对LLVM API启用；不设置时保持既有行为。指定DIR即声明该目录及工具链是用户控制的可信构建环境，不是任意外部下载缓存。缓存读/写失败按miss/bypass处理，绝不产生已核能力。
对象复用在当前语言Verify及已核LIR绑定之后；命中仍运行当前机器结构预检，随后复用此前由同工具链完成核验和优化的完整对象。不为命中伪报LLVMBuilder/LLVM verifier本次执行；链接与最终发布仍执行。新对象在完整请求成功发布后才写缓存，缓存写失败不将成功发布反标失败。
key覆盖同一编译器二进制与实际LLVM共享库的安装身份、运行时LLVM版本、完整目标profile/优化配置，以及模块triple和所有机器实体的精确顺序/结构。只排除不被Builder读取的全局验证指纹注释；当前核验绑定仍保留。身份不稳定只造成miss，不借此重命名符号或调整分区。
信任：已安装的编译器/LLVM使用ELF build-id和文件元数据识别，缺build-id时散列完整文件；build-id不是对敌手的真实性证明。缓存包包含key、对象长度和SHA256，检测意外损坏；不支持敌手可写缓存的真实性验证。实际机器配置与完整编译器身份一起绑定，后端实现变化自动失效。
不新增语言接受性、Wire、优化属性或数值验收条件。默认仍单CGU、缓存关闭；此片成本结果只说明被测显式缓存配置。

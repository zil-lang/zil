# 0142 普通库：定宽 Copy 字节记录容器

只增加普通 ZIL 模块，不改变 IR/schema、内存权限、默认额度或产品门。以已有 ByteBuffer、借片、137 truncate、Package/拥有回调承载 ZUI 的紧凑事件记录和索引序列。不是泛型 Vec<T>，不存放 Managed 元素，不做地址重解释；宽度及长度对齐在公共操作处检查。

增长先校验范围/整数上界，再以几何容量 reserve；分配失败保持原状态。插入/稳定删除的线性搬移和 swap_remove 的单记录搬移明确区分。返回记录视图借自实际底层载体；相交修改和自插入必须由原独立 Verify 拒绝，即使运行时会失败或不扩容。普通库错误/范围返回不会制造权限。

普通 Managed 局部整体替换暂不开放：现有 DropManaged 是自动清理并独立核对逆成功初始化序；简单地“暂存新值、Drop 旧槽、Store”会违反该顺序。去掉 Types 的 Unsupported 既不能形成完整实现，也不能据此放宽 Verify。保留为独立编译器缺口，容器闭环不等它。

扩展同一普通库切片：inbox 单线程有界字节 FIFO，将 Package 标量状态、拥有 ByteBuffer 和 FnMut 组合为关闭/排空后立即释放的消费闭环。无 ABI/schema/编译器求证修改；不是异步排空或泛型拥有元素容器。

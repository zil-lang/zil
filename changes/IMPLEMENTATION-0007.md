# 007 源码交付瘦身

## 问题与决策

默认源码ZIP与可选审计原始产物/Git历史分离。保留源码、规范、任务、当前决策、紧凑结果/审核及关键失败小文本；大型原始产物独立归档并有机器清单、hash和恢复方法。不得改写历史、删除既有严重失败或降低handoff。旁置bundle恢复说明要正确。先不改既有验收判定或legacy runner默认。

## 可检验边界

源码包解压真实构建/运行；审计清单与hash可核验、恢复路径不得逃逸、重复/缺失/篡改拒绝；源码包不含ELF/bin/target/Gitbundle，大小与文件数有真实统计。必须明示raw省略，不能冒称源码包有全量证据。

正式语言/产品完成门保持。详细派工在.task/impl/007.md。

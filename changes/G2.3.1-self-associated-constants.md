The concrete source gap is:

```zil
trait C { const A:i32; const B:i32=Self.A+1; }
```

## Existing boundary and smallest bridge

Driver `ct_artifact/associated_constants.rs` deliberately skips expressions
whose dependency walk finds Self or a generic parameter. It already evaluates
closed explicitly scalar equations via `expression_value`, the source CT
compiler, independent CT verification and VM, then reifies ordinary literals.
Expand `generic_trait_constants.rs` already has declared-type symbolic atoms,
exact trait-instance keys, concrete `solve` witnesses, definition checkers and
canonical literal consumers. Its three `closed` gates currently precede useful
symbolic default checking and concrete equation evaluation.

Removing only the skip cannot work: the CT compiler's Member path has no
associated-constant value consumer. The frozen reflection ImplSnapshot also
admits only its existing method-only trait subset; it is not a constant witness.
No reflection query or unverified syntax lookup may stand in for proof.

The proposed first implementation is a private, request-local two-stage bridge:

1. Expand prepares a finite equation plan using the ordinary trait index,
   coherence and complete selected-impl obligations. A recipe is not a witness;
   candidate values must not prove their own premises. Definition checking uses
   declared associated scalar types under symbolic Self, including unused and
   overridden declarations. Do not globally replace a trait default with the
   result obtained for one host.
2. A plan entry binds the actual nominal host, exact ordered trait instance,
   declaration/member identity, chosen impl/default source and receiving scalar
   type. Resolve dependency edges with active/completed states. Driver replaces
   only references to already resolved, verified scalar dependencies in that
   entry, then uses the existing verified CT expression path. No host arithmetic
   interpreter, dummy type substitution, new CT value tag or public IR field.
3. Reify each result for that concrete impl instance; preserve the original
   symbolic default for definition checking and retain source lineage. Final
   ordinary expansion repeats the usual obligations and receives ordinary
   literals. Direct Expand without a CT bridge must still explicitly reject an
   unevaluated concrete equation rather than treating syntax as a value.

Recommended smallest scope for root to approve: nongeneric trait and concrete
nongeneric nominal impl; explicit existing scalar receiving types; own-trait
`Self.<declared constant>` edges and pure scalar expressions. Preserve all
existing closed-equation/helper and symbolic-read behavior. Generic impl
instances, associated receiving types, inherited/ambiguous constant selection,
and new cross-module or generated contexts remain explicit Unsupported until
this bridge preserves their complete identity and definition obligations.
Existing accepted inputs in those lanes must not be blanket-rejected.

## Definition, cycles and failure rules to fix before implementation

Unknown/wrong-type Self members, duplicate/missing equations, ambiguity, foreign
or runtime effects, and impure helpers remain definition errors even when the
member is unused. Closed equations keep the existing CT execution and failure behavior.
A real active equation cycle must diagnose a cycle, not run to a host stack
failure or silently return a default value. Acyclic dependency growth stops on
the request budget. Source order must not decide dependency availability.

All defaults and impl values first receive declaration-time member/type/purity
checks, including unused and overridden equations. Closed expressions retain the
existing complete CT evaluation, including overridden 1/0. Without an impl,
Self-dependent equations receive symbolic checks only: no Self value, numeric
sample or hypothetical host is invented.

For each real committed impl, evaluate every effective constant, choosing its
explicit override or the original default. A separate DefaultCheck job evaluates
each overridden Self-dependent default against that impl's completed effective
Self.member values. It cannot replace an override, provide an effective value,
or prove an impl premise. Effective graph Active cycles reject explicitly. An
override that breaks a template dependency cycle is a valid control; do not
reject the unselected template graph. Finish all jobs before updating stable impl
ordinals in the output AST. Preserve the symbolic trait default unchanged.

All plan scans, symbol/instance-key comparisons, dependency insertions, clones,
substitution output, CT compilation, independent verification and VM execution
use the same remaining request ledger. Preflight depth/size before allocation;
transfer consumed work between Expand planning and Driver CT without resetting
limits. No default-budget increase. Test exact N/N-1 and a fresh successful N.

Memo identity must bind resolved declaration ownership, complete host/trait
arguments, member ordinal and selected impl/default, source/context dependency
fingerprints, target (including usize width), receiving type and selected
limits. Span, name, expression spelling, or result scalar alone is insufficient.
Changing A, swapping two hosts, changing an override, shared spans, imported
same-named traits and cold/warm semantic caches must not reuse a stale B. Reuse
existing source/CT/instance identities; any new public schema or encoding
requirement is returned to integration before implementation.

## Proposed write set and limited checks

Private Expand trait/constants planning and definition checks; Driver
ct_artifact associated-constant materialization and necessary CT entry/context
plumbing; existing impl162_trait_bounds tests and a small source fixture.
No root Cargo, public schema, normative files or new test target. Do not change
Types/Analyze/Verify ownership rules for a scalar frontend feature.

Check literal and Self-dependent 42 through real Source/Core/Types/two kernels,
raw/Wire and native O0/O2; multiple actual hosts and reversed declaration order;
unused bad member/type/effect, missing/duplicate equations, real cycle and finite
growth, old closed/override controls, 32/64-bit arithmetic, source-context/cache
identity, and exact budgets. Native success must assert the actual result rather
than merely successful compilation. Independent review binds the final commit.

Rust goals: this proposed slice removes a concrete associated-default expression
gap while keeping compile-time evaluation checked independently. Runtime/RSS,
compilation/maintenance costs and a repeatable net breakthrough are unmeasured;
no broader trait/life or language completion follows from this proposal.

## Final phase guarantees and first-slice boundaries

`associated_constants::prepare` returns only immutable-input item/member
coordinates and remaining allowances. Its private trait index proves actual
ordinary recipes before scheduling; values never establish their own premises.
The Driver creates no numeric sample for symbolic Self. Definition jobs compile
and independently verify typed scalar dependency parameters without running the
VM. Effective and DefaultCheck jobs use the existing compiler/verifier/VM and
publish only after every job succeeds. Original trait defaults stay symbolic.

Standalone Expand checks definitions and consumes already materialized effective
values; it rejects an actual unevaluated equation even if main never reads it.
It does not claim the Driver's full DefaultCheck guarantee without CT input.
Only the Source Driver bridge supplies complete Source acceptance before Types.
No public/serialized completion marker is introduced. Private completed-job
coordinates originate solely from this request's successful CT work and move
with actual output item positions, including removal of CT-only functions.

After materialization the Driver audits actual output impls. Real imports,
definition-site required imports, full alias parameter ordinals and caller scopes
are reconstructed with a separate depth/work/byte bound. Duplicate or unresolved
names/targets, unselected Meta declarations and recursive aliases cannot establish
Closed. A missing nominal binding in a complete namespace is left to its existing
consumer, not declared Closed or given a trait permission. Uncompleted generated,
late-selected or cross-module Self-default impls remain specifically Unsupported.
Root-registered original local instances are the admitted first slice.

The real #emit and #for nearest sources currently fail at existing Expand
profiles (`generic expansion of unexecuted syntax island`, and the finite #for
item-kind restriction). Their closed #emit control passes. They do not demonstrate
a Source bypass or a reached coverage guard. Separate untrusted actual-output
AST component controls exercise the post-audit, aliases, ambiguous Meta rows,
conflicting frozen import targets and actual ordinal relocation. These component
controls are not labeled native/source generation acceptance.

A mixed resource Drop + associated-constant trait source has an older fence:
Expand reports `generic bound Drop is not a declared nominal trait`. A CLI built
from the original fe69 baseline verifies resource-only input, but the same mixed
source with literal B=42 already reports this exact error. This slice records it;
it does not broaden resource/trait normalization. Generic/inherited traits,
nonlocal impls, type-dependent receiving types, generated contexts, and Self
references inside CT syntax/statement forms without a scalar substitution
consumer remain explicit follow-up scope. Existing closed/helper paths stay.

Planning now has an opt-in temporary-byte ledger in the private generic budget.
Object/header and text/key preflights bound clone/metadata allocations, including
projection growth exceeding raw input size. The child starts with the current
remaining request limits and returns its debit; live Plan vector/string capacities
remain charged while released preparation scratch is refunded. CT program copies,
substitution output, graph/alias work and actual scalar results share the same
ledger. Ordinary Expand's existing budget mode and default limits are unchanged.
The byte bound is conservative compiler bookkeeping, not a measured RSS result.

The native fixture checks each host/trait result separately, so swapped values
cannot cancel in a sum. It includes a method between constants to distinguish
complete member ordinals from constant-only numbering. Cold/warm/fresh exact
limits, override/source changes, multiple module-local owners with private
same-named helpers, bool/f64 results, 32/64-bit usize, raw/Wire and actual native
executions are recorded in the limited author receipt, separately from review.

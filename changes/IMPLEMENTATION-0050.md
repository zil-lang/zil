# 0050：精确有限关系的区域消元研究

## 提案（实现与计时前）

本片只增加独立 Rust 研究程序、固定实验形状和证据。它不接入 TypedIR、不改变语言接受性、预算、清理顺序、产品门或可信核。046 的模块工作列表优化及小例完整检查退化继续保留。

候选算法把一个区域的局部约束合取，再仅对内部变量存在消元，生成保留变量身份的**联合边界关系**；区域组合是共享变量等值连接。独立慢参考逐值枚举赋值，并直接检查原始约束，不调用候选的连接、消元、计划或缓存代码。性能对照另用同一关系精度的单体连接，不把更弱的 may-set 工作列表当等价基线。

正常和失败结果都必须进入完整观察关系。安全解释是没有可达的坏结果；存在安全结果不代表所有执行安全。每个输出元组重建一个完整赋值并核验原始约束；小规模完整性由独立枚举对照保证。这不是可用于生产的完整证明证书。

预算在分配输出表项前检查。超过宽度、行数、工作量或整数表示范围时返回明确限制结果；不得截断、丢行后成功。显式关系表对域大小 d 和边界宽度 w 可有 d^w 行；不声称所有符号表示都有同一下界。

非单调编辑采用精确输入比较和依赖失效；不得把旧关系并回新关系。具体 transfer 的 kill 可在 powerset 格上保持单调，这与编辑后的旧摘要是否可复用是两个问题。闭包和 trait 只以有限协议模型研究相关性，不宣称完整语言能力。

## 先冻结的实验要求

固定模型生成配方、算法合同、限额、采样次数和输出身份，然后才做 release 交错配对计时。计时包括输入构图、分解、摘要、重组、赋值重建和原始约束核对；读取配方文件与进程启动在计时外。报告宽度、表行数、密度、阶段成本、全部重复样本及退化；不依据样本重新选形状或只选最小值。

## 本片结果

执行代码为 `bef7d9f3dbfebf9ab8deaae9c1f207819fcd81b0`；冻结 manifest 在 `bdb1576` 提交后才开始计时。16 个限定研究测试通过，含 2048 个初始随机模型、256 次非单调编辑、18 个固定形状，以及闭包捕获相关性、重复消费、共同 trait 替换、失效、限制和篡改反例。生产测试、正式全门均未运行。

唯一一批 6×7 交错配对样本完整保留。链16的单体精确模型 12.4772 ms → 区域 0.05731 ms；密图12反向退化 0.10062 ms → 0.53706 ms；小例和闭包亦退化。宽16观察边界输出32805行，两者均未压缩。没有把这些数字推广到当前 ZIL 或 Rust 编译成本，046 的小例退化不被冲销。

实际实现包含逐节点联合摘要、消元值恢复、逐原始约束核对和事务式内容失效；慢参考使用独立回溯枚举。见证检查不能证明完整性，源码/TypedIR 抽取尚未连通。生产潜在点定位到资源检查中状态复制/合并及 Desc/newer 关系；尚无生产热点采样，不修改核验器。下一阶段先测真实语义图和独立完整性核验成本，再决定生产写集。

## 050-R1 提案：复用表也受当前预算约束

独审在 `cb16a84` 发现：三值 chain8 的答案9行，缓存建立后将 rows 上限降为6，未改模型的 update 会跳过表限制，仍成功返回9行；同限额的新计算会拒绝。root 决定本轮修复。

当前 rows/scope 上限约束本次成功更新的全部摘要和最终输出，不限于重算结果。复用前先检查表形状，再按复制的关系行和消元见证条目计费；超限不得先克隆该表。事务改为按拓扑顺序构造新值列表，脏节点直接重算，不先克隆全部旧摘要；发布仍只在全成功后发生，失败保留旧缓存和恢复原预算后的可用性。其它计算规则、默认限额和生产代码不变。

追加精准 rows/scope 收缩与复用复制工作量回归，保留同一测试文件的修前失败/修后通过记录。原 `bef7d9f`、冻结合同/input-manifest 及1512条样本保持原样；修复后源码身份不同，本轮不重采性能，也不把旧性能归于新提交。

# Qualified pure Array projection consumers

Types admits a by-value Array signature only after the actual finite inline graph passes its own paid pure-shape walk. Analyze and Verify independently traverse each real Array/Enum/Record/Tuple payload, reject Address and owning leaves in all variants, and require every qualified descendant to equal exactly one complete nominal instance whose metadata and physical payload already passed module preflight. Array values carry no target or loan; an immutable address to one remains subject to the normal actual address/index bounds and root proof. Ordinary Copy arrays retain their old admission path.

The executable projection path pays the new deep Type copies before cloning a qualified Array element, result, address, or tuple and borrows known Name/Index shapes for classification. A plain Struct may embed a pure Array with a qualified child, while Analyze and Verify signature relations treat that complete array as a value with no new loan. Their module preflights still check its real physical graph and unique nominal instances before any relation or plan is accepted.

Signature relations consume each actual qualified child class at its ordered Element, Field, or Variant type path; a missing or forged row is rejected. Pure field and index updates compare full input, child and result types while retaining the existing no-target/no-loan transfer rule. The new source-project Enum clone charge runs only for an actual qualified Enum candidate, preserving the prior ordinary owning Enum budget path.

# Qualified pure Array projection consumers

Types admits a by-value Array signature only after the actual finite inline graph passes its own paid pure-shape walk. Analyze and Verify independently traverse each real Array/Enum/Record/Tuple payload, reject Address and owning leaves in all variants, and require every qualified descendant to equal exactly one complete nominal instance whose metadata and physical payload already passed module preflight. Array values carry no target or loan; an immutable address to one remains subject to the normal actual address/index bounds and root proof. Ordinary Copy arrays retain their old admission path.

The executable projection path pays the new deep Type copies before cloning a qualified Array element, result, address, or tuple and borrows known Name/Index shapes for classification. A plain Struct may embed a pure Array with a qualified child, while Analyze and Verify signature relations treat that complete array as a value with no new loan. Their module preflights still check its real physical graph and unique nominal instances before any relation or plan is accepted.

Signature relations consume each actual qualified child class at its ordered Element, Field, or Variant type path; a missing or forged row is rejected. Pure field and index updates compare full input, child and result types while retaining the existing no-target/no-loan transfer rule. The new source-project Enum clone charge runs only for an actual qualified Enum candidate, preserving the prior ordinary owning Enum budget path.

For the full value-transfer consumer, Analyze and Verify now allocate class ports by the complete `(projection path, child-local class)` pair, stopping at each qualified boundary. Constructors, reads, field/index/variant projections, and updates connect only their actual active child through the parent's exact retained row. Address projection keeps its separately proven outer borrow; a semantic child class never becomes a new root or loan. Both kernels debit each retained/path lookup and bound recursion by type depth. Pure qualified Enum and retained Record signatures use the same complete value-only physical predicate while preserving the existing borrowed Record/Tuple signature route.

The ordinary Sum resource kernels admit a fully proven pure composite as zero ownership leaves. Verify's owning Enum/tuple dispatch now checks actual Managed descendants instead of interpreting every non-Copy qualified child as owning. `pure_inline` exits before a new structural scan when the module has no nominal instances, preserving ordinary no-instance budget measurements. This change does not grant mutable-address writes of a qualified whole value; that existing unsupported path still requires its own access and class transfer proof.

Each independent header also requires a complete class contract when the actual parameter or result type contains a qualified child under Array, Address, Tuple, Record, or Enum. A raw/Wire caller cannot remove the whole contract to bypass Element or Variant rows while leaving the genuine nominal instance in place. This absence check walks the actual type with a local debit and depth limit; modules without nominal instances retain the old constant-time path.

The paid nominal inventory records only whether any actual instance has an empty slot list. The pure-value probes use this as an O(1) eligibility gate and still prove each actual physical value, retained shape, and unique instance independently. Old borrowed `Tag<'s>{p:&'s i64}` instances have real slots and never pay repeated failed pure-value probes. Direct qualified/closure class ports keep their original ordinal lookup and fees; nested composite ports use exact paid paths.

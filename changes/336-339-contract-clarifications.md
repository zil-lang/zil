# 336–339 集成前合同澄清

2026-11-04，root根据实际生产路径与非作者复核，在首次冻结和后续来源定界后明确两处责任。不是整语言或全部并发的验收。

337：Analyze构造未核CandidatePlan，不承担Verify的完整raw指令类型核验。Types保存真实引用模式；Analyze和Verify独立核来源上界，新337 Analyze还检查mutable结果的每个实际输入根具有mutable输入权限。声明上界可含未实际返回的共享输入。伪造共享输入下的mutable重借现在两侧均拒绝；伪造函数返回模式可由Analyze形成候选，但Verify及Wire重放必须独立拒绝，不能声称所有raw攻击两侧均拒绝。

339：普通地址参数和真实固定捕获槽是经过实际调用/捕获建立检查的前置条件。原对象来自Store、拥有聚合或已证明的借用返回，并不使这些前置失效；该对象仍须在整个调用、父body执行/清理到join期间存活。局部未获得这种证明的动态投影/lending路径仍Unsupported。实际同根调用实参冲突，以及从仍被指针借入的Store转移所有权给会reserve的body，均须由调用/捕获来源替换后拒绝，不能凭参数编号不同放行。源级类型Unsupported的更大Desc捕获路径不是这种安全拒绝的证明。

parent侧普通共享helper返回如果真实根仍为已支持局部，应按独立重建的根核验，而不是第二套producer语法白名单；worker可达helper的结果仍只允许标量。本次不开放worker地址返回、一般持久共享、Mutex/Atomic、异步SABI或新增schema。精确作者/独审结果另绑定交付提交，预算与旧失败保留。

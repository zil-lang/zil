# G1.3.1 finite Store field replacement

The preserved impl180 owning-write source already emits an actual exclusive Store element address and a Reserve/Commit transaction. Analyze and Verify still stop at their Store-element resource consumers. This change implements those consumers only for a direct Managed<Copy Record> field of a completely initialized borrowed element.

The existing Store borrow operation establishes canonical element layout, initialization/bounds and parent responsibility. Settlement preserves the Store prefix debt and lexical cleanup age, consumes exactly the staged RHS, and reuses the retained SSA address for old teardown followed by store. No field debt, element construction or fresh-origin privilege is created; Store pop remains Incoming. Abort retains the original element.

Ordinary Store descriptors and descriptors of an element's owning field previously shared a coarse resource root. Each kernel now retains a private parent-Store qualification on actual Store descriptors and strips it on actual element extraction and non-Store descriptor results. The original responsibility identity survives local/capture transport. A live unqualified resource description from the same Store family conflicts with replacement; different/unknown indices are deliberately conservative. Parent teardown still invalidates both kinds. This is acceptance of a previously unfinished consumer, retaining the original instance and lifetime obligations.

Public schema and normative files stay unchanged. General owning endpoints, nested/partial Store replacement and new callable envelopes remain outside this finite slice.

Implementation refinement: the private qualifier records the actual parent Store descriptor, and is stripped by the actual Store borrow instruction and by any non-Store descriptor result. Ordinary live resource descriptors with the same responsibility family then block settlement; Store carrier descriptors retain parent identity. This covers conservative helper-return transport without minting field identity from a nominal pointee name.

Explicit remaining fence: the existing ordinary callable may-write effect does not express Store field instance invalidation at the caller. This slice therefore rejects Store replacement through borrowed/captured Store parents and any ordinary Product replacement helper instantiated into a Store element. It admits an actual Store owned by this body (including a Store field in a body-owned Package), retaining its complete original parent responsibility. Existing ordinary Product helper replacement is unchanged. Completing the nonlocal caller invalidation summary is subsequent work, not claimed implemented here.

# draft11：有限同步错误和真实 TypedIR 研究

用户要求接续 draft10、推进语言下一阶段并行研究倒序图切割。恢复基线为
`7e4c4728c09fd07a55680844514e0f38bb29e708`；不回退到较早聊天中的进度。
本包由 056 共享表示与 native、057 前端/Analyze、058 独立 Verify 同批组成；
055 为独立研究。作者、非作者审核、精确候选和 no-ff 集成身份记在主树工单。

## 行为和格式

内部 schema/raw wire 从 7 升至 8，TypedModule 指纹域为 V8。新增错误联合类型
tag 16、操作 tag 44–48，以及 cleanup exit 的规范枚举编码。旧版本、非规范 bool
和非法 exit tag 拒绝。已有正式 schema.v1 交接义务没有因此完成。

在明确 E!T 上下文，原错误联合直接传递，其余值仅恰好匹配 E/T 一侧时注入；
同型歧义拒绝，载荷类型不靠猜测错误/成功分支决定。未受其他明确类型约束的整数
默认 i32；需要其他类型时使用合法类型标注。后缀 ? 要求同一错误 E，成功 T 可以不同。
这里只实现有限 Copy 载荷，不开放拥有错误载荷或未约定的 Err/Ok 新语法。

所有源函数显式生成词法存储 scope。Verify 独立重建栈、局部存储归属和汇合；
拥有 SSA 块结果可跨 scope 转交，其责任仍由全函数核验。临时槽位在 scope 入口保留，
Store 才建立责任；先求值的 give 参数/FnOnce callee 在后续实参失败前有真实持责位置。
错误结果先计算，再按本侧实际责任清理。unsafe 区域先退出，再结束其存储 scope。

LLVM 使用内联 `{i1,E,T}`，包含两侧载荷存储，非活动侧置零；投影先检查活动 tag，
Unit 或未使用结果也不免除检查。普通 main 的成功 i32 作为退出码、成功 Unit 为0、
错误为1且不自动打印；错误清理已在函数返回前完成。保留 trap 的进程终止语义，
没有从普通错误返回推导 panic unwind、取消或异步能力。

纯 CT scope 标记仍按真实 VM 指令访问计费。旧4/8步预算夹具更新为真实12/24步，
另验双查询23步仍拒绝；没有提高默认限额或改变产品门。精确拒绝测试发现旧 `3i64`
拼写先被Lex拒绝，修为合法i64绑定后才观察目标Types诊断；旧失败原样保留。

## 规范、接口与旧身份

规范15.2明确既有错误联合的唯一类型注入及同 E 传播，15.7明确 native main 的退出映射。
接口声明补全 scope-storage/SSA 边界、wire 编码和实际 ABI，不能以标签授予权限。
新规范摘要仅更新正式任务与当前生成索引。已合入055–058切片保留其精确候选中的旧
规范摘要；handoff按各自提交读取字节。研究正式性能仍绑定 draft10/schema7；schema8
只增加单独功能影子核对，不重新标记原性能样本。

统一验收 runner 仅更新范围说明，必要门、命令、固定最低执行数和产品条件均保留。
完整语言 NotSatisfied、产品门 NotRun、B0 Doing；有限同步错误闭环不等于完整语言终态。

## 研究判断

055只读抽取真实 TypedIR，比较 flat/cut/block 的 may-liveness 和完整带标记事件图，
独立 raw oracle 不共享候选抽图、位集或工作队列。真实CFG切口与资源交互宽度分别记录。
完整联合状态关系仍未求解；相同 may 集合不能证明路径相关责任等价。
冻结实验记录全部收益、退化、准备/恢复/核对成本与有界回退。预算独审发现的漏计费
在正式冻结前修正，失格预检保留，不移动旧测量身份。生产接受集合和安全核未被替换。

## schema8研究适配的集成约束

055主计时保持schema7原提交、输入和二进制身份。schema8新增的ScopeEnter/ScopeExit均保留为可观察事件；MakeErrorUnion、ErrorTag和ReadErrorUnion显式访问value，ReadErrorUnion另保留保守失败出口。独立raw审计和直接TypedIR oracle分别更新，不能调用候选操作数访问器作为预期值。真实error_cleanup四模块通过现有模块展开及check_program进入生产Analyze/Verify，再逐函数比较完整may关系与标记事件图；不扁平化源、不跳过函数、不把该功能执行当计时证据。最近反例删除错误ScopeExit事件或ReadErrorUnion失败边，必须被独立raw审计拒绝。生产求解器和接受集合不变。

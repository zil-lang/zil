# Complete local Enum replacement endpoint

The frozen 7a1fbfd4 candidate supports local whole Package and Managed address endpoints. Types recognizes an Enum address as a route root, but its endpoint matcher accepts only Managed or the finite Package profile. A whole owning Enum therefore falls back to WriteAddress and leaves old/new owning responsibility unpaid in Analyze. This is a missing producer and consumer, not evidence that the source is intrinsically unsafe.

Admit only one reconstructed complete body-owned local at an empty route. Each ordinary Enum variant has at most one direct Managed<CopyRecord> field plus inline scalar/unit fields, and at least one variant owns a resource. No parameter/helper/Store/capture, nested owning Product/Sum or partial endpoint is added. Existing public reservations snapshot the exact Enum type and settle by Commit/Abort; no schema change is required.

Unlike a projected active arm, replacing the whole root can retire whichever complete arm is actually live. Both kernels must separately prove all possible old contents complete, bind real resources and teardown entries, retain original shell cleanup age, and strongly replace tagged contents with the actual prepared RHS tree. Incoming must remain Incoming; replacing an Incoming old arm with a Created RHS may expose only the new Created leaf. A previous tag observation/old payload description cannot justify access after Commit. A multi-root may-write cannot strongly initialize every alternative. No declared arm, nominal type equality, matching layout or existing Managed may-write summary substitutes for actual root/tag/source proof.

Types must emit the real single-evaluation Reserve/Commit/Abort sequence. Analyze changes are private replacement/Sum facts and existing resource liveness; Verify is separately implemented. Machine Commit uses the existing Enum helper at the real old root, which dispatches on the actual old tag, then stores the entire prepared Enum once with actual layout/alignment. There is no recoverable operation between old cleanup and publication, no hidden allocation, and no new runtime reservation storage.

Validation uses existing aggregates and replacement components: runtime different arms and scalar values, actual Create/Give variants, pre-Commit RHS failure and staged owner cleanup, singleton/old-instance/loan neighbors, raw/Wire invalid actual tags or roots, and small Clang/API O0/O2 executions. Preserve prior original sources and exact bounds. Ordinary formal/helper ownership is deferred because it additionally requires definite-Commit versus may-write/exit-sensitive summaries and caller old-instance checks. This finite whole Enum endpoint is not all Sum, ErrorUnion or G1.3 completion.

Rust comparison: the intended gain is safe inline composition with actual independent kernels and native cleanup/value observations; no compiler speed, memory, maintenance or broad language comparison is claimed without measurement.

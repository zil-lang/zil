class0 shape, which is correct for transport layout but insufficient to check

rewrite discards the real lexical-class vectors before comparing these two
positions. This is an actual earlier ordinary-source acceptance defect;
M37 did not parse the source, and CT subvalue correction d1b7867 did not cause it.

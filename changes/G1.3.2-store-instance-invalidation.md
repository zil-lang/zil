# G1.3.2 private Store instance invalidation summaries

G1.3.1 intentionally rejects nonlocal Store parents and a Product helper instantiated into an actual Store element. The legacy resource may-write row cannot say that a particular old Managed field instance ends. This change introduces a distinct private invalidation effect in each kernel, derived only from actual verified Commit operations and propagated monotonically through ordinary calls.

At a call, ordinary Store descriptor inputs are substituted with their actual resource parent roots. Borrowed Store captures use independently reconstructed carrier roots; multiple possible Store captures may conservatively invalidate all actual parent families until a more precise private capture map is available. Live non-parent resource descriptions, including descriptions carried by closures, must be apart from each invalidated Store family. Caller responsibility/lifetime/freshness and parent cleanup age are preserved.

The ordinary Product replacement summary also retains actual destination paths. Verify will pass its independently reconstructed private target rows to the resource consumer so calls into actual StoreElement targets receive the same instance and parent checks as direct Commit; Analyze uses its own replacement route substitution. This is separate from merely forwarding ordinary write effects.

No public schema or envelope is extended. Public callable-contract helpers cannot be authorized via private new effects: actual nonlocal Store replacement in such an entry remains Unsupported. Owned capture/PackageView summary mapping remains closed where exact capture translation is not available. Original Store element shape, initialization, exclusive loans, pins, RHS staging, old-drop/store, and Abort cleanup continue to be checked by their existing independent consumers.

Validation will preserve the original G1.3.1 and G1.3/Product controls and add source-derived call/relay/Desc liveness neighbors, raw/Wire controls, both native backends O0/O2 and real exact-work boundaries. Source-level rvalue projection producer work remains separate.

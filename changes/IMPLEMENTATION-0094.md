# 094：显式 ByteBuffer 源面与泛型组合

基线 `1ec3bf43ee373c073c19f2342705924f221b8d2a`，父任务 B0；权威派工位于主树 `.task/impl/094.md`。公共规则与 ABI 只消费 `PROPOSAL-0094-0096-BYTE-STORAGE.md` 及 schema17，不增加新的能力授信通道。

## 实施范围

- 解析并保留内建 `ByteBuffer` 资源身份和七个裸原语名；普通观察为 Desc，创建与明确 give 保持 Managed 责任。
- Types 产生六条未核 Typed 指令，汇总唯一内建资源定义，封闭字段伪造、Package/capture/CT/FFI/拥有错误载荷。
- Analyze 从真实指令建立 ByteBuffer 资源生命周期、读写效果与切片来源候选；Desc 仅记录来源，不被当作地址 loan；Verify 由095独立重建。
- 泛型符号检查补数组/切片范围、索引、长度、合法可变重借和已初始化 place 赋值；未约束 T 不推断 Copy 或数值能力。
- 所有新增输入在既有限额中先计费；源码、阶段产物、命令和最近反例按实际执行保存。实例仍完整进入 Types/Analyze/Verify。

## 准入与证据

本单只运行限定测试，不跑正式全量、不自行合入。候选将交由非作者绑定精确提交审核；原生机器行为由096提供。所有失败日志保留，当前文档不是通过声明。

## 已实现的闭环

普通源码的 `ByteBuffer` 默认解析为 Desc；`bytes_new()` 与 create/give 返回得到 Managed，现有暂存、提交和清理指令继续承担唯一责任。封闭载体不开放字段，七个裸原语均不能被声明或重绑；成员名字不被保留。单模块和多模块在 Typed 函数构建完毕后，以先收费的扫描汇总唯一 `@builtin:ByteBuffer` 定义。

Analyze 记录 ByteBuffer Desc 的真实根，但不把 Desc 种成地址窗口。普通 Desc 参数产生 Parameter 根；本地载体和消费给入参数经 DescribeLocal 产生 Local 根；ByteBufferBorrow 继承实际根。普通函数返回 Address 时沿既有返回来源固定点替换参数。095 独立重建这些事实；本单没有调用或复用其求证函数。裸 Desc 返回、ByteBuffer capture/Package/聚合/error payload/CT/FFI 仍未开放。

泛型符号检查支持数组/切片索引、范围、长度、可变目标及显式重借。调用的已知引用形状允许短期重借和 `&mut` 降为共享读取；无引用约束的任意 T 仍按值消费。赋值先检查真实目标可写性，再检查 RHS；`let p: &mut T` 可修改目标而不能重绑 p。层次推断保留范围结果与字节原语的固定返回形状，故 `count(bytes_view(b))` 和跨模块 `put(tail_mut(p), value)` 进入完整生产链。该推断不授予 Copy 或地址安全。

# 034 编译期聚合值

CT闭合能力集扩展到有限纯Copy tuple/array/record及其构造、字段读取/替换、动态索引读取/替换。先由独立verify检查普通CFG和CT白名单，再解释。结果重建为普通未核Core值并重新经过types/analyze/verify；VM不输出真实地址、资源、闭包或函数指针。

逻辑live-slot预算按聚合展开的单元数预留（容器节点加字段/元素），而非把大数组当成一个常量。聚合复制与构造的执行费按展开大小计入；负索引/越界在CT返回明确错误。标量路径已有计步契约保持，正式产品成本另按既有门测量。记录/数组返回能组合进运行时源码，不把CT执行成功当类型/权限凭证。

独审反馈修正：CT聚合结果使用内部未核`Ascribed { ty, value }`表达式保留完整有限类型，尤其空数组与跨模块名义身份；此节点没有表面语法，不授类型/来源权限，types仍检查子表达式与声明一致。依赖签名在其声明模块解析后才给查询结果提供提示，模块可见性仍由正式调用检查。所有Core预算/名字/闭包/CT走访包含该节点。

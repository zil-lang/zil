# Public42 pollable-registration transport candidate

This isolated successor implements the raw fields in the independently reviewed
[G8.4.1 proposal](G8.4.1-pollable-registration.md), not its source/semantic/native
consumer admission. The limited review is retained in
`https://github.com/zil-lang/zil/blob/dd766f513bd8022e4d2c703f51a9343824150da8/docs/validation/G8.4.1-interface-review.json` and bound to proposal0e10f4a32.
It does not turn an unsafe host no-future promise into a proof bit.

Schema/Wire42 and Typed/Type/Life identity domains42 keep all prior operation,
type and synchronous role tags unchanged. CT artifact5 remains unchanged. The
production decoder still rejects every old envelope. Tests only update current
version assertions; frozen bytes are untouched, and no41-header relabelling
adapter is introduced.

Types, Analyze and Verify gain explicit refusal of unimplemented pollable
types/roles/operations; Analyse/Verify inspect unused new occurrences too. Their
actual operand visitors retain callback/head references instead of erasing them.
ClosedEnvironment and native/CT/cache helpers explicitly reject the new shape;
old synchronous Registration behavior remains its old path. Lower and LLVM do
not acquire a synchronous fallback. The old independent legacy Vec oracle only
tracks the new current identity domain; it expressly refuses new pollable cases,
whose raw identity/transport tests live in the existing Wire target.

Required successor work remains the real source producer, actual foreign-role
contracts and both independent semantic kernels, private pollable Task owner
drain/PendingExit result responsibility, stable record/trampoline, same-thread
host event queue/no-future execution and nearest failure/reentry/late-entry
cases. Explicit early finish uses a runtime guard and never frees an unclosed
record; unknown pollable Direct automatic Drop must be statically rejected,
not implemented by Pending-to-abort. Owned mutable FnMut state is eligible only
after those consumers prove its self-contained actual closure/cleanup graph;
retained shared/mutable borrowed addresses are outside this first slice.

## Publication migration

Root adds the reviewed same-thread contract at Design §12.3.1 and its explicit interface profile. The source role spellings are `async_callback_register()`, `async_callback_request_close()` and `async_callback_poll_drain()` with `static_callbacks()`/`effects(ffi)`. Fourteen formal engineering contracts receive the new normative hashes and revision only; statuses, prerequisites and Done criteria are unchanged. Generated documentation is refreshed. Historical implementation/review hashes retain their original meaning. This publishes an isolated transport interface for successor work, not feature acceptance or a merge into main.

# 226 同步共享Product捕获

基线42ce8081；父任务B0。合同见_zil_design.md §9.1.4，依赖224。先辨别普通Product来源与Store元素来源，再开放有限同步共享捕获，不能删掉Package地址检查后直接放行所有来源。默认Product只读捕获必须生成真实共享地址，显式move保持拥有语义，已有地址move不延长父寿命。

源例、raw/Wire以及实际调用场景必须同时验证活借用、最后使用、嵌套投影、父移动/替换/清理；不以ClosureId相同合并实例。若缺少来源表达或验证，记录最小阻塞和当前反例，不偷开长期窗口。保留非逃逸、Copy/Unit结果边界。

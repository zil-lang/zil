# 0066：有限具体环境 helper 的独立核验

父任务 B0；派工与状态只读主树 `.task/impl/066.md`。本提案先于实现记录新接受集合、安全边界和最近反例，公共结构以064冻结接口为准。

## 范围与独立责任

普通函数可在已核有限合同内接收一个具体环境：按值 `Closure(id)`、共享地址 `Address<Closure(id)>` 或独占地址。借入调用使用真实环境位置，不能通过 `ReadAddress` 把非Copy环境复制出来。所有环境的定义、模式、参数和结果仍独立核验。闭包返回、环境内部嵌套环境、保存/逃逸、动态擦除以及任意循环/递归调用轨迹不由本切片开放。

核验器从 raw CFG 重建有限调用轨迹、Hold 与 Cleanup，比较未经信任的声明，并把已核合同提供给公共消费者。声明本身、Analyze 候选、函数名与 `Fn` 标签都不产生权限。当前有限 Fn/FnMut 正文不允许转交拥有捕获，且借入 Desc 只支持保留资源位置的读写；重复调用的保态前置由这些实际受核操作及出口责任检查获得，不能外推到未来可失效的效果。

借入环境同时依赖环境位置和其中捕获的地址/描述。地址 Hold 与独占 loan 继承原环境的捕获依赖；资源 Desc 依赖在资源核中单独传播。借入环境不能Drop，原位置移动/销毁不能使仍有未来使用的借入或捕获失效。所有实际参数在调用进入前成功准备，任何后续失败仍由原责任核检查临时清理。

## 最近反例

- 声明零次但实际调用一次，或遗漏分支上的第二次调用。
- 删除一个实际捕获 Hold，或把借入环境声明为拥有且允许Drop。
- `ReadAddress` 读取拥有环境，按值复用已转交环境，重复消费 FnOnce。
- 借入环境尚有未来使用时移动/销毁原位置；捕获地址/Desc 尚有未来helper调用时终止其来源。
- 通过helper隐藏对共享 Fn 拥有资源字段的写入。
- 含回调调用的循环/递归不能以空合同通过；预算耗尽也不能返回部分Pass。

## 证据安排

限定 raw/wire 核验测试与最接近反例；构造输入明确为原始IR等级。真实源码和native轨迹由064/065贯通后另核，不把手工IR测试记作源面或机器证据。保存实际命令、退出状态与第一次失败；作者不跑正式全门、不自行合入。

## 已冻结的实现选择

064公共接口为schema/wire10：`TypedFunction.callable_contract`承载参数序号、具体ClosureId、请求bound、三个捕获索引集合、Owned/Borrowed与Return/Trap轨迹。请求Fn只适配actual Fn；FnMut经可写真实位置适配actual Fn/FnMut；FnOnce按值消费actual Fn/FnMut/FnOnce，ABI与剩余清理由064实施。本片源码FnMut helper使用`&mut F`，不因bound隐式使按值参数可写。

其他helper参数限finiteCopy、Managed或完整Package，结果限finiteCopy；额外Desc/Address参数显式拒绝，普通非helper历史签名能力保留。该限制使新callback合同不依赖未公开的额外借入效果。它仍不是完整分离编译、动态擦除或一般高阶效果系统。

`hold`是全部Address捕获，`call`是全部Desc/Address捕获，`writes`保守枚举Desc及mutable Address捕获，是能力上界而非实际写次数；消费者据此可能安全拒绝一个实际上只读的Desc callback。Return包含Copy错误联合的任意标签，合同不声称标签敏感；实际错误CFG的早停与清理另行核验。

核验使用有界拓扑工作队列与合并后的调用前缀集合，拒绝可达CFG环、参数转发和每路径超过两调；不同分支的相同调用前缀合并，不枚举重复路径。候选元数据在指纹计算前扣费与限形。callback所带的目标窗口在普通Call参数比较时逐一展开，环境位置独占不把其共享捕获误提升为独占。参数清理仍由独立责任核与storage核交叉检查，轨迹声明不替代实际债务结清。

## 独审提出的公共调用隔离修正（实施前记录）

root独审指出：公共callback分支之后仍迭代helper的旧私有效果表，即便跳过callback行，也留下无必要的正文读取和收费。现已明确额外参数只有finiteCopy、Managed和完整Package，且结果finiteCopy；这些额外参数不携带借入来源，转交前的活性与责任核覆盖旧来源，helper内对其拥有参数取Desc产生的是本地根。因此公共helper Call可完整跳过旧私有效果分支；普通非helper函数保留原路径。helper定义本身仍由完整模块核验，不能跳过其正文检查。

最近反例改为调用点独立转移：先对完整raw/wire模块获得VerifiedModule，再删除全部私有效果行或向helper行放入伪造参数索引，调用点的非空公开写上界、零次调用空效果及实际工作收费均不得变化。该测试不将伪造表当作模块核验输入或权限，也不声称整个模块的成本与helper正文无关。Analyze同时将获取私有表和遍历移入非helper分支。旧23432f2/9c53293收据保持原身份，修正后另测另记。

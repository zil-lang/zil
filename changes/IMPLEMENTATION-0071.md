## 假设与对照

067 的位置编码节约坐标，但完整关系像的临时 BDD、变量耦合和 GC 成本回归。
本轮分别检验：①每个 token 的保守位置可达域是否减少无效坐标和公式；
②对实际完整联合态执行同步赋值是否免去昂贵的前后态关系乘积。

固定五组：`dense:fused:owner:gc`、`location:fused:owner:gc`、
`local:fused:owner:gc`、`location:direct:owner:gc`、`local:direct:owner:gc`。
首两组为保守基线；后面构成域/引擎的二因素对照。不将直接行集合称为 MDD，
不把物理类比或已知有限状态算法称为新定理。是否有净收益由完整成本决定。

## 局部域的正确性义务

从原始 TypedIR 的参数/环境/制造点为每个身份建立种子位置，加入 Store、Take、
拥有捕获和 give 返回可能发生的搬移边；忽略 guards 得到过近似的有向闭包。
只删去不在闭包内的 token/owner 组合，不合并不同身份，不以边缘集替代联合态。
归纳基：初始 token 均在种子位置；归纳步：正常事件只保持、退休、制造或沿已登记边搬移，
因此闭包包含每个正常后态的位置。带多个 token 的同一闭包载体不违反唯一位置。
实现对初始行/解码/独立 oracle 编码以及每个正常像检查域和唯一性；域外正常写入
必须 `Mismatch`，不能暗中滤掉该行。故障/abort 在原始完整前态记录，重复实参/捕获
的出现次数在任何集合化前观察。

## 独立性与有限合同

保留067独立 raw oracle，不调用其抽取、解释、转移或固定点实现。
候选共用自己的事件公式编译器：BDD 引擎构造等式并关系像；direct 引擎仅对完整
输入行求前态谓词/RHS，在同一个前态上求所有赋值，展开 free 位并精确去重。
两引擎输出所有 point/exit/fault/abort/unsupported 联合关系、原始标签和独立 schema，
逐行比较并比较完整规范字节，不只核对摘要、may 集合或安全布尔值。

沿用每函数100M抽象工作预算、300k BDD槽、600k缓存、100k完整关系行、4096语义位、
20k点，以及 schema10有限 Bool/整数/枚举/单活跃分配点合同。直接引擎的逐行访问、
比较/复制/去重收费不同于 BDD 节点收费；相同数值不意味着同CPU工作，不以 work比
宣称时间收益。超限/Unsupported/多活跃 incarnation 分开记账，不记 Pass。

# Original host/member CT source classes

The source class checker currently recovers only free calls. A CT call through
an original generic host and member therefore yields Unknown before comparison
with a qualified source annotation, and rejects the two real `Pair` examples.
Resolve the actual `Host::<...>.member::<...>()` AST against the source record
and its owned member in the existing inventory. Map host and member full
ordinals in separate declaration domains, then substitute those facts into
the member's declared result. A same-spelled lifetime in the member shadows
the host binder only within the member declaration; the caller's actuals are
resolved in its own scope. Wrong kind, missing actuals, or absent source owner
remain rejected. This relation is only for annotation compatibility; it does
not authorize CT origin, borrow, access or machine behavior.
Const host/member actuals remain explicitly rejected in this source class
adapter until their declared domain and original source binder can be checked.

The recursive free CT result exposed the same missing full ordinal map on a
free call: `forward::<37,'s,i32>` returned a qualified `Nested` while the
source fact collector zipped only non-life formals against the full actual
list. For an explicit full application, check each original formal/actual kind
in order, bind Type to the source type fact and Life to the caller's actual
lexical binder; check Const against the declared scalar domain or the actual
source const binder. The existing short all-Type profile retains its earlier
path. CT and later type consumers independently verify the physical value.

The unrelated all-Type Copy path first attempts its unchanged ordinary key.
Only the existing scoped-relation rejection can enter the source class proof;
resource-limit and other diagnostics remain final.

The proposed finite acceptance broadens only the result of the existing Direct, noncapturing, single mutable Package-input helper. The result may be an ordinary finite Copy tree: scalar/Unit, Tuple, fixed Array, Record, Copy Enum and ErrorUnion recursively containing these same nodes. Address, Desc, Managed/Package, closure, function pointer and foreign carrier results are excluded. The Package/input/RHS-parameter profile remains unchanged.

Verify reconstructs actual reserve tickets, endpoint authority and Commit/Abort activations independently. On a failed RHS, Abort settles the ticket without consuming or overwriting the old destination; resources acquired during argument preparation retain their real cleanup responsibility. On success, Commit independently consumes exactly the prepared complete RHS, retires the old instance and retains the caller shell/cleanup age. The existing current-CFG ticket, resource and retirement/source-pair checks remain mandatory.

A returned error does not imply no write: the helper may Commit and then return an error. New non-Unit helpers therefore use conservative may-origin/retirement rows on every ordinary return, and cannot enter G1.3.7's Unit-only must-Commit/Fresh lane. Mere Commit presence or may-write rows grant no new Fresh authority. Ordinary caller reborrow/read remains supported without a Fresh proof.

The Unit result retains its constant-time previous qualification path and the accepted Unit must bounds. Only a non-Unit result triggers the paid structural return traversal, with pending-work growth prepaid. No new public IR/schema, ABI, runtime ownership mechanism, Cargo target, default budget or Analyze/types proof dependency is introduced. Real Source/raw/Wire/native and exact-budget evidence will be recorded at their actual stage and production identity; this proposal is not acceptance.

# Produce closure contexts at the actual Engine node

The existing closure guard rejects retained nominal annotations because Core lacks the creator's genuine enclosing class scope. This producer records that scope while Engine processes the actual closure and transports it through a request-local syntax marker. CoreLower will consume the same ledger after minting the real outer CoreExpr id. Parser/raw markers and declaration/type spelling do not authorize context.

Only original life-only free-function Definitions and shared qualified creator-input captures are proposed initially. The original ordered generic vector, declaration source identity and actual header occurrence-to-binder inverse are retained. Closure P/R is an unverified StorageLifeContract proposal; named Fixed entries point to full creator generic ordinals. Runtime parameter/address/class anchors contain no guessed capture slot. Actual Types/Analyze and independent Verify still establish capture, Fixed and access facts.

Normal lexical bindings carry input origin alongside their type. Clones retain that binding; a local/pattern/closure-parameter binding clears it. This preserves same-name same-type shadowing without matching source spans or assuming two visitors run in the same order. Cloning after context production is not a second production; duplicate or orphan markers fail reconciliation.

The private stored-contract helper retains its already constructed inverse vectors instead of guessing them from a generated qualified type. Existing callers discard them and retain their original fee path. New producer snapshots, lookups and rows are prepaid. Missing scope, unsupported creator transformations and unresolved anchors remain closed. No public wire/runtime metadata, default limit or normative rule changes here.

The complete initial implementation carries only a raw Core context. Root's actual lowering events bind its creator and newly minted outer expression; no Typed source identity table or Wire43 is published. Types must form the joint Parameter/Capture/Result contract from the real source header and real captures, and both kernels retain their independent existing contract/environment checks.

Original declaration identity is insufficient for original closure sites. Driver's independently recorded closure_sites state must be Original; a new-path paid scan also excludes CT rewrite capability in the actual creator for direct Expand. This scan does not assign occurrence identity or match two walks. The first input profile is direct shared qualified input storage with shared direct slots; local qualified aliases/shadows, nested retained-carrier inputs, nested/generated/member/mixed creators and non-scalar creator results are not opened. Unnamed outer header borrows are preserved as None, distinct from declared generic ordinals. MAX is reserved for absent syntax transport; production rejects that occurrence before publication.

# Complete callable relations and authenticated CT ambient context

Runtime39 stores nested nominal classes but its flat borrowed-function-pointer
relation cannot express `for<a,b> fn(&'a Tag<'b>, &'b i32)`. CT4 also cannot carry
the source distinction between independently extracted locally Fixed0 types.
The exact successor model is in
`changes/proposals/terminal40-callable-life/model.rs`, with the contextual-key
inputs in the adjacent `contract.md` and `frozen-context.md`. Those files propose
the representation; the corresponding current rules are in `_zil_design.md`.

The integrator publishes runtime/Wire40 and CT5 on an isolated source branch.
This is not executable admission. Signature class rows are separate from
borrowed access positions; all callable forms use one rich relation. CT graph
owner references and authentic ambient source scope references remain disjoint.
Structural transport hashes cannot substitute for contextual semantic identity.
Every changed byte layout has a fresh domain; historical bytes stay frozen.

Migration ownership: 341 Expand/source declarations; 340 and root Types/callable
consumers; 342 independent Analyze/Verify and stored classes; 344 CT compiler,
independent CT verification, VM and genuine frozen context; 343 Lower/LLVM and
Task integration. Root owns the shared schema, current tasks, interface/cache
integration and full checks; Astra independently reviews the actual candidates.
Each old consumer must either implement the complete relation or explicitly
reject unsupported nonempty metadata, with prepayment from the same request.
No schema-only success upgrades B0, terminal language, platform or product gates.

Controls retain the existing original View and phantom sources, full rich
same/different class relations, role-specific contracts, exact ambient binder
and full ordinal identity, relocation, context rejection and N/N−1/fresh budgets.
Source, independent kernels, transport and native behavior are reported at their
actual layer. Existing failures remain recorded until a verified successor fixes
them. Default budgets, dependency rules and the native/Rust comparison gates do
not change.

# Complete nominal actuals in Copy qualification

The CT6 ambient Type consumer returns `Wrap<Phantom<'s,i32,42>>` into ordinary
source. Copy qualification must resolve the real nominal declaration and its
complete ordered Type/Const/Life arguments, then inspect the substituted
physical fields. Existing structural Copy bounds still constrain phantom Type
parameters. Lifetime metadata itself grants no storage, address permission or
Copy eligibility to a physical address/Managed/Package field.

The present source checker assumes every aggregate/enum actual is a Type;
normalized instance names must also resolve through actual declaration
metadata rather than spelling heuristics. Correct these consumers while keeping
the existing all-Type path and its fees where unchanged. New kind/domain,
substitution, traversal and copy work is prepaid in the request budget.

Validate the original CT6 complete Type consumer, a genuine const-sized field,
enum payloads and nearest wrong-kind/domain/physical-borrow/phantom-bound
negatives. A CT-only scalar reduction is not a substitute for the original
Type materialization and runtime consumer. No default budget or public schema
change is proposed.


Copy eligibility alone is insufficient: an outer nominal whose Type actual
contains a qualified nominal must publish its own complete LifeNominalInstance.
The source application retains the child's actual lexical class vector before
normalization. TypeArgument paths carry each real child declaration/full
ordinal into the outer canonical class domain. Physical nested qualified fields
map classes once through retained bindings. Ambiguous source mappings remain
rejected; physical instance names never reconstruct a caller's lifetime.
The original CT consumer must pass both native observations and direct
inspection/reverification of its published semantic inventory. Compound Type
actuals without an implemented complete mapping remain explicitly rejected.

Physical fields select their qualified Type actual by the original generic formal occurrence and complete ordinal before substitution. Equal physical child names never merge caller class mappings belonging to distinct Type formals; the substituted field must still match the selected actual. Grouped and tuple field occurrences preserve their original structural correspondence.

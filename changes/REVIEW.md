## 2. 最终选择及理由

| 主题 | 选择 | 原因与边界 |
|---|---|---|
| 闭包捕获 | 正文用途推导；move显式按值 | 避免要求用户重写编译器能局部得出的捕获清单；逃逸失败不反向改变模式 |
| Copy | 普通闭包默认只读借入；move拍快照 | 保留“观察原变量”与“固定值”的区别，避免默认偷偷记旧值 |
| Desc | 继续复制描述 | 不将ZIL图操作重新变为默认长地址借用；访问进入Call合同 |
| Managed | move实际载体或正文give推导转交 | 复制alias不夺取owner，close不等于give；责任在创建时落实 |
| 调用能力 | 环境访问与目标状态分开 | 拥有捕获可重复只读；外部close仍可能因状态阻止二次调用 |
| 接收者 | impl Type(self:...)、显式覆盖、trait继承 | 节省重复首参，又在读正文前确定合同；保持普通关联函数内核 |
| .name | 词法self成员 | 不引入运行时this、不复用作enum标签或管道占位 |
| 函数值 | fn指针无环境；Fn族具体闭包；受限opaque返回 | 补齐捕获闭包跨函数接口，避免默认Box或擦除依赖 |
| 记录 | 期望类型省略；单base首位spread | 不引入结构类型搜索；Copy/Move及失败清理可确定 |
| 管道 | 左先右后，一元调用 | 不通过插参、柯里化、传播错误改变原调用的含义 |
| 脚本 | Native统一main/run；托管扩展单独协议 | 当前施工不承担隐含GC，未来桥接也不能绕过原生责任 |

保留 `->` 作为返回类型标记，支持 `=>` 表达式体；不导入讨论示例中偶见的冒号返回同义拼写。箭头后裸大括号固定为块；函数指针箭头取得完整返回类型；方法名与字段名冲突、普通调用Fn选择、Address捕获截断都已明确，避免实现者按各自直觉补完。

# 163 公共资源方法的导出入口

集成者负责 `source_exports` 的公共入口变更。已有导出规则同时要求名义拥有者公开和方法自身公开（普通 trait 则要求 trait 公开），但拥有者集合只收录 struct，造成公开 resource/package 的合法方法无法跨模块调用。

将集合扩展为全部公开 Aggregate，保持其余筛选不变：私有拥有者、私有 inherent 方法不导出；内建 Drop 未进入公开 trait 集，清理入口仍不能作为普通调用/函数值。ByteBuffer 并无用户名义声明，因此不借此获得跨模块扩展方法搜索。

这扩大源面支持范围，复用现有直接函数 ABI 与独立 Verify，不改语义、schema、默认预算或产品门。163 实施者需独立审查这一集成者改动，并从真实跨模块调用核验公开资源/包方法、私有拒绝和 Drop 隐藏；源面正确接受不替代原生清理验证。

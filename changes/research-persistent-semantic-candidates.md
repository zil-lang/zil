# 显式可信本地语义候选缓存

用户要求继续补齐跨进程重复前端工作。新增可选 CompileOptions.semantic_cache / --semantic-cache，默认关闭；原 --cache-dir 仍只保存原始源码 bytes。只适用于 project/compile_path、stop_after 至少 Verify、无 emit_dir 与原 cache_dir 的请求；其他路径原样执行，不隐式降级产物合同。

语义目录由用户明确指定为可信本地构建输入，安全边界与已有对象缓存一致。SHA只检测损坏和身份，不证明不可信写入者的来源/源码对应关系；不得用于未经认证的共享或远端缓存。保存原始 TypedProgram，绝不保存 Verified。缓存键绑定完整源图字节/路径/ID、规则版本、全部 Limits、target、显式 build_inputs 及当前编译器可执行文件身份。动态加载器插入时关闭缓存。

编译器身份复用对象缓存已有 installed_identity：GNU ELF build-id 与当前文件身份/时间/大小组合，无 build-id 时全文SHA回退。沿用已安装工具在进程运行期间不可变的合同；不把build-id作为恶意替换工具的真实性证明。每次CLI的真实身份开销计入完整时间。

私有格式封装现有 Wire 原始 TypedModule（空候选）及完整程序映射。接口的 module、原导出名称、函数ID、参数/结果传递模式、两个原始指纹和 root_functions 均保存。参数/结果 Type 从原始模块对应函数读取，但编码先逐项检查与原 TypedProgram 类型完全相等；不满足则跳过缓存。因此该格式对可编码输入是无损 roundtrip，不丢失跨模块合同或名义类型。所有已核接口字段必须为空；读取后仍为空，由当前 Verify 与 contracts::publish 重新生成。

只保存完整请求成功的前端快照。恢复仍执行当前 Analyze 与独立 Program Verify、入口/接口检查及所有后端/产物检查。原成功前端在完全相同源/目标/每项预算下复用；任何额度变化都miss并走原费用路径。缓存解码/编码使用当前 Wire 和字节/节点上限，超限不扩大接受集而是跳过优化。

损坏、截断、未知格式和不匹配按miss重算。输出规划在任何缓存写入前保护缓存文件与所有源码/输出的路径、符号链接和硬链接身份；原子临时写后发布，取消和失败请求不发布。成功产物完成后的可选缓存写入失败不回滚已完成构建或掩盖原诊断。

解码后的候选若当前 Analyze/Verify 拒绝，清除本次导入查询并重新从源运行，保留实际事件和核验次数（一次拒绝Verify再fresh成功应报告2次）；取消不重试。独立Verify已成功之后的接口、Lower、后端、链接或产物失败按原路径返回，不重跑外部动作。接口类型复制在每次clone前扣完整结构节点及驻留表示/名义与字段字符串字节，编码使用同一上界，超界只放弃缓存资格。

必须验证新Session/新进程命中、真实多模块完整接口roundtrip、源/目标/limits/build_inputs变化、损坏恢复、错误/取消不发、源/输出别名保护，正常冷构建与有效候选命中每次Verify计数为1；候选拒绝后恢复按真实尝试次数报告，不把故障恢复控制混入普通性能请求。完整CLI时间计入编译器身份、文件读取/哈希/解码/序列化/发布，不能只计省略前端的阶段时间。

# 035 用户泛型枚举

将既有普通泛型展开接入有限 Copy enum：类型实例使用卫生名称与既有预算/缓存，构造支持既有 `Option::<i64>.Some(value)` 及唯一的期望类型/载荷约束；无载荷构造不能凭名字猜类型。match 从已知 scrutinee 实例正规化构造路径并提供 payload 局部类型。普通泛型工厂和泛型匹配在定义期检查，不从具体实例授予未知 T 的 Copy/数值能力。

未实例化 enum 模板也检查参数、变体、属性与字段类型形状；实例克隆、替换和 key 构造仍先预检预算。产物继续进入普通 types/analyze/verify 与既有 tag+maxpayload 机器表示；不新增内置 Option/Result、问号语法、公共 IR 或 ABI。

实现细化：由返回/绑定/参数/聚合字段上下文与先前实参逐项产生约束；显式与推导路径使用同一规范化实例 key。数组类型参数使用定长字面量的结构 key。泛型 match 的有用性矩阵在复制或列展开前计费；模式局部变量使用定义身份追踪移动，遮蔽同名变量不能清除旧身份的移动。

当前范围仍是单模块有限 Copy 载荷，tuple/unit 变体；泛型 bounds/where、借入或资源载荷、record 变体以及跨模块导出模板不在本片中。所有限制明确拒绝，不授予未知 T 的 Copy 或数值能力。

# G9.3.1 backend static UTF8 consumer

Base: `967e6e74a546acf21f18acd24e91ce8318361344`, parent G9.3.1 / G9.3.
The shared schema43 contract supplies `StaticUtf8 { bytes }`, immutable
`Address<Slice<U8>>`, and independently verified static origin.

The common structured LLVM producer will emit private immutable exact byte
arrays and the existing `{ ptr, i64 }` slice. Empty arrays retain a static
symbol and length zero; UTF8 and embedded NUL retain exact byte counts. Neither
terminators nor hidden allocation are introduced. Both textual and LLVM API
consumers use this same machine model. Existing symbol-reference CGU partition
and complete machine-input cache hashing must retain and distinguish these
globals. Runtime static storage is explicitly forbidden in the CT VM.

Lowering and codegen must prepay actual static-byte copying/comparison and
machine-data materialization from their current request budgets. Existing
scalar/slice paths should avoid an additional whole-function inventory pass.
Focused tests extend existing targets; no Cargo/schema/gates or default budget
changes, and no formal full-suite execution by this implementation agent.

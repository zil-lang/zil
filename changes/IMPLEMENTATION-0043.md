# 043 跨模块公共类型与普通模板

## 变更提案（先于实现）

依据 `_zil_design.md` §14、§15.1、§15.4 和 §16.2；正式父任务仍为 B0。
本片把已有有限 Copy 类型/普通模板的同模块能力接入显式项目导入。
公开函数、记录、枚举、普通泛型函数/记录/枚举及非泛型透明别名可跨模块消费。
泛型别名、一般 bounds/trait、资源布局和泛型方法继续由原有 Unsupported 边界拒绝。

项目名称归一先依据已解析 ModuleId、声明可见性及词法绑定，把源名字换成卫生内部名；
整个项目只运行一份有界别名/模板引擎，再把每个实例放回模板的定义模块。
普通函数导出名和原有 CoreProgram 模块/函数身份不变；导入别名不会制造新名义类型。
每个实例仍完整进入 Core、types、analyze、verify、LIR、LLVM 和 native 路径。

公共 Core 的唯一新增字段为 `CoreField.public`，只保存源声明的字段可见性。
声明模块来自现有 ProgramModule；不增加可执行权限，不改变 Typed 记录字段布局。
类型阶段按真实声明身份和实际字段索引检查字段读、投影和写，源展开按真实声明检查构造：定义模块可操作私有字段，
外部模块可传递含私有字段的值，但私有字段访问/构造拒绝。
项目形状准备共享声明索引，仍依据声明所属模块生成名义身份，不能按同名或同尺寸合并。

所有源模板（包括未实例化模板）、别名链/环、写出的类型实参、来源跨度和累计工作均受现有限额约束。
不放宽预算；预算不足停止且不产生新 executable，不把 Unsupported/ResourceLimit 记为语言通过。
名称隐私拒绝在第一次需要导入声明的阶段报告；普通非泛型私有函数保留既有后续诊断路径。

## 最近反例与限定验证计划

- 公共 Option/Result/泛型容器函数经两个消费模块组合，O0/O2 与 Rust 行为对照一致。
- 显式/推断调用、泛型模式、公开别名、别名转导入、两导入名指向同一 ModuleId。
- 不同模块同名记录/枚举及不同泛型实参不可混用。
- 私有模板/类型/别名、私有字段读/写/借入/构造拒绝；含私有字段的公开值可传递。
- 未使用的非法模板和别名环仍拒绝；实例/节点/步骤预算耗尽不产生 executable。
- 检查真实 Core/Typed/LIR/LLVM，保留实例定义来源和函数导出边界。

## 交付结果

三模块样例 `examples/impl043/main.zil` 从公共模块取得 `Option<T>`、`Result<E,T>`、
`Row<T>` 和普通别名，处理模块保留定义身份，根模块通过推断调用和别名模式得到
`5000000042`。样例包含编译期创建私有字段公开值，再通过公开字段和定义模块getter消费。
同目录 `oracle.rs` 为独立 Rust 行为对照；O0/O2、实际阶段产物和命令收据在本片证据中。

`impl043` 限定测试覆盖两导入名共享身份、不同模块同名类型拒绝、定义模块私有helper、
名称遮蔽、未用坏模板/别名、累计预算和私有字段的普通/闭包/薄函数/CT路径。
CT重化已有合法值是复制，不是用户重新构造；源构造隐私必须先在展开处判断，
不能把重化的 `MakeAggregate` 当成用户访问私有字段，也不能放行源CT构造或私有查询。
通用模板中明确声明的私有字段引用在符号检查时拒绝，包括尚未实例化的定义。

旧 `mainline/app` 的 Dataset/values/checksum 原为私有却由根模块直接读取；新规则正确拒绝，
集成者负责把确实公开的数据声明显式标为pub。本分支不跨写集改旧样例。

仍未实现跨模块省略字段所需的默认值helper发布，调用时明确Unsupported；
显式完整构造、含私有字段公开值传递、同模块默认值保持实际机器链。
泛型别名、一般约束、泛型方法、资源和完整包体系仍未宣称完成。
本片不修改正式门，不更新公共schema版本；集成者同批发布结构版本。

## Rust 四目标与突破

| 目标 | 判断、证据与差距 |
|---|---|
| 同类安全 | 仍为部分子集。新增声明隐私、模板定义作用域、名义身份及CT/闭包反例；每个实例仍经普通类型和独立verify。完整资源/清理/并发安全未完成。 |
| 运行与内存 | 同级未证明。真实ZIL/Rust样例在O0/O2核对完整i64结果；名称与别名归一没有加入运行时字典、Box/RC或锁。未测配对时间、RSS和尾延迟。 |
| 表达与维护 | 模块组合已推进：业务方直接导入共享Option/Result/容器和别名，无须重复定义。整个任务演进优势仍待产品场景比较。 |
| 编译成本 | 更低未证明。一个项目使用一次有限模板引擎，同一声明与实参复用实例；所有新增索引与复制受现有预算约束。没有冷/增量计时数据。 |
| 至少一项突破 | 尚未证明。本片交付真实组合能力与反例，不以测试数量或更短写法代替产品结论。 |

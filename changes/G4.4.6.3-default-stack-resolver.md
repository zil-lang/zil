# 默认 2 MiB 栈的 Types resolver 帧隔离

root 默认 workspace 扫描在 `large_copy_enum_error_default_stack_api_reliability` 的 `frontend` 子进程真实 abort。该分支只到 Parse/Core/Types/Analyze/Verify 并包含原 depth48/projection48，不调用 Lower/LLVM。已链接 Types archive 中 `aggregates::Resolver::ty` 的 x64 prolog 为 `0xa000+0xb08=43784` 字节/层；48 层本身即2101632字节，大于默认2MiB，新增名义 Enum/qualified 临时量被所有普通 Array 递归层携带。

本片把 `Type::Named` 的实际名义声明/Enum/cache 大分支原样隔离到 `#[inline(never)]` helper，保留公共 ty 的实际 charge、precheck、分派和各字段解析先后。helper 不增加语义预算收费，不重排 cache/active 状态、校验或诊断。数组递归无需携带该无关分支临时帧；不加线程栈、RUST_MIN_STACK、堆盒、预算或深度豁免，不放宽原测试。

验证仍用原默认栈 isolated frontend 与 O0/O2/API 子进程家族；先 -j1 no-link，root 唯一重窗再执行，实际命令和结果分级记录。target object 的帧大小是静态辅助证据，不替代原 Source/default-thread 执行。原 ordinary/qualified 名义、错误顺序和精确预算由原限定 source/raw/Wire 控制回归。

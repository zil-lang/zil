# Bounded derived objects from a full current-compatible base

Stage11 baseline21ecc60ff (production8cf48baf2). Two missed retained-symbol units each cost180–205ms despite a small changed definition set. Splitting only callers cannot remove the remaining large leaf unit from the critical path. Test a bounded object-level work product, preserving requested CGUs, O2, canonical symbols and current source/machine validation.

Admission is explicit incremental O2, Linux LLVM API and the existing trusted object cache, with installed GNU objcopy and sibling ld.lld available and both exact installed identities bound into the cache namespace. Other configurations use the original path. Only ordinary externally linked scalar functions and unchanged declarations/signatures/order are eligible; global data, named types, local/imported definitions, address-taking and indirect calls reject the candidate. Current complete model preflight still runs before consuming a base. A full object hit retains its existing checks.

After successful publication, a private bounded record may identify a previously fully compiled object, per-function current machine fingerprints and direct definition references. On a full key miss, compare with that base; take the reverse closure of changed definitions over old and new references. Patch at most16 definitions with at most4096 machine work, also a small fraction of the unit. Reject outgoing source-definition dependencies outside the patch so normal O2 retains the relevant optimization context. Signature/target/declaration/tool changes, malformed records, missing/corrupt base or an oversized closure fall back to full compilation. Candidate records confer no Verify authority.

Keep all old code: GNU objcopy renames and localizes the old patch symbols to collision-free private names, preserving LLVM-generated merging thunks and their references to the old implementations. Independently compile the current patch module with the original O2 policy, current preflight and LLVM before/after verification. Fixed-identity ld.lld -r combines these into one current relocatable object. Record every actual subprocess. Partial/failing derivations are discarded and may fall back; they never publish a cache candidate or executable on their own.

Always derive from a full base, not a derived-object chain. The ordinary exact current object cache can retain the successful combined object; only successful full native compilation updates the base record. Bound input/metadata/output bytes. All publication/cancellation checks and trusted-directory rules remain. Optional metadata failure must not fail an otherwise valid compile.

Independent review identified a concurrent same-action-key replacement: a delayed derived result can overwrite full object bytes after the full-base record is published. Bind the record to the exact full-object content digest as well as its action key; a mismatch rejects derivation. A bounded read-only ELF64 symbol check additionally requires the exact canonical global definition set, rejects weak/extra globals and private patch symbols in a full base, and checks that every retired replacement is a unique local function after objcopy and after ld.lld. Unknown shapes fall back; this checker never rewrites ELF.

Controls must cover body edits and restoration, optimizer-generated old thunks, native-entry reverse dependencies, function-address/resource/indirect fallback, stale/corrupt cache metadata, current source rejection, cancellation, and actual exported behavior. Inspect symbols, output size and real native results; old private code retention and changed local merging mean exact full-file equality or universal runtime quality cannot be presumed. This is a ZIL experiment, not a claimed Rust implementation. No public Wire/Cargo.lock, language budget, default optimization or product gate change.

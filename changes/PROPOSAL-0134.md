# 134 跨模块公开记录默认字段

规范15.5已经规定默认值按定义域与声明顺序执行；当前实现却对不同源文件直接Unsupported。本片把公开普通struct的公开非manages默认字段降低为定义模块内的普通零参数函数；构造处通过生成的精确导入调用。没有将默认表达式复制进调用者作用域，不授予隐私或安全例外。

名称由名义身份和字段名确定且使用源码不可拼写的前缀。公开helper与普通函数一样经过Types/Analyze/Verify，字段隐私检查不变，Self与私有函数仍按定义模块解析。显式字段先按书写顺序求值，遗漏默认值再按声明顺序求值；spread更新不会重跑默认值。显式覆盖也不阻止公开默认声明本身被检查：这是新增能力的接受性变化，不能继承旧的未使用坏默认表达式被放过的行为。

暂不开放泛型默认值（仍要求符号检查）、package/manages或resource的跨模块默认值。无schema/wire、LLVM ABI、隐式分配、RC或权限规则变化。映射和生成源码节点受原预算控制，低额度必须ResourceLimit且会话可恢复。

必要测试：三模块真实默认副作用顺序、定义域同名遮蔽、Self、重复构造与spread不重复、泛型默认值的原有拒绝边界、私有字段/函数拒绝、坏默认、预算边界。测试既走普通Verify，也做原生O0/O2。当前会话自查不冒充独立审核；集成依照用户本轮直接main授权。

# 040 无捕获闭包转为真实薄函数指针

实现设计294与CL13：已有 `fn(A)->R` 上下文可以为无捕获闭包推导参数和结果。上下文沿函数参数/返回、绑定、赋值、记录、数组、tuple和条件分支传递；类型仍由普通检查与独立verify重新核验。有任何词法捕获均报 `E-CAPTURED-FN-POINTER`，不隐式装箱。

实际生成普通 `TypedFunction { environment: None }`，使用既有 FunctionRef/CallIndirect；不修改IR、后端或独立verify的环境拒绝规则，不添加trampoline。捕获分析结束后，把需要转换的最新Pending从闭包表移入独立无环境生成函数槽。ClosureId继续稠密；所有生成FunctionId共享同一计数和函数预算，最终按ID归位，避免与普通闭包入口冲突。函数体仍通过Builder完整检查与计费。

源约束图只提供未核类型上下文，既有带环境闭包保持具体闭包类型。嵌套的显式fn函数字面量只收集已知签名，之后在实际创建位置检查其完整函数体与捕获；不能以预推导结果绕过普通检查。预算仍覆盖源AST、签名展开、生成函数和CFG尺寸。

本片不增加借入返回的间接合同、不扩资源/Box/dyn/general callable escaping，不声称Rust整体目标已完成。作者限定测试须覆盖CL13/CL14、各上下文、Unit ABI、真实普通入口、ID混排、捕获近邻和预算；集成方运行正式总门。

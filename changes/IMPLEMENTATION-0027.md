# 027 编译期函数与控制流

本片按 ZIL-COMPTIME 的既有 `#(expr)` 规则实施，不引入裸 `#call` 或新语法。driver 按查询的静态可达调用图收集函数，使用现有类型/CFG 构建和候选分析；结果是普通未核 CtProgram。独立 verify 先检查预算与纯标量操作白名单，再运行既有 CFG/类型/初始化/来源核验，才能创建不可伪造的 VerifiedCTProgram。VM 只解释这个对象，没有宿主函数、文件、网络或运行资源入口。

VM 复用既有标量算术语义，并执行局部变量、条件/短路、循环、直接调用和递归。每条指令和每次终结边均计一步；调用深度与同时存活值槽另有限制。全模块/全项目扣除实际步骤，耗尽为 ResourceLimit，不回退运行时。原闭合线性算术保留原计费合同；新控制流查询使用实际执行路径计费。表达式中的运行期变量不能因为与某个函数同名就误解析为编译期函数。

CtProgram 包含 TypedModule、CandidatePlan、无参数入口与声明预算；raw wire 只保存候选，重读必须重新独立核验。普通 CFG 的未来新操作不自动得到 CT 资格，必须显式扩展纯操作白名单和 VM。

本片暂限 Unit/bool/i32/i64，不覆盖 Type/Syntax、反射、生成、运行地址、资源及动态调用。范围是实现边界，不改变终态规范。

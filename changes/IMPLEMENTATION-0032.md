# 032 共享投影和借入接收者

有限纯Copy聚合支持共享字段/元组/数组元素地址和共享地址再借入：`&p.field`、`&a[i]`、`&*r`。地址投影仅缩小机器读取位置，Hold仍保守携带完整来源根；不能据此声称两个字段具有独立写资格。动态数组索引在形成读取地址之前检查非负和上界，失败执行trap。

`&Self`接收者按已知声明对可借入位置自动共享借入一次；字段/索引对共享地址自动解引用一层。创建借入并不改选方法、插入clone或装箱。需要临时对象存储的非place方法接收者在其临时生存期规则实现之前保持Unsupported。新增原始IR AddressField/AddressIndex及wire标签23/24，由verify独立核索引、类型和根。CT纯执行白名单不自动放开真实地址。

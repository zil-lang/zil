# G4.4.5.4 B recursive context relocation

Root 授权将当前只允许完全相同 field CtTy 的 Source-authenticated record copy
扩为有限 ordinary pure value 的成对递归重构。该动作保留两个真实 schema 和
完整 scope/actual 参数目录，不使两个 schema 全局相等，也不赋予新权限。

Producer 对 scalar、tuple、array、UserPure record/enum 逐层核真实形状、nominal
身份、完整参数图及最终原来源 lifetime endpoint。需要变更 schema 的字段发出
真实 Extract 与 Make；enum 通过真实 tag 分支选择并重构相同 variant。所有增长
和扫描预付当前请求余额，失败不产生可执行产物。

独立 consumer 从 immutable source-call 事实和实际 SSA/CFG 重走对应 typed copy，
不调用 producer helper，也不把 sidecar 相同当证明。逐层检查确切 field/array index、
variant tag、顺序、输出 schema 和原 endpoint；任何改值、跳字段、错端点或额外
local store 都拒绝。

运行时普通 pure Copy 由 Analyze 与 Verify 各自独立分类，要求完整嵌套类型无
Address/借用/root 权限，且真实 opcode 的输入输出与布局精确相符；不是仅向
stored profile 增白名单。保留原 B/C 真实复合源码，不以 scalar 化替代消费者。

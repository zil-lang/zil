# G4.4.5.4 B recursive context relocation

Root 授权将当前只允许完全相同 field CtTy 的 Source-authenticated record copy
扩为有限 ordinary pure value 的成对递归重构。该动作保留两个真实 schema 和
完整 scope/actual 参数目录，不使两个 schema 全局相等，也不赋予新权限。

Producer 对 scalar、tuple、array、UserPure record/enum 逐层核真实形状、nominal
身份、完整参数图及最终原来源 lifetime endpoint。需要变更 schema 的字段发出
真实 Extract 与 Make；enum 通过真实 tag 分支选择并重构相同 variant。所有增长
和扫描预付当前请求余额，失败不产生可执行产物。

独立 consumer 从 immutable source-call 事实和实际 SSA/CFG 重走对应 typed copy，
不调用 producer helper，也不把 sidecar 相同当证明。逐层检查确切 field/array index、
variant tag、顺序、输出 schema 和原 endpoint；任何改值、跳字段、错端点或额外
local store 都拒绝。

运行时普通 pure Copy 由 Analyze 与 Verify 各自独立分类，要求完整嵌套类型无
Address/借用/root 权限，且真实 opcode 的输入输出与布局精确相符；不是仅向
stored profile 增白名单。保留原 B/C 真实复合源码，不以 scalar 化替代消费者。

经 root/g44 协调扩展必要写集：compiler_types 的 Enum checking_generics 分支、
compiler_symbolic_nominal 的真实 struct/enum 抽象目录、compiler_expr enum expected
桥、compiler.rs active scratch schema 类型、runtime_context 仅 enum 类型重实体化 arm。
Record 与 Enum 共用原声明+完整 Type/Const/Life 顺序身份，所有 variant 均真实展开，
不发布抽象 scratch schema，增长前支付实际 backing。原 Definition/实例检查保留。

### Nested nominal field source contract (root approved)

`SourceLifeBinding.parent: Option<SourceSchemaId>` is a private locator only;
`SourceSchemaId::{Record,Enum}` distinguishes actual schema tables. Producer
sets it only while traversing the selected immutable nominal's actual fields.
The child site remains the canonical frozen Type SourceSite. The complete
parent schema's ordered Lifetime arguments map through that same graph's
unique `(owner,class)` ambient entries; a strict nominal alias table forbids
caller-name fallback. No new function lifetime scope is invented.

The independent source consumer authenticates the parent from its original
declaration and complete actual vector, proves the child site belongs to a
real field of that item, and re-walks the original field Type to compare the
whole child graph/endpoints. It rejects wrong parent/field/item, missing or
duplicate events, cycles, and depth/resource overflow. `parent=None` retains
the existing function-site authentication. Private locators do not change Wire.

Write partition: this task owns `compiler_data::closed_nominal_context`, the
private schema locator/binding fields and producer state; source-auth owns
`invocation_context_source_types` and independent field replay. g44 owns
`compiler_scoped_metadata` graph extraction, `metadata_copy` graph-only arm,
and strict `metadata_life_bindings`/`ambient_actual` lookup. No owner replaces
the other's source proof or removes a guard to admit this source.

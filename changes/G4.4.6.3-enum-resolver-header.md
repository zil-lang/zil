# Qualified Enum resolver header

An authenticated stored Enum resolves to `BorrowedStorage(Enum)`. The resolved Core enum declaration must take its physical variant payloads from that complete result while preserving the qualified instance separately. Moving the payload vector avoids a second type clone and keeps the ordinary Enum path unchanged. Inference and closure constructor prepasses likewise select variants only from the physical projection while retaining the full qualified Type for their existing validation and binding. A malformed resolver result is a Types diagnostic rather than a compiler panic.

Array address/index reads admit only immutable arrays whose entire actual element graph passes the independent pure-inline shape walk; the local type clone is prepaid before growth. Enum constructor lookup borrows the authenticated namespace type through `MakeVariant`, where the qualified SSA/result copies are prepaid. Read-only `known_type` lookahead skips qualified constructor guesses and leaves real expression typing to the metered constructor path.

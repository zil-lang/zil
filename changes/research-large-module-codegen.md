# 大源码模块的 O0 代码生成分区

基线12fc97bde（生产9fe）。扩展分布诊断发现每个source file被无条件union为一个CGU，单文件4096/8192函数即使请求8个单元也只能产生1个单元。Rust把代码生成工作划为多个稳定单元，而源码文件不是必需的链接不可分边界。

候选：仅O0且显式多CGU时，以每文件256个非foreign函数的固定连续块替代整文件union。固定块宽与正文内容无关；非foreign LIR函数集合与顺序均不变的局部编辑不移动其他块；正文新增闭包或泛型实例仍可能生成函数并保守使后续块失效。所有local linkage引用、静态全局地址和入口wrapper仍按真实引用union，跨单元声明按当前结构化引用提取。小文件、count1及O2分区保持既有策略。不给O2拆分，以免丢失模块内内联改变优化质量；其差距单独报告，不通过降低优化掩盖。

新增生产写集：crates/zil-backend-llvm/src/build.rs（调用内部策略）、machine_cgu.rs（既有范围）；测试object_cache212.rs。不改语言接受性、预算、schema、公共API或产品门。源码成功/最近反例包含跨块调用、私有编辑命中、插入/删除、取地址、闭包/资源及失败清理；机器local-linkage合并控制保留。完整分布O0/O2/Rust与原候选消融，内存和不利点一并保留。

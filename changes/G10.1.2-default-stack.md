# G10.1.2 默认栈修复

修复共同8477e08c1上的两个真实默认2MiB工作线程崩溃，不修改语义、源深度、预算、机器ABI或产品门。

Types调用分派已有外借`'a`签名表，普通函数/方法使用该引用，消除递归参数检查时对完整Signature的重复本地快照。只有确需改写的普通模板在原有预付费用之后克隆其工作副本；元数据、实例身份、参数准备顺序和全部独立核验保留。

泛型定义期检查器的单个expr_inner曾为Call/Record/Closure等所有分支预留约111KB debug栈帧，长Binary链每层都占用该帧。将原Binary操作逻辑逐字搬到单独小函数，公共tick/enum/constant前导及别名开始/结束仍在原位置；非Binary分支进入另一个独立函数。原操作遍历与费用次序不变，不在编译器内另开大栈线程或引入堆盒。

最近正例就是原nested_calls与impl126的原字节；最近反例保留nested深度126在Parse ResourceLimit、原精确N/N−1、helper消费重用/循环与三核预算拒绝，不以降低深度或放宽输入换取通过。

## 已选组合基线

常量摘要候选在原严格叶调用规划之后，使用不可变的虚拟替换和有界反向消费者工作表，计算纯零参数标量函数的摘要。无效果、地址、间接调用、内存、Phi、除余移位和未定义值等证明条件不满足时保留原行为；独立优化额度耗尽也不改变语言接受性。联合变换仍先核验完整未修改机器模型，保留全部 canonical 定义。只在显式 `O2 && incremental_o2` 路径使用。

验证专用 API 保留全部符号、类型、签名、CFG、操作形状、SSA、Phi 多重集和支配检查及其错误顺序。当所有块可达时，这些检查以支配深度和块内位置的严格次序证明依赖图无环，省掉随即丢弃的调度结果；存在任意不可达块时仍运行原 Kahn 路径。原生构建仍收集完整调度。该改变适用于所有验证专用调用者，包括 O0 和缓存命中的当前预检，不能误记为只在 incremental O2 生效。

## 独立筛选候选

图分区在现有源分组、局部引用、入口包装耦合的 DSU 整组之后规划。当前机器直接调用图及保守源反向影响只参与启发式成本；它们不授权缓存命中、跳过当前 Verify 或减少完整调用闭包导入。局部维护引用计数、反向消费者和可回滚变更，七项约束、确定性顺序和完整原布局回退保持。新版本在试探之前以目标 owned cost 加移动组成本作为 body load 下界，只在严格大于当前最大负载时排除必败移动；算术失败完整回退。减少优化计费可能让旧版本耗尽预算的输入完成新规划，因此只在预算充足时声称与原搜索结果相同。

稳定身份候选只在显式闭合、Linux LLVM API、增量 O2 等完整门内接收当前 filesystem 路径和 AST 来源。当前 Analyze/Verify 后重新核对声明、密集 ID、签名及跨度的完整映射；身份由规范根路径、模块路径、种类和原声明名构成，不能用已含密集编号的后端名称代替。实际机器符号、所有引用、分区和顶层顺序一并稳定化，键仍散列实际模型。无来源、生成定义、地址、内存、全局对象、间接调用或源函数间剩余引用等均完整回退。稳定身份不等于函数级语义缓存。

闭合删除候选是上述接受域上的另一版本。在完整原机器预检之后，依据该域已证明的唯一可达集合，仅保留 source entry、native main 及实际引用的声明，然后再重命名、序列化和构建一个真实单元。当前前端、CT 效果、Types、Analyze、Verify 和默认导出合同保持。任意原模型的 LLVM 专属非法 intrinsic 不属于此结构预检的证明范围；实际源路径只能产生当前已核 LIR。稳定身份与删除政策的收益分别比较，不能以一单元结果证明多单元分区收益。

常量除数 lowering 候选必须先完成 LIR 与当前独立 VerifiedModule 的精确绑定。它只接受直接、类型匹配的整数常量：有符号除数排除零及负一，无符号排除零。仅省略必假的陷阱条件和合成分支，原操作、效果顺序、零除和 MIN/-1、MIN%-1 行为保持。每函数 16384 个候选及一百万块/指令扫描的优化上限失败时完整发射原检查；不做别名或值传播。该政策只接显式增量 O2，原公共 emit 路径保留原行为。

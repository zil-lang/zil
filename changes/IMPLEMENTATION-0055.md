# 0055：真实 TypedIR 图切割影子研究

## 提案与实际写集

050已证明人工有限关系可以精确消元，但没有真实前端抽取和生产热点收益。055新增独立 Rust 研究 workspace，经生产 Parse/Expand/Types 读入真实源码，先验证生产接受，再抽取资源/闭包/控制事件；候选消去描述活跃性传递为恒等的内部点。写集只含055研究工具、文档、源配方与证据，不改生产核、根Cargo或预算语义。

## 保证分别列出

1. Desc/借入闭包每个原点的完整 may-liveness 与独立 TypedIR/BTreeSet oracle 相等。
2. 同一有标签事件图保留资源身份、条件 ValueId、两分支、tag、清理顺序、回边及所有观察出口；独立 raw-IR 审计防止抽取器与候选同时漏事实。
3. 一般联合资源状态求解本轮未实现，050人工精确关系仍另列；前两项不得冒充第三项。

关键反例交换不同资源对应的 true/false 分支，完整 may-liveness仍相等，但事件图不同，检查必须拒绝。其它测试覆盖捕获用途遗漏、异函数身份复用、漏臂/出口、清理顺序、恢复摘要/活跃位篡改、残缺行、填边回退和原生产拒绝不被影子答案覆盖。

## 预先冻结的比较

19份实际源码包括7份现有资源闭包样例，以及无资源小例、长标量段、分支、循环、多出口、双资源关联及宽捕获4/16/64的生成源码。对照为同位集的逐点 flat、逆序 cut、原块 block；生产全Analyze/Verify仅提供成本背景。6轮×7次交错采样，在集成方协调其它构建停止后完成；包含前端、抽取、规划、求解/复原、raw审计、完整参照核对和销毁。

完整慢oracle参照创建在冻结阶段，不计入样本。结果不会声称测到完整生产核替换收益，更不会借050的模型倍率表示ZIL或Rust编译倍率。主计时身份固定draft10/schema7，schema8错误出口另作功能补充。

## 最终功能与实测状态

最终13项限定研究测试和研究workspace的clippy通过；19份源的73个非外部函数已全部通过生产验证、独立抽取审计、三法逐事实/事件关系核对。正式冻结119源码hash、38个完整TypedIR/预期关系成员，以3d4375a实际源码/驱动身份重新freeze并先提交输入，再完成3192样本。非作者在独立检出复跑13测试，核对全部hash、样本键及684组统计；完整结果见docs/research/055/RESULTS.md。

结论为当前恒等点切割候选暂不入核：19/19案例配对cut/block完整成本中位比大于1（1.007–1.147），波动明显，不把小差异逐例称统计显著；straight512计划+求解比为2.343。保留真实输入/完整检查资产和关联反例。宽捕获64的载体活跃槽在切口仅1，但同现图宽度上界64，不能由窄CFG或一个闭包载体推导一般联合状态也窄。

## 四项既定目标的影响

- 接受性：生产接受集合不变；三份已有借入/混合闭包非法源码仍由生产Verify拒绝。
- 安全性：不制造Verified，不改变生产验证边界；新增的只是带独立裁判的研究工具。
- 性能：正式计时完成；块算法、密图、小例和全部阶段均报告，未建立相对块算法的稳定完整成本收益，故不提出生产替换。
- 可用性：单命令可重做功能冻结和有明确身份的计时，所有源、关系与哈希可追溯；生产CLI无新入口。

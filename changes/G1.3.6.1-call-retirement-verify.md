# Cross-call resource retirement: independent Verify proposal

The actual user-Drop Source `old = packet.owner; reset(&mut packet); return old.code` passes Verify although reset commits a new resource into owner. Inlining the same operation in the caller already rejects a live old description. The actual Content replacement fixed point retains parameter/path may-effects, but the final private replacement-target ledger only exports targets needed for Store calls; resource invocation only consumes Store element targets. Ordinary caller field retirement is lost at that boundary.

Retain all actual nonlocal Commit target recipes in the verifier-owned ledger, including conditional and nested-call propagation. At invocation substitute actual arguments/captures with this kernel's actual address reconstruction, map the selected owner position to resource roots, and apply independent active-description retirement checks. Do not derive retirement from mutable signatures, ordinary write summaries, Copy writes, names, candidate Holds or Analyze permissions. Calls with no possible Commit have no retirement effect. Possible successful Commit followed by a recoverable error remains conservatively may-retire; this fix adds no exit-sensitive must fact.

Only safety rejection changes. Preserve debts, shell cleanup age, Content may-origin union and fresh flags; no new creation permission or whole formal/helper Package/Enum endpoint. Nonlocal alias uncertainty cannot prove old descriptors disjoint; retain conservative checks where the existing private description representation lacks a finer source distinction. New vector/path cloning, substitutions, searches and active-descriptor scans are prepaid. Public IR/Wire/schema/ABI and default budgets remain unchanged.

Use real Source before raw neighbors; never execute the accepted unsafe probe as native code. Readonly &mut and scalar-neighbor helpers, other actual roots/fields, no-Commit/Abort-only and conditional/nested Direct cases distinguish retirement from mutation. Exact final commands, initial failures and measured boundaries will be compactly recorded; raw logs remain local. Non-author review/common acceptance belong to root.

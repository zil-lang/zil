## Actual missing information

`generic_stored_nominal::storage_header` has real `LexicalLife` occurrences;
`stored_types::Instance.classes` retains the enclosing-class map privately.
The Core boundary keeps only each Type's local equality partition. Current
`CoreExprKind::Closure` has no context; Types `closures::State::finish` writes
`ClosureDefinition.storage_life: None`. Inferring an outer s from a local
class0, matching Type bytes, names, Span or ClosureId would silently equate
unrelated contexts. Existing guards must remain until a genuine map reaches
its complete consumers.

## Proposed untrusted Core table

Add a module-owned table keyed by `(actual CoreFunction.id, CoreExpr.id)` and
referenced only by the actual closure node. These NodeIds are relocation keys,
not semantic owner identity. Reject duplicate, absent, nonclosure, inaccessible
or non-enclosing entries. A row contains:

- `owner`: actual module/function reference plus stable original declaration
  identity from SourceIndex/Origins (package, logical module, declaration/member,
  generation path), actual binder-site ancestry and full original parameter
  kinds in declaration order. Reuse the semantic identity rules of
  `LifeDeclarationIdentity`; do not derive a declaration from a printed name.
- `instance`: Definition or the complete ordered Type/Const/Lifetime actual
  vector. A Lifetime actual references the actual enclosing owner plus its
  **full generic ordinal**, including intervening Type/Const parameters. Use
  the existing CT5 owner/instance meaning, without treating a CT raw scope
  index or structural digest as authenticated runtime identity.
- `fixed_sources`: dense closure Fixed class -> `(owner, full ordinal)`;
  unique, kind-correct and scoped. Nested closures explicitly compose through
  the real parent entry instead of restarting a numeric Fixed0 namespace.
- `relation`: one complete StorageLifeContract for Parameter/Capture/Result
  class and access rows. Invocation binders stay local to this callable.
- `capture_sources`: source binding selections for each proposed Capture row.
  Select an actual enclosing parameter ordinal or Binding statement NodeId
  (plus typed projections), not a name or Span. Types reconciles these with
  its actual inferred minimal capture slots and modes; source-order indices
  alone cannot predict that final layout. Tuples/pattern bindings need actual
  bound-position selectors, or reject until supported.

First implementable profile: every nonempty Fixed class is grounded in an
actual captured class/address and its valid enclosing mapping. A merely open
annotation with no retained grounding is still unsupported. This closes the
assigned **captured** outer Fixed path without inventing metadata-only roots.
Supporting context retained without any physical capture requires an explicit
creation-binding transport through Typed/Wire; it cannot be encoded solely
by the existing closure-wide StorageLifeContract.

## Production and independent consumers

Expand reads the original lexical binder ledger before label erasure and
emits these raw rows while processing the real node, retaining original full
ordinals before any lifetime-only projection. Specialization and CT generation
must remap actual owners/instances and node references together. Closed
Invocation-only annotations do not acquire an enclosing table accidentally.

Types checks node ownership/ancestry, full kind/ordinal/actual closure, resolves
capture selections against actual inferred captures, and builds complete
ClosureDefinition.storage_life plus the entry relation. It never copies an
actual helper role into the global closure definition. Context is kept in the
private Pending state through both inference passes and actual construction.
Unsupported captures/results stay rejected independently.

Analyze and Verify separately validate complete capture/signature relations,
actual entry identity and capture modes, and derive actual capture class facts
from each MakeClosure operand. Each actual environment value/local carries its
retained Fixed equations. ReadCapture/WriteCapture and moves preserve those
facts. For calls, **Fixed selects the same environment facts; only Invocation
gets fresh variables**. The same ClosureId in two runtime positions does not
merge their facts. Each helper role has its own actual receiver provenance and
is checked against those facts and the real body. Capture targets, parent loans,
initialization, mode and cleanup are separate from semantic-class equations.
No kernel imports Types or the other kernel's proof functions.

Existing runtime Capture rows can ground this first profile if all Fixed facts
come from actual captured values. Before publishing any wider context-retention
profile, root must supply a raw Typed/Wire creation-binding record; a definition
reference alone cannot prove an environment's per-instance Fixed substitution.
Lower/LLVM erase classes only after exact verified-module/LIR rebinding; actual
inline capture representation and mode-specific calls remain unchanged.

## Budgets, keys and nearest controls

Prepay row/selector/owner text and path bytes, complete actual Type/Const trees,
parameter-kind vectors, ancestry lookups, capture reconciliation, copied storage
and relation walks from each current request before allocation or cloning.
Persistent environment fact allocation, propagation, substitution and equation
work debit the same live kernel ledger. Bound all counts before domain vectors,
check depth/cycles and retain N/N-1/fresh/warm behavior. Full semantic context
participates in source/Core/interface/cache identities; NodeId/Span/table
relocation does not change semantic identity, and defaults do not increase.

Nearest positive: `apply<life s>` constructs Tag<'s>, captures that actual value,
and calls a closure with an explicitly Tag<'s>-qualified parameter through an
actual helper. Repeated legitimate calls retain s. Negatives: pass Tag<'t> from
a distinct declared t; change a capture map to an unrelated same-shaped local;
reuse owner/ordinal0 from another definition; select an intervening Type/Const
ordinal as Lifetime; omit/duplicate/swap a row; forge a non-enclosing owner;
copy a context across different complete actual vectors; misbind a nested
closure parent; mutate raw/Wire Capture or role relations while recomputing
candidate fingerprints. Every positive must reach both kernels and native;
negative checks must bind the intended stage and reason. A scoped fixed-source
row, class equality or matching structural hash grants no loan or access.

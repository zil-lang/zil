# 131：有限参数效果图的删除/增量边界

101已将冻结扫描器的有限布尔参数写关系化为种子可达性；131不重复声称该转化是新发现。研究新问题：编辑移除写种子或依赖边时，怎样只重算受影响区域，同时避免递归环互相支持旧事实。

候选为old/new边并图上的前向脏锥，内部清空并从新直接种子及未变化外部入口重建最小不动点。原理与删除/重推导类维护相关，不声称普遍优于DRed/B/F、一般Datalog或图分解突破。先实现独立研究Rust引擎、穷举/随机oracle、精确额度回滚和增长反例，再绑定真实源码闭包接收者观察。生产Types/Analyze/Verify/schema/预算不改；AST提取、编辑身份稳定性、查询摘要与全管线成本尚未计入时，不准生产替换或宣称编译加速。

最近反例是A↔B仅由种子A可达，删除A种子后两者必须变false，不能保留内部旧真值当外部输入。还有多路径仍保活、批量先删后加、同边末写覆盖、无操作修改、预算N−1与非法节点后的完整状态不变。

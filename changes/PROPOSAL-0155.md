# 155 Mutable Managed local replacement

Normative source: _zil_design.md §§7–9. Previously Unsupported for local Managed assignment. Proposed accepted form evaluates and stages RHS before conditional old cleanup, then consumes preparation into the same lexical slot. An RHS propagated error cleans actual temporaries and preserves old lifetime until its normal error-path cleanup. Existing independent Verify must reject live old descriptors/views crossing replacement. No hidden allocation, RC, generation or new opcode. Owned FnMut capture uses the same existing Package capture protocol. Non-move captures of a newly replaceable slot and nested owning closure inference remain outside this slice.

## Revision before production candidate
Direct DropManaged violates reverse-successful-initialization checks when the RHS is staged. Instead, mutable Managed bindings lower to a hygienic single-field owning Package, initialized at the binding's original lexical position. Replacements retain the slot and use existing prepare / DropPackageField / TakeLocal / StorePackageField transitions. Capturing the mutable binding captures this existing owning Package. No verifier, IR opcode or schema change. This adopts the already-specified Package slot lifetime for the newly accepted mutable assignment; old borrowed views still cannot cross replacement. The invariant is lexical *slot* cleanup order, not reordering unrelated owners on each payload change. Shadowing and source annotations remain checked. Prototype must pass existing cleanup and resource mutation tests before any engineering composition.

## Compatibility refinement and controls
A bounded lexical prepass promotes only mutable bindings with an actual assignment to that binding. A same-spelling shadow does not promote its outer binding. Mutable resources without rebinding preserve their previous IR and borrowed captures. The first broad promotion prototype was corrected before composition. The initial nested owning closure positive was rejected by existing C1 inference even with annotations; a gap test now records that exact limitation, while old-descriptor-last-use is tested separately. Conditional DropPackageField is idempotent: duplicating it is not a valid hostile double-free mutation; omission and invalid field index are independently rejected in raw and wire verification.

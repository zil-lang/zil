# 每次产物检查内复用共同父目录的解析

基线5e0613cc4（生产a4bec09）。新增前端复用后的完整窗口中，512模块暖check约21.6ms，Parse事件之前及重放区间仍约10.6ms；源码阅读发现产物计划为每个同目录source重复调用destination，缺失虚拟文件的identity又重新逐组件metadata/canonicalize相同父目录。此归因是代码及阶段间隔证据，不冒称排他CPU剖面。

候选保留原destination算法，增加仅保留一个成功父目录的局部解析器。键为本次调用计算的绝对词法parent（保留..语义），值为原算法解析得到的parent；最终文件名仍是目录项，不能跟随输出symlink决定发布位置。错误不缓存。缓存分别局限于一次计划构造或一次validate调用，绝不跨observer边界、请求或后续产物检查。

每个文件仍调用当前metadata；存在文件的canonicalize与inode、缺失文件的dangling symlink检查、所有源/输出冲突与发布前验证均保留。没有把物理身份、文件存在性或验证结果跨请求缓存。共同父目录下连续多个文件只复用同一检查批次中成功得到的目录解析；外部并发修改不增加任何原本没有的原子文件系统快照保证。

控制：同一序列cached与原uncached destination逐项Result比较，含..、符号目录别名、缺失目录、非目录、dangling及相对路径；同一ArtifactPlan的后续检查必须看到硬链接/最终symlink变化和父目录改成普通文件；保留当前源码及最终发布取消/回滚测试。完整限定测试、独审和整窗计量后决定是否保留，旧阶段3两窗保持原身份。

# Qualified Enum constructor work accounting

The original ordinary Enum namespace path retains its existing construction and budget. When authentic qualified Enum instances are present, Types pays for scanning each complete instance before comparing it with the actual resolved declaration, then pays before cloning the matched complete type into the constructor namespace. `MakeVariant` keeps the old owning branch's clone order and pays for its two qualified output Type clones before allocation. Full declaration, actual payload and expected Type equality remain unchanged.

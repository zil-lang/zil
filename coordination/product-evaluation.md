# 同语义产品评价

产品条件以 main 的 [`validation/product-gates.json`](https://github.com/zil-lang/zil/blob/main/validation/product-gates.json) 为准，goal 不另立宽松阈值。每轮分开记录安全、运行时间与内存、完整任务表达/维护、冷与增量编译，以及至少一项可重复净突破；明确已实现子集、设计义务、受限探针、未测和失败。有限语言验收不等于完整产品目标。

与 Rust 对照须固定同一业务、资源、错误、清理和并发合同；允许合理的安全封装、Cell/GhostCell、Arena 与索引。冻结源码、工具链、配置、输入和机器，计准备、验证、代码生成、链接、运行、峰值资源及失败/慢例。局部加速、缩小 ZIL 语义或只数语法字符不证明完整产品优势。结论绑定其有限负载与源码，不把不同窗口的比例相乘。

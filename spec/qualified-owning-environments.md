# Qualified owning environments

A moved `BorrowedStorage` Package capture transfers the complete physical
Package responsibility and its actual stored permissions together. The
qualification wrapper does not turn an owning capture into a borrowed-only
field. Its cleanup index covers its owned fields, while its capture source
relation covers every external address or description leaf. Neither relation
substitutes for the other.

The generated entry binds one exact Package capture to a view and ends that
view on every exit. The view aliases the original environment storage; it is
not a newly created activation owner. Field observations borrow the original
live field, and preserve its complete path and parent loans. Reading or copying
the whole owning wrapper with `ReadCapture` cannot replace this protocol.
Partial moves, field replacement, and cleanup retain the ordinary Product
responsibility checks, including initialized ancestors and exact field types.

A producer may propose the concrete environment's Fixed classes from its
actual creator signature and complete capture source relation. Each source
must select an actual parameter leaf. Equal nominal types do not supply class
relations or runtime targets. The factory result relates each free Fixed class
to a class already present on its inputs. Analyze and Verify independently
check the class equations and the actual source permissions.

A shared entry cannot mutate captured storage or hide an exclusive stored
address behind the qualification wrapper. Mutable entries publish the actual
terminal state of each external capture leaf. At invocation the caller
substitutes those sources through the current actual receiver instance, and
replaces its environment rows. Two values with one ClosureId remain distinct
instances. Existing pointer SSA values retain their earlier target and original
parent loans after a slot replacement; changing a slot does not rewrite those
values or grant permission to invalidate their targets.

Environment cleanup follows the owned responsibilities. A borrowed slot alone
does not make generated Package teardown dereference that target. Where the
actual owned cleanup can access external storage, that dependency remains live
through cleanup. Unknown or opaque cleanup cannot be treated as an empty read
set merely because its enclosing representation is owning.

All complete paths, source sets, class relations, terminal state rows and loan
copies consume the current request budget. A snapshot copies every actual
nonempty environment row, including empty keyed permissions, parents and its
creation completeness state. The empty private namespace uses its fixed
snapshot dispatch; a public Unknown source relation is never an empty proof.

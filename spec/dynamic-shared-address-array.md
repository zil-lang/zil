# Dynamic shared address Array selection

A dynamic read selects an element from an actual nonempty fixed Array of thin shared addresses to finite closed Copy storage. Ordinary Array values, existing qualified Record fields, and owning Package direct fields use this route. It adds no dynamic slot borrowing, replacement, extraction/refill, exclusive Array copying, Slice profile, or general Address Copy qualification.

Literal indexing keeps its exact physical ordinal path. A dynamic expression evaluates and snapshots its actual Array value once before evaluating its integer index once, then uses the existing `ExtractIndex` operation. Shared views and fields use a complete `ReadAddress` snapshot. This may copy the pointer Array; it is not an O(1) runtime claim.

Both kernels independently check the real nonzero length, shared thin element profile, integer operand and exact element result type before ordinary pure-Copy fallback. Every possible `Field(i)` must have an actual source. Final whole-snapshot checks use the current CFG state for each actual root and ordinal: one complete root cannot hide a missing or vacant candidate. Extraction checks shared access for each candidate and retains their actual target and loan union across index effects and intervening instructions. This initialization rule also applies to whole snapshots followed by literal indexing.

A private finite relation carries existing upper variable IDs through actual typed copies, local loads/stores, reborrows, Array ordinals and checked physical slot projections. Selection requires a nonempty domain for every actual element before union. Unknown producers do not supply a default upper. Array container borrows are distinct from element uppers, and `Element` metadata grants no physical address or source.

Local closed-Copy reads, local copies/reborrows and ordinary Direct scalar observers can consume references with different rigid uppers. Such observers have no environment, foreign declaration or rich relation, accept ordinary scalars or shared addresses to closed Copy storage, and return an ordinary scalar. Their complete bodies and all actual target/loan accesses remain independently checked. No lifetime meet or new grounded class is constructed.

Identity boundaries retain the existing declaration checks for every candidate. Qualified construction, stored replacement, rich call binding, Address/Array return and capture/retention use their real expected class ports. Stored replacement resolves the actual carrier and physical path to the declared slot binder. Existing bindings are collected before candidate identities are checked; persistent retention has an earlier checkpoint and a final recheck. Incompatible rigid candidates cannot be renamed into one declared class. Mixed-upper rich consumers, unclassified producers and more general lifetime relationships remain explicit boundaries.

The backend uses its actual-length unsigned bounds comparison before GEP/load for the six existing integer index types. Dynamic selection conservatively retains every candidate even when a caller passes zero or one; literal selection keeps its previous precision. Every new scan, lookup, path copy, domain merge and source/loan union is charged before work. Large owning-Package snapshots and their native ABI remain a separate boundary.

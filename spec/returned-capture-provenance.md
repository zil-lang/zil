# Returned environments and owned dynamic cleanup

`CallableReturnContract.capture_sources` is an untrusted relation from every external borrowed leaf of the returned environment to actual input positions. `None` is Unknown and cannot authorize a return or call. `Some([])` asserts the absence of external borrowed leaves and must be reconstructed independently from the complete environment and reachable factory CFG. A fresh environment allocation does not imply self-containment.

Each `StorageSourceBinding` has one exact `StoragePosition` in a capture and a canonical nonempty set of parameter source positions. Ordinary field/variant/error-arm projections describe actual typed paths. `ContractProjection::Capture(i)` selects a nested environment capture for contract substitution only; it is never a byte offset, GEP, permission or independent source. Every selected capture and actual leaf must exist and match its full physical type. Equal lifetime binders, equal layouts and identical closure types do not establish equal runtime instances or origins.

Types derives the relation after concrete environment inference. Analyze reconstructs it from its actual CFG; Verify independently reconstructs it from raw/Wire operations and actual callee bodies. A captured address of a factory's by-value parameter slot is local storage and cannot escape. A captured address value targeting external input storage retains the target, full projection and each actual parent loan. Forwarding and nested captures preserve this distinction. Call substitution transports those exact dependencies through the returned owner, every move, aggregate and later invocation. Moving or destroying the environment cannot erase a loan retained by a separately returned borrowed result. Factory input-write effects remain independently checked and are not replaced by this result-only relation.

`DynInterface.owning_cleanup` is a whole erased-owner cleanup upper bound, separate from every ordinary method cleanup. `None` is Unknown; an owning construction requires an explicit independently proved bound. Every concrete provider's actual synchronous teardown, including nested Store elements and user Drop, must fit the declared accessed positions and effects. Calls, errors and reentrancy cannot be declared absent when their concrete bodies are unknown. External retained accesses select actual `Result.RetainedPort(i)` positions; the concrete vtable maps them to actual Self leaves, preserving all external parent loans and upper bounds. Method dispatch does not grant ownership, transport capability or permission to destroy a live borrowed provider.

Runtime schema and Wire48 encode both new relations and their nested metadata. Prior envelopes reject. Identity domains include all fields and distinguish Unknown from finite empty. CT contract projections use their versioned typed codec. Metadata counts, complete paths, source sets and substitutions consume the current request budget before allocation, hashing or copying. A fingerprint or transported claim supplies no semantic authority.

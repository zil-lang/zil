# 142：ZUI 基础记录容器与拥有 FIFO 闭环

## 为什么、是什么

现有 ByteBuffer、借片、有限 Package 和拥有 FnMut 已能组合普通库；通用 Vec<T> 和普通 Managed 局部整体替换尚未实现。本切片不等待图性能准入，不复制安全核，也不通过删除 Unsupported 绕过清理顺序。

`examples/mainline/record_vector/records.zil` 是定宽 Copy 字节记录向量，不是通用 Vec<T>、本机结构重解释或资源元素容器。10 个公开接口为 count/reserve/at/set/push/insert/remove/swap_remove/pop/clear，另有内部有界 prepare。所有公开操作检查正宽度、字节对齐、索引与上限。长度和容量仍由受核 ByteBuffer 操作管理。

## 怎么做

预先完成范围与乘法溢出检查；增长采用受 byte_limit 限制的倍增容量，一次 reserve 成功后才搬移/初始化。稳定插入右移从后往前，删除左移从前往后；swap_remove 只搬最后一条记录。可变窗口结束之后才能 truncate。失败前不改变内容、长度或容量；byte_limit 约束逻辑长度和新分配请求，不强制收缩之前保留的较大容量。

`at` 返回借自 storage 的只读窗口；非法索引返回空片。旧窗口跨写、自插入、自 set 和局部拥有者借片逃逸仍由独立 Verify 拒绝。最终负例分别绑定 E-BORROW-CONFLICT（3 项）和 E-BORROW-ESCAPE（1 项），不能把入口类型错误算作这些反例通过。

`inbox.zil` 为额外的单线程、有界字节事件 FIFO：一次初始化分配、环形读写、满队列拒绝、不分配入队/出队、关闭后拒绝新事件、保留已有事件按序排空，并在关闭且空时替换为新空 ByteBuffer、立即释放旧字段。它是普通拥有 FnMut + Package 组合，不是异步调度器或携带资源的任务队列。命令 0..255 入队、-1 出队、-2 关闭、-3 计数、-4 保留容量；错误 -1 关闭、-2 满、-3 初始化失败、-4 空、-5 非法命令。环索引避免 head+count 的有符号溢出。

## 本轮实际执行证据

- 最终 impl142 测试 6/6（5 个正例各 O0/O2 原生执行，另一个测试包含四个 Verify 最近反例）。原有 10 个相关目标 68 项通过；加第一版 5 项共 73，随后最终六项重新执行。不能相加冒充 79 个独立功能。
- 独立 Python 不可变字节记录列表 oracle：80 组 × 160 操作，O0/O2 及两个 realloc/free 探针变体共 320 个原生进程、51,200 次操作；每步检查全部字节、长度、容量和结果，不只比 checksum。
- 48 个故障/无需分配运行：40 次真实分配失败，8 次武装但未需要分配；检查失败后的全部字节及长度/容量，并在结尾 allocated=frees、live=0。
- 精确增长 vs 倍增增长，4096/65536 条 12 字节记录，O0/O2 共 8 个原生运行；两侧逐字节核对。65536 条时 realloc 调用 65536 对 16，均最后释放。这不是运行时间、RSS 或 Rust 对照结论。
- FIFO 6 个探针原生运行：正常和武装第二次分配失败各 O0/O2，分别 20,488 条 FIFO 记录；加初始化失败 O0/O2。正常路径只一次分配，关闭排空后保留容量为零，最终 live=0；第二次分配从未发生。
- 限定 clippy `-p zil-driver --test impl142_record_vector -- -D warnings` 通过，Rust 新文件 rustfmt、Python 编译检查通过。

## 失败保留与边界

保留所有失败尝试：探针初稿包错 malloc 而实际运行时为 realloc；增长测试误用超出 u8 范围的检查转换；FIFO 测试忘记增加循环变量及漏传故障环境；Package 载体迁移漏写 give；初稿三个借用负例的 main 返回 i64，实际先因 E-ENTRY-SIGNATURE 拒绝，最终纠正入口并要求指定 Verify 代码。它们是本轮工具/测试或用法修正，不伪称为语言缺陷修复。

普通 Managed 局部替换仍需处理 RHS 临时载体、旧责任释放次序、别名身份和重填。只删除前端 Unsupported 会与逆初始化清理约束冲突，未这样做。未实现完整 String、通用/拥有元素 Vec、并发队列、跨线程取消、窗口/渲染后端或完整 ZUI 产品闭环。没有正式全量门或独立审核；候选不自行合入 main。

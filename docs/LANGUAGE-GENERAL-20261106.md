## 本批实现的关键约束

普通文本沿既有不可变切片表示；静态来源来自真实 `StaticUtf8` 指令和显式返回
合同，不能从“没有参数来源”推得。字符串拥有资源仍显式分配，字面量不增加
运行期分配或终止符，不归一化 Unicode，不把运行期文本自动引入 CT VM。

借入 `Option` 使用完整内建声明身份、真实 Type 实参及实际 Some 槽绑定；两核
分别验证。None 只表示实际无载荷，不凭空制造地址根。控制流精化只使用原完整
CFG 收敛后的事实，并且只重放一次；原本不可达代码的检查规则保持。源码 life
标注、方法降名和物理字段模式均不能代替实际来源与权限证明。

同语义 Rust 运行时间、RSS、编译时间和维护成本仍需独立实测。可表达性与安全
反例的增量不等于成本优势；完整语言安全、完整标准库、原生 Windows 和产品
四目标合取没有由本批有限实现自动完成。`validation/product-gates.json` 不变。

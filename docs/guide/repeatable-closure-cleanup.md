# 可重复闭包的完整环境清理

独立Verify要求可重复调用的闭包在每次普通返回时保持全部拥有捕获和直接Package字段完整；整体移动Package作为捕获时，也必须保证每个拥有字段均已初始化。闭包变量是否仍存活仍由原有外层责任标志检查。该合同不同于只调用一次、允许带着已移出字段返回的消费式闭包。

后端仅对已经通过当前验证的无借出捕获、由ByteBuffer及其直接Package载体构成的可重复环境使用静态清理：在外层调用者检查并交出环境责任后，不再逐个读取和分支判断必然存活的捕获字段。仍按原声明顺序清除相同标志，再执行相同的析构调用，包括空缓冲区的原清理；不改变布局、地址、内联属性或分配失败路径。闭包体内部暂时移出和补回字段的标志操作保持不变。

消费式闭包、借出捕获、嵌套拥有、拥有枚举和用户自定义资源清理继续使用原动态标志路径。本规则不扩大语言接受范围，也不因缓存中存在闭包类型而复用旧验证授权；原始输入、当前独立Verify与机器预检仍是前提。将来扩展类型范围时，必须重新核对构造、调用、消费和清理的完整责任闭环，不能仅根据调用种类删除动态状态。

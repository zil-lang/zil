## Concrete remaining findings

1. **Analyze Array captures can use Invocation classes.**
   `signature_life.rs:298-302` advances the new Array child row and calls
   `Cursor::binder` without the direct qualified branch's capture-to-Fixed
   restriction. `binder` itself accepts Invocation. In isolation,
   `capture_relation([], [Array<qualified child with one local class>], Unit, c)`
   accepts `c` with fixed count 0, invocation count 1 and a single
   `Capture(0)/Element/class(0) -> Invocation(0)` row. Verify rejects this via its
   global capture check in `visit`; Analyze must independently reject it too.
   This is a signature-kernel control-flow counterexample, not an executed
   end-to-end acceptance claim. Author/root notified.

2. **Additional relation visits remain outside the new debit selector.**
   `borrowed_fp.rs:194` and the header selector match only a top-level Array.
   The relation now unwraps an actual Address<Array> and performs both pure
   physical and class enumeration at Pointee/Element; this new work gets no
   corresponding new Array debit. Separately, Analyze
   `stored_flow::header:772` calls capture_relation with `d.captures` without the
   per-invocation capture reservation added to class_flow/helpers/definitions.
   Paying those other relation invocations does not pay this repeated one.
   Author/root notified.

3. **The owning-Enum fee repair adds an unreserved inventory scan.**
   The new `enums.rs:346` `.any` scans actual life instances and compares Enum
   names before deciding whether to run the qualified payload classifier.
   This restores the ordinary false-classifier fee, but the new scan itself is
   not prepaid there. The author reports replacing it with a flag set during
   the existing budgeted source-Type walk, including BorrowedStorage descent;
   that successor has not been included in this exact receipt.

4. **Preserved source result is repeatedly cloned without prepayment.**
   After the move into `return_type`, `generics.rs:1990` clones the complete
   source Enum result for every Return statement; `:1629` does so for an
   expression body. These sites formerly saw a shallow physical stored head.
   The new retained original can contain arbitrarily deep Type actual syntax
   within the configured depth bound. The creation-time `budget.ty` pays its
   initial capture, not every later clone. Statement/expr entry pays a fixed
   tick, and context checking occurs after the copy. The new source-hint path
   needs a full debit before each copy while preserving ordinary profile fees.
   Producer/root notified.

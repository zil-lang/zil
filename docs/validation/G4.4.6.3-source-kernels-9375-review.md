4. In both `9375` and `5f48e7e4b`, the added MakeAggregate and MakeVariant
   propagation loops still visit every field when the parent and children have
   zero class ports. `link_projection` then returns on empty child keys without
   charging, so an ordinary large Copy constructor adds an unmetered field-count

   reports adding an O(1) nonempty-parent-class gate around those new loops.
   That unfrozen report does not close this exact finding.

5. `link_projection` computes its reservation by folding every parent key and
   retained row before calling `spend`. This newly repeated per-child cost scan
   itself precedes the local debit; an exhausted budget still completes it.
   Unlike signature binding, this path has no preceding local signature-row
   reservation. The author was asked to identify a same-invocation outer debit
   or move the O(1)-known visit-count part before the folds, subtracting it from
   the later reservation to preserve totals. This is a prepayment-order finding;
   no additional asymptotic total-cost deficit is claimed.

6. **An omitted complete signature contract bypasses nested class rows.**
   Both `stored_flow::header` None-contract branches inspect only a direct
   qualified carrier or an Address to one. An actual
   `Array<qualified child>` or `Address<Array<qualified child>>` passes this
   branch without any storage_life relation. For a normal function without an
   environment, class-flow's None-assumptions branch creates no rigid header
   class variables, its final Return binding is skipped, and a call to a
   None-contract callee also skips the class relation. Thus deleting the entire
   contract evades the new Element-row completeness check despite the complete
   qualified child still being present in the Typed signature. This uses the
   actual Typed child, not an assumed Source recipe. Author/root notified to
   detect actual nested class positions in each independent None-header check,
   with a local paid traversal and an unchanged ordinary no-instance path. No
   end-to-end mutated-module execution was performed here.

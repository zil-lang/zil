## 已开放范围

声明和语句位置的 `#for` 接受有限半开整数范围、显式同型纯标量数组。数组元素为 Unit、bool、u8、u16、i32 或 i64；范围端点通过同一个普通 CT 数组查询推导一致的整数类型，左闭右开、升序发射，终点不大于起点时发射零项。大于 i32 的值可以由既有 i64 函数返回上下文提供。

端点和元素可以调用 219 已封闭的无条件普通纯标量函数及传递 helper。它们经过既有 CTIR 编译器、独立 CT verifier 与 VM，保留目标整数推导和陷阱。宿主只枚举已经由 VM 返回的有类型整数常量；没有用宿主解释器求用户表达式，也没有增加 CT 外部访问权限。

```zil
fn count() -> i32 { return 3 }

fn main() -> i32 {
    var total = 0
    #for (i in 0..count()) {
        let term = i * 3
        total += term
    }
    return total - 9
}
```

本片声明模板输出普通 `fn`。私有函数获得每轮独立的身份，可以在该轮生成的 public 函数中调用；public 名称保留，重复导出继续被普通名称规则拒绝。

```zil
#for (i in [3, 5]) {
    fn helper() -> i32 => i
    #if (i == 3) {
        pub fn first() -> i32 => helper()
    } else {
        pub fn second() -> i32 => helper()
    }
}
fn main() -> i32 => first() + second() - 8
```

生成 struct、enum、trait、impl、type alias 等其他声明种类仍为 Unsupported。`#emit`、Type/Syntax 生成、迭代驱动类型或泛型常量形状、条件 import、任意 CT 全局、反射以及新增 CT 权限没有随本片开放。泛型、类型标注与属性等仍由普通前端的既有能力裁决，不能据此声称完整 §16。

## 卫生、作用域与阶段

每轮迭代绑定只在模板内可见，以 VM 返回的常量替换普通表达式位置。替换在实际遍历并完成内层选择时进行，所以 `#if` 选中支声明的同名局部、运行期循环模式、闭包形参和内层迭代会正常遮蔽；运行期同名值不能倒流为 CT 输入。record shorthand 保持字段名，仅替换其对应值。

选中后的私有函数和接收列表顶层局部通过源不可拼写、由模块与迭代次序决定的名字区分。嵌套普通块保留自己的词法作用域，同一轮的重复绑定仍是重复绑定；不会给每个重复声明任意新名字来让错误程序通过。生成私有名字不暴露给模板外的普通源码。

生成大括号不插入运行期作用域。语句按迭代顺序进入接收列表，return、defer、break/continue 和资源清理按实际发射的普通程序解释。三模块消费者专门让各轮 ByteBuffer 和 Marker 活到接收函数退出，检查其逆构造顺序清理；错误的“每轮额外作用域”无法匹配这个 oracle。

零轮模板仍须语法正确，但其未知名字、未知类型等语义不执行。ConfigReady 在本请求内不可变；本批生成的函数不是后续 CT 条件的候选，实际依赖获得 `E-CT-PHASE-DEPENDENCY`，不进行反复求值。跨模块查询保留 public/import 约束，轨迹记录实际 `rounds → configured_rounds`，以及原 module/span。

所有输出仍是未核源/Core，并完整经过普通 Types、Analyze、独立 Verify、Lower 与机器生成。真实资源的重复消费在 Analyze 拒绝，仍使用共享窗口时消费其所有者在独立 Verify 以 `E-BORROW-CONFLICT` 拒绝。没有新增安全事实、Wire 指令或放宽产品门。

## 配额和缓存

`#for`、嵌套 `#for`、`#if` 和后续普通 `#(...)` 共享请求的累计 CT 步数与节点余额。范围枚举先预付整个常量向量，模板克隆、节点追加、名字、词法记录、依赖和轨迹也在增长前计费。超大范围先得到 ResourceLimit，不能先分配大输出再检查。成功及失败均清理活动查询状态。

查询用真实原始展开分配器返回的下一个 NodeId 建立 wrapper，避免长数组的表达式节点与人工 wrapper 身份碰撞。结果沿既有私有展开缓存保存，暖请求仍扣实际用量、执行当前独立运行期 Verify。没有 `#for` 的既有 219 费用路径保持。

| 固定输入 | Core 最小 CT 步数 | 完整 Verify 最小 CT 步数 | 完整 Verify 最小节点数 |
|---|---:|---:|---:|
| 222：range + 每轮 `#if` + 后续普通 CT | 71 | 138 | 751 |
| 219 原固定输入 | 127 | 205 | 645 |

222 固定输入 SHA256 为 `30697085ee3d9f616423c37a2d6401904dd9da0de2a73e373708a17dc6cea7d4`。测试实际运行 N、N−1、失败后的新请求 N、暖 N，核对成功请求的一次独立 Verify；原始收据保留在包中。这些数值只描述冻结输入，不是默认限额或编译性能比较。

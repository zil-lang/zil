# 101 结果：参数事实图实现完成，生产准入 Inconclusive

## 裁决与交付边界

固定一次正式确认完成 4,940 个完整进程、19,760 次编译请求。按事前协议，
R 的裁决是 **Inconclusive**：95 个终点没有区间下界超过 1.01 的明确退化，
但 89 项区间上界仍超过 1.01，因此没有证明所有真实消费者的回退均不超过 1%。
13 项点估计超过 1%；它们完整列于下文，不能用逆链收益抵消。

**[0.6952662179, 0.7184453234]**。这是本片对冻结 BASE 的局部收益，
不等于全矩阵准入，也不是对 Rust 的产品优势。

生产和 crates 测试已在 `587c2f7a9d43cf96062b7fe78515c00788dbf8f1` 净回退至
BASE `24ca9583d8789cfdfe3ccdbfe3eeff614bf56429`；候选实现、证明、测试、全部
失败与测量历史保留。没有重采、扩样、删除终点、放宽 1% 或修改旧 097/100 裁决。
最终只交研究工具与证据。作者已经完成归档逐成员核验；root独立复算了全部

## 实现与有界正确性

候选 `c9863bd549e23477eee1b8374aff9084b48c16f8` 保留原 Scan 的前两次扫描和
早收敛返回；仍增长时才进入单独 outline 的参数事实图。关系提取把每个函数
当前有限的写摘要表示为直接种子和固定参数来源边的并，在有限事实集合上求
最小闭包。每个事实最多入队一次；这个界从关系提取结束后才成立，不省略图
构建、局部 Origin 循环、分配与预算成本。DB、Driver、Analyze、Verify 和默认
限额没有生产改动。[证明](PROOF.md)及[论文到实现的映射](PAPER-MAPPING.md)
说明了边界端口如何保持原参数身份，也明确没有继承物理论文的概率、范数或
时间分层结论。

作者最终限定控制为 10 个 Types 测试、6 个 Driver 源程序测试：包括 4,096 个
小图/写种子模型、3,680 次单步转移比较、全部 25 个 CoreExpr 与 15 个
CoreStatement 变体、参数交换、遮蔽、未知调用、字节操作、递归、无种子环、
预算 N/N−1、取消/失败恢复及 Fn/FnMut 拒绝。十九模式功能对拍共 304 请求、
48 次原生运行；BASE/R 各 142 个 guard 请求。计数版与无探针版共享 LLVM
48/48 逐字节相等；接口、诊断、query 观察、阶段产物与原生输出相同。
所有成功请求保持 Verify 运行一次、active query 为零。

reverse128 冷/修改请求的资源效果体访问由 **16,512 降至 384**；R 由前两次
扫描 256 次加一次关系提取 128 次组成，传播 128 个事实、127 条边。forward128
仍是 256 次访问；三个真实消费者的早收敛访问和 DB/Analyze/Verify 计数保持
原值。计数只说明工作结构，正式成本来自无探针的独立二进制。

## 零效果体工作与全流水线归因

最初 5 轮诊断、随后 960 进程 A/A、最后 660 进程 campaign A/A 均在正式 R
之前完成，原件没有混入 R 的确认。modules512 的效果体访问为零，但其请求
仍包含加载、展开、其他 Types 和 raw snapshot Debug/digest。诊断中的效果
求解仅约 190–410 纳秒，完整 API 约 55–57 毫秒，其中 digest 约 22.4 毫秒、
展开约 9.2 毫秒、加载/发现约 5.6 毫秒、整个 Types 约 3.8–4.0 毫秒。
因此“效果体为零”不等于“API 为零工作”，也不能证明旧 H 的 API 退化源于
图算法。独立107据此调查完整构造身份；它有自己的源码/功能/采样，不能用其
未来收益改判101。

A/A 的同 SHA 成本也有明显波动：大多数非 tiny 单元的 wall/child CPU 相关
约 0.969–0.9998，P0/P1无块读入且无 major fault。推迟父进程处理没有改善；
不能把变化只归因于调度等待、文件写入，更不能无证指定频率或虚拟机原因。
最后 C1 同 case campaign 的单块绝对 log 比差中位为 0.05076，低于 C0 的
0.07288，但仍未证明 1% 可辨识。依已冻结停止规则只执行本次固定 R 确认，
如实保留精度不足，未继续校准或追加确认样本。

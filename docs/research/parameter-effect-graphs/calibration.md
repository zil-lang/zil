# 101 独立 A/A 校准 001

本合同在任何本校准样本之前登记。它不改变旧097、100或diag001，候选R仍未
正式采样。diag001同SHA A/A的250对绝对log比差中位数为0.0581268632，50项
中41项的五对中位数偏离1%；仅据此不声称真实回退或95项非劣。

## 固定输入和边界

复用diag001的精确BASE无探针及BASE阶段探针binary，复制后核SHA。原十个
模式单元、cold/unchanged/private_edit/public_edit四请求全保留，输入和编辑
字节来自BASE24ca。A0和A1执行同一SHA、同一来源路径、相等长度的新输出路径。
每个进程仍真实创建session、读入、编译、独立Verify、Build调用clang、写完整
报告并销毁；没有批量改写被测请求。报告、输入和查询观察全部保留、逐次核对。

固定三个控制策略，每策略每模式单元8个四进程块，共960进程/3840请求：

- P0：无探针binary，块内A0-A1-A1-A0或A1-A0-A0-A1；每个进程后立即解析、
  核对和压缩其完整报告，尽量复现diag001父进程的工作边界。
- P1：同一个无探针binary和交错顺序；四个进程均退出后，才统一写runner
  日志、解析、核对和压缩报告。子进程自己的原始报告写入不改变。
- D0：阶段探针BASE binary，父进程采用P1边界；定位阶段时长波动及调用工作量。
  该组不用于生产时间或直接选择无探针成本的优劣。

8块中各有4个ABBA与BAAB。随机种子10101预先打乱每个策略/单元的顺序；
每轮用P0/P1/D0循环轮转起点，避免某策略总在同一时间段。具体顺序在prepare
写入schedule.json并冻结。不清页缓存，不改变CPU/ASLR/sysctl；仍固定CPU2，
root授予独占，记录开始结束UTC。没有任何按慢样、异常切换或CPU等待删行。

## 新观测

逐进程保留相同API wall、完整进程wall、全部报告与VmHWM。controller在唯一
子进程及其已等待后代执行前后读取RUSAGE_CHILDREN，记录user/system CPU、
自愿/非自愿切换、缺页和块IO差值。累计maxrss不是该子进程峰值，单独标为累计，
不作差冒充峰值。记录父进程后处理wall/CPU与每次launch开始时间。CPU与wall
边界略异且后代可能并行，wall减CPU只作归因线索，不等同于精确调度等待。

所有调用的计数与源/产物观察须一致。D0按嵌套关系报告阶段，不能相加重复计费。
同一块为每臂两次完整成本的算术平均，再取A1/A0；也保留每个单次及其顺序。
预先展示相邻1、2、4、8块汇总后的比值（每臂成本先求算术平均），全展示，不选
最有利聚合级别。这是测量稳定性诊断；8块没有正式95项同时非劣裁决。

## 决策用途

用独立A/A比较父进程后处理、调用顺序、启动/CPU与文件工作相关的扰动，再为
尚未采样的R正式确认预登记块设计与固定样本量。1%实用界、真实消费者、全部
API与进程终点、多重比较家族不变；不能用本校准抵消旧NoGo或直接准入R。
若稳定性仍不足，查明剩余来源并报告具体统计能力，不能在正式R样本后扩样或
择优改估计量。所有失败与原始960进程保持可复算。

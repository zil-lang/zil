# CP21：不存在 producer 的新查询跳过失效全表扫描 — NoGo

## 决定

**CP21 不合入生产。** 本轮完整 O0 build 窗口没有建立净收益：加权墙钟 B/A 为 **1.018946717（+1.895%）**，CPU B/A 为 **1.025763478（+2.576%）**。墙钟探索性配对区块 bootstrap 95% 区间为 **[0.965531057, 1.027143400]**，跨过 1。NoGo 表示当前完整成本证据不足以采用，不能把共享宿主上三个区块的点估计推广为永久、确定的退化。

保留独立候选、正确性测试、机制微测、全部完整 CLI 记录和负结果；生产保持原实现。这是历史 084 同类 shortcut 的新基线重测，不是新算法发现。旧 084 已判生产 NoGo 并恢复基线；历史记录见主树 `_zil_goal.md` 第 29 行、`docs/research/compile-performance/COMPILE6-PLAN.md` 的 CP21 分工，以及候选的 `evidence/research/compile-performance/CP21/author-result.json`。不将旧实验和本窗口合并统计。

## 冻结测量口径

本轮仅测 **完整 O0 build**，输出原生可执行文件，8 个请求 CGU、4 个 codegen jobs。两个 ZIL 版本对称启用源码候选缓存和对象缓存，**query cache 关闭**。每个请求都启动新的 CLI 进程；同一个四请求序列内部复用该臂的磁盘缓存，每个新序列使用独立工作目录。没有常驻 Session，没有把 Cargo no-op 作为完整编译，也没有把源码发现之后的内部秒数当作外部总时间。

请求顺序为 `cold_process → unchanged → private_edit → public_edit`。cold_process 表示新 CLI 进程和该序列的空编译器缓存，**不表示清空 OS 页缓存**。私有/公开编辑的源快照及原生输出 oracle 在计划中冻结；合成语料的编辑改变被调用函数体或签名及调用点，retained 的私有编辑采用被使用正文的等价改写，不能把所有编辑一概解释为运行输出必须改变。

五语料权重固定为 5%、15%、30%、30%、20%；四请求权重固定为 10%、35%、40%、15%。3 个配对区块，种子 `20261029`，区块内部 ABBA/BAAB，并随机排列语料。正式矩阵为 3 区块 × 5 语料 × 4 臂位置 × 4 请求 = **240 条请求**；预检是每语料 AB 各一次完整四请求序列，共 **40 条请求**。

聚合先在每个“区块×语料×请求×臂”内对两次观测取均值，再对三个区块取中位数，然后按预定权重累加 A、B 各自的绝对成本，最后求 B/A。CPU 为 wait4 的 user+system，包含由 CLI 回收的子进程；没有平均各格加速百分比，也没有把 wall 和 CPU 混在一起。

## 完整加权结果

比值小于 1 表示候选成本较低，大于 1 表示较高；变化率为 `(B/A−1)×100%`。

|---|---:|---:|---:|---:|

墙钟探索区间跨 1；本窗口没有另外报告 CPU 区间，不把墙钟区间套用到 CPU。该区间按完整配对区块重采样，只有三个区块且使用共享宿主，属于描述性证据，不是产品置信保证。

## 正确性、覆盖与非作者审核

- **240/240 正式请求和 40/40 预检请求通过**，没有超时、失败或缺失单元，没有移除不利样本。
- 正式 240 条记录对应 **768 次计时外原生输出核对**，全部通过；预检另有 128 次原生核对，未进入性能分数。不要将正式的 768 次误写成包括预检在内的总数。
- 所有正式请求 `verification_runs=1`；240 条 query-cache 状态均为 disabled，parse-cache 报告不存在。15 个“语料×源快照”单元的 A/B 可执行文件摘要一致。
- 候选的限定 db 验证由作者和非作者分别执行，均为 **11/11**，保留原 **9,600 个可达 DAG/指纹/驱逐 oracle**。这证明此次数据库小改动的限定正确性，不等于完整语言或产品安全证明。
- `/root/incremental_review` 对原始完整 CLI 证据作非作者审核，结论 **Pass**：重建冻结矩阵、核回二进制/helper hash、核对 8,056 项 fixture、raw report/native oracle，并独立复算 wall、CPU、正负分项及区间。它没有重新执行原计时进程。

自动生成的 `summary.json` 中 `independent_review: NotRun` 是生成时状态，原文件保持不变；后续独审由独立文件 `CP21-full-cli-review.json` 记录。**数据/算术审核 Pass 不等于性能采用 Pass**。本次采用决定仍为 NoGo，产品门保持 NotRun。

## 宿主与工具链限制

宿主记录为 Linux 6.18.55 x86_64、glibc 2.39、AMD EPYC 9V74；容器可见 affinity 为 CPU 0–8，CPU quota `800000 100000`、内存上限 8 GiB。被测进程实际固定在 **CPU 0、1**，并非拥有独占物理主机。4 个 codegen jobs 在这个 affinity 内调度，不能把此配置称成独占四核测试。只有三个区块，OS 页缓存未清除；冷请求和安装工具链读取也可能受共享宿主状态影响。

编译器本体由 Rust/Cargo **1.99.1** 构建，rustc commit `58cf8f9c35b355199727627d07ae34a4e2846d67`，其内置 LLVM **23.1.1**。两臂 ZIL 的实际 LLVM/Clang/LLD 为 **23.1.4**，官方 LLVM commit `7a941dfb2877a0b8cf30323fefa85ad019e0b0f5`。本地 `libLLVM-23.so` 是从该官方发行包的静态组件派生的共享库，不能称成官方原样共享库；两臂使用同一文件。

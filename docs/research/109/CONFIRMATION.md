# 109：普通字节映射与外部绑定的冻结五臂协议

本协议在任何 109 正式样本前登记。108 的单次完整结果维持 NoGo，原件和净回退
独立保留；109 使用新输出和新观测，不复用 104/108 的性能样本。实际源码形态
探针只提供实现动机，不提供本协议的速度成绩。

## 功能与身份准备

三个消费者、五臂、O0/O2，每组十个原输入及五个原失败索引，共 450 次普通/轨迹
执行（300 普通、150 轨迹）。失败索引保留 0、1、2、7、17；只以观察器实际失败
事件统计触发次数。输出、退出码、真实分配身份/顺序、末尾 live/unknown frees 与
独立 Python 模型逐项核对；每个 ZIL 构建必须有真实成功 report 与独立 Verify 一次。

父进程高水位的 12 个原控制另行执行；目标 RSS 使用已审小型 C exec/fork launcher
内的 wait4。Python 父进程 RSS 仍保留为原始元数据，不进入目标内存比较。

冻结原件包括 source/plain/observer 的各自身份、全部工具真实路径与 SHA、构建
命令和环境、26 源 provenance、普通/观察二进制、输入、预期、实际失败轨迹、
编译阶段、机器表示、完整顺序和控制器。所有新输出目录必须不存在。

109 的调用旁置记录直接绑定每次实际传入的 argv、stdin 规范路径/字节数/SHA、
完整白名单执行环境、cwd 和时限，普通执行、故障执行及 RSS outer 一致。记录
和输入/产物校验放在原 104 被测 spawn 区间之外；原参考计时器的字节与边界不改。
执行环境由固定白名单构造，不把未记录的 shell 环境或秘密变量带入目标。失败时
调用旁置记录和所有已完成原件保留，不能以输出偶然相同代替输入绑定。

## 一次正式时间系列

原三消费者的 64 KiB、4 MiB 为 runtime 六单元；空输入与单字节为 startup 六单元。
共十二单元，每单元两暖轮及三十保留轮，每轮五臂各运行一次，共 **1,920 个完整
目标进程**，含 120 暖观测、1,800 保留观测。root 授予 CPU 2 独占窗口后才能执行。
计时包括进程启动到完成 wait4；文件打开在时钟前，输出核对在时钟后，时限 120 秒。

五臂 Williams 基序索引为 `[0,1,4,2,3]`。分别对各项加 shift 0–4 后 mod 5，
再取每序列的逆序，得到十种序列。每种重复三次，使用 seed 109 的单一确定性 RNG
按单元依次 shuffle；每个单元完整三十轮提前封入 identity。暖轮单独使用固定臂序
及逆序。每个保留单元每臂每位置六次，每种有向相邻对在**轮内**六次。它不是
穷尽 120 种排列，也没有宣称 shuffle 后的跨轮边界平衡。

所有臂的每次观测、慢样、失败、顺序和原输出保留。任何身份、完整性、输出、退出
或时限失败使该次系列无效；不删样、换 seed、扩样、重采直到过线或事后挑臂。

## 统计与原门

逐单元报告五臂 median、p95，NS/BASE，以及 N/BASE、S/BASE、NS/N、NS/S 的同轮
配对比和 `(NS×BASE)/(N×S)` 交互比。比值中位数与两列中位数之比明确分开；描述性
每单元区间沿用原中位数次序统计，不宣称全族覆盖。

只读取原 `validation/product-gates.json` runtime 条件：Rust/NS 每例至少 0.9、
几何均值至少 0.95。runtime 六例、startup 六例、全部十二例分别判定，任何一组
失败即 NS NoGo。其它臂仅作因素解释，不能替代 NS 准入。全部 median/p95 不利结果
以及内存、功能、ELF 启动/IFUNC 时机边界单列，数值过线也仍须非作者审核。

## 独立内存系列与边界

同十二单元、每臂五次，共 **300 个目标进程**。每次重复按 repetition mod 5
循环左移臂序，使每臂每位置各一次。报告独立目标 RSS 原值、median/p95/范围；
这条系列不产生时间推论。完整 300 行同样按冻结顺序、唯一槽、调用及内层收据核验。

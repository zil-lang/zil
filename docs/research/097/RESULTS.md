A在反序链上的有限结构收益确实进入了完整请求：整进程A/B0配对比为0.711103，

## 为什么仍不准入

| 候选 | 触及原停止规则的单元 | 配对比 | 探索性95%区间 |
|---|---|---:|---|
| A | 真实拥有组件／Verify／unchanged API | 1.013751 | [1.005014,1.241019] |
| B | 真实拥有组件／Verify／private_edit API | 1.041603 | [1.008234,1.176842] |

| AB | 真实拥有组件／Build／cold API | 1.078969 | [1.012600,1.191662] |

[全部40单元](ALL-CELLS.md)同时展示32个API单元和8个完整进程单元，不只挑选
上表回退或上节收益。配对比是各轮候选/基线比值的中位数，不能用两个独立
耗时中位数相除替代。七对样本的bootstrap区间仅为预登记探索性判断，没有做
多重比较校正；不能将这些观测外推为候选在所有机器必然退化的因果定理。

旧实现在真实拥有组件只访问三次函数体，A也访问三次，而A仍构造队列、索引和
读取依赖记录。这说明该输入没有可供A消除的全轮重扫，为下一候选提供了明确
成本假设；本实验没有证明它是所有观测回退的唯一原因。B移除了重复闭包重验，
但在这些完整请求中未建立普遍、稳定的净优势。它的16行生产快路不因此自动准入。

本轮停止当前三候选的生产准入，保留实现历史、局部正结果和全部回退。一个有
依据的下一候选是：先沿旧扫描执行传播及稳定检查，只在仍未达到不动点时

及非作者审核；本轮没有实现或验证该方案，不能登记为已完成的收益。

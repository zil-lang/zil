# 050 实验合同 v1

**等级：独立有限模型。尚未与 ZIL 源码、TypedIR 或生产 Verify 连通。**

## 语义

模型有有限域变量、显式有限关系约束和有序观察变量集。答案是满足所有原始约束的完整赋值投影到观察集之后的完整关系，包含所有可达 normal/error 结果。投影相等是同合同；仅 SAT/UNSAT、边际相等或有一个可行赋值均不足。

候选先按确定性的 min-fill 顺序消去非观察变量。每个节点将全部含该变量的关系等值连接，随后投影除去该变量；每条输出保存一个被消去值以便逆序恢复赋值。最终连接所有剩余关系。单体基线使用相同精确关系连接原语，保留所有变量到最后才投影；它不是 Rust、生产 ZIL 或优化过的 SAT/BDD 求解器。两者都重建每条答案的赋值并重新检查全部原始约束。

独立慢 oracle 是回溯枚举：按固定变量顺序赋值，只在约束所需变量已全部赋值时检查原始表，从每条完整可行赋值直接收集观察元组。它不调用 min-fill、join/project、摘要或缓存。oracle 仅用于正确性锚点，不作为性能优胜基线。

边界必须包含所有跨区变量及身份、被观察的错误/清理效果和共同替换变量。把联合关系拆成边际、遗漏错误出口、只记录某 trait 目标可满足，会违反合同。模型源的正确性和有限化本身不由本算法证明。

## 表示、预算与失效

变量域为 1–4 个有限值，元组使用经溢出检查的混合进制 u64 编码；模型最多 32 个变量。每个关系最多 131072 行，每次求解最多 5000000 个关系行操作，每个中间 scope 最多 24 个变量；oracle 最多 5000000 个搜索节点。行计费覆盖连接输入/匹配输出和投影输入，并非 CPU 指令、图计划、输出检查或内存分配的完整计数；完整时间包含这些成本。限制结果独立于空关系，不当作正确拒绝或成功。所有限额对候选和单体基线一致。

计划只依赖域、原始关系 scope 和观察集。编辑后 scope/域/观察集不同即完全重建；表内容不同按依赖闭包重算，旧行直接被替换。上下文身份变化时全失效。身份字段用于保守实验失效，并不能替代 Rust 的宇宙、ParamEnv、外部区域约束、循环栈和递归预算语义。原型不接受递归 trait 求解。

## 冻结与计时

配方位于 tests/perf/impl050/cases.txt，模型生成器在 tools/research/050/fixtures.rs。生成器、所有研究源码和合同先提交，再 freeze；冻结程序运行独立 oracle 和两个精确实现，逐行核对完整关系，写规范模型/答案的 SHA-256 manifest。manifest 提交后才计时。无性能数字时允许修复正确性问题并建立新冻结身份，保留说明。

release 参数：rustc --edition=2024 -C opt-level=3 -C codegen-units=1 -C panic=abort -C debuginfo=0。独立 std-only 可执行文件，不建 workspace target。每例预热各一次；6 轮、每轮 7 个重复，轮次和样本序号交替候选/基线顺序，总计每方法每例 42 个样本。固定可用 CPU。小例可每样本运行相同固定 batch（配方指定），报告每次均值；不依据测量结果调整 batch。

每次计时从配方解析和模型构造开始，包含确定性 min-fill、所有关系连接/消元、最终组合、每个输出赋值重建、逐原始约束检查、与冻结完整输出逐行比较，以及本次分配的销毁。summary 与最终关系组合合计为 solve 阶段；候选的逆向赋值重建计入 check，单体基线在最后投影时生成完整赋值，计入 solve；阶段间不作相同工作的错误等价比较。OS 文件读取、进程启动和样本 JSON 输出在外；无 LLVM、源码类型检查、产品编译或并发。各阶段纳入总时间；原始 JSONL 保留全部采样，报告 median、p10/p90、IQR。表行数/编码字节只表示逻辑表成本，不伪称峰值 RSS。

## 必须出现的反例和负面对照

1. 两闭包捕获相同边际、不同联合关系，第二次调用的 normal/error 不同。
2. 创建有效不意味着可重复消费；未调用销毁和读取不消费分别建模。
3. 资源替换后旧静态身份仍被错误沿用；修改 Preserve 为 Consume 必须删除旧答案。
4. 共同 trait 替换变量不能分区独立存在化；特化候选表/上下文变化必须失效。
5. 关系摘要或恢复赋值被篡改时，原始约束检查拒绝；枚举 oracle 检测遗漏答案。
6. 链、二维带状、密图、宽观察边界和极小用例同时报告；表预算触发也报告，不截断后输出。

## 结论边界

消元与 min-fill 是已有方法，参考 Dechter 的 Bucket Elimination。Deng/Hani/Ma 提供的是保留切口身份并选择组合次序的研究启发；其分子范数、森林分层和收益计数不证明任意编译器图的效率。本轮不恢复旧世代/租约架构，不宣称新发明、Rust 性能优势、生产接入或通过产品门。

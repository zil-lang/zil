## 三个源码身份和证据等级

- BASE：工单基线 `b9cce1d1b7301850a3e65b81323caea8ea88593c`；构建前核对其
  Cargo 与 crates 和生产基线 `24ca9583d8789cfdfe3ccdbfe3eeff614bf56429` 无差异。
- ON：实现 `bbe8dafb570b613f8f5cf9be413882928a8bd511`，私有构造身份启用。
- OFF：同一 ON 提交，仅在冻结副本把 `construction.rs` 中唯一的
  `pub(super) const ENABLED: bool = true;` 改为 `false`。完整原 Debug digest
  路径保留；差异、来源和逐文件摘要均留证。

三个变体各有未注入的 plain 和单独注入的 count 构建。source 是原件/源码证明，
plain 是完整净成本与公共行为，count 只核实际工作和私有依赖账本。计时 executable
没有 count 探针，不读取环境变量选择身份算法。OFF 只做功能及工作量消融，
**OFF 耗时未测**，其被探针影响的任何时间都不用于性能准入。

工具、编译器、clang 的真实绝对路径和 SHA、构建/执行环境、所有输入、编辑清单、
源码副本、二进制及 controller 分别冻结。新输出目录必须不存在；失败前缀和日志
保留，不在原件上重跑。控制器最终修订绑定独立提交，不冒充重建编译器。

## 十九单元完整功能与消融

输入源于 101 的 `907b2c3cd03f1ad3c2738d8fe945b4ae7bf284f3` 固定矩阵：
tiny、modules512、forward128、reverse128；swap16、alias-cycle16、fanjoin16；
三个实际拥有/字节消费者各 Verify/Build；同三个消费者实际使用的私有函数体修改
及恢复各 Verify/Build，共十九模式单元。旧追加未使用函数的 private/public
编辑完整保留，同时单列六个真实私有体单元。输入数、预算和结构不扩大。

每组每单元四个完整请求：普通为 cold/unchanged/private_edit/public_edit；
实际消费者为 cold/unchanged/body_edit/body_restore。所有 plain/count 都生成
阶段产物并逐字比较，三个 plain 的原生输出按预填字面期望核对；每个成功请求
独立 Verify 一次，active queries 为零。全矩阵 456 请求和 72 次原生执行。
既有完整 guard 集在三组各执行，必须连分析预算边界一起相同，不删掉不便的负例。

count 同时记录原 digest 调用/Debug 字节数、新身份调用/编码字节/实际依赖数、
DB 读取/遍历、Types/Analyze/Verify 真工作量及成功发布数。BASE 和 OFF 的工作及
原始身份须逐项完全相等；ON 的其余工作量相等且旧 digest 为零。实际发布的完整
key、种类、依赖 key/kind/observed、身份和保留字段分别留证；独立 Python 编码
重算 ON 的 SHA，追溯每个依赖到前序实际发布记录，不把新身份写成 IR 内容 hash。

## 唯一正式耗时系列

只跑 ON/BASE 一次，复用 C1 两臂布局。CPU 2，root 协调独占。每模式连续完成
一个 BASE-ON-ON-BASE 暖块（两预热对）和 64 个保留 ABBA/BAAB 块，各 32 种
顺序，固定随机种子 107 先随机化模式顺序再随机化块顺序；完整顺序在采样前落盘。
总 4,940 进程 / 19,760 请求，含 76 暖进程 / 304 请求、4,864 保留进程 /
19,456 请求。完整 API 和完整进程含源读取、摘要、各阶段、Verify、报告与 session
销毁的既有边界不缩小；编辑写入在 API 计时外。Build 包含实际 clang。

每臂每块两次完整成本取算术平均，求 ON/BASE；64 个块比值的中位数为估计量。
76 个 API 加 19 个完整进程终点，共 95 项，使用二项次序统计 Bonferroni 名义
95% 同时区间：排序第 18 和 47 项。主要收益预先指定 **modules512 Verify 的
完整进程**，对应本片已发现的重复大快照摘要热点，不从事后最快单元挑选。

任一同时区间下界 > 1.01 为 NoGo；全部上界 ≤ 1.01 且主要收益上界 < 1 才
满足性能条件，并仍须非作者审核；其余 Inconclusive。任何功能、身份、Verify
或失败清理不一致也为 NoGo。所有 > 1% 点估计分别列出，不以平均热点收益抵消。
所有失败/慢样/暖块/顺序/原报告保留，不删样、不扩样、不第二次采集直到过线。

控制器逐进程追加 JSONL，最后生成等值 JSON；分析必须逐行对照冻结顺序、四个
scenario、身份、原报告、严格正整数时间及完整计数，核 finish/sample/journal 的
hash。正常和对抗式控制器验证不计入候选成本样本。

前后半漂移、首臂差异、所有父进程 VmHWM 都报告；VmHWM 不包含 clang 子进程
峰值，也不等于同时进程树内存。名义区间依赖稳定且足够独立的块，A/A 的残余噪声
是实际限制，不把名义覆盖写成已排除宿主波动。只作本宿主/固定输入的完整编译
实证，不推导普遍复杂度，不借 101 候选或 Rust 产品目标改判 107。

若未获生产准入，保留候选/负控制/功能/统计原件，生产及 crates 测试净回退；
由 root 集成处理，本作者不自行合入或自审。

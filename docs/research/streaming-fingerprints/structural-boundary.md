# 图切割的关键边界：输出、控制和可观察查询

本文件给出数学论证及有限模型检查的适用范围，不声称机器核验的普遍语言安全证明。
它不重复实现用户Boundary Lab 0.6的U/K/D，也不将已知图分解性质命名为新发明。

## 1. 已停止的强路线

设每个分量Xi有两个可达状态，且n个分量的全部组合均可达。若接口要求显式给出
所有完整元组，则输出有2^n行。因此，所有完成此接口的算法至少写出2^n个行记录；
逐字段输出还需相应的字段字节。图切割、符号表示、驻留及逆序恢复均可减少内部
重复计算，但不能在保持这个接口时消除结果本身。懒枚举也只把成本推迟到消费时。

这证伪的是“保持全部联合状态显式输出，也能无条件消除状态积的完整成本”，
**不是**“编译器的所有安全分析都必然指数”，也不是“图切割没有用途”。

076既有Dense direct测量中，独立核对与完整输出物化约占完整候选成本60.3%；
该数字仍属于原schema10实验，093没有重标或重采。它提示应先核对生产查询究竟
需要哪些观察，不能继续把内部搬移的小幅加速当作整体突破。

## 2. 可以成立的有限分解定理

对有限状态空间S1,...,Sn，初始集合I=I1×...×In，且各Ii非空。
每条全局转移是一个局部关系Ti的提升：只读/改第i坐标，其他坐标保持。
任意局部转移均可独立交错，不额外受跨分量PC、共享guard、配额或退出条件限制。
则全局可达集合恰等于各局部可达集合的积：

`Reach(I, union lifted(Ti)) = product Reach(Ii, Ti)`。

正向包含：按全局轨迹长度归纳；每步只使一个坐标沿本地关系移动，其余坐标
保持，所有可达元组的每个投影都属于对应局部可达集合。

反向包含：任取各局部可达状态及其有限见证轨迹，从选定初始元组开始，依次执行
每个分量的见证。因为局部转移没有跨分量前提，先前已完成的坐标不受影响。
于是任意局部可达状态组合都有全局轨迹。循环无需展开无穷轨迹；每个可达状态
都有有限见证。

若坏状态集合是各局部坏谓词的并，则“是否存在坏状态”可分别查询各分量，
不需要枚举其完整积。此查询接口与旧研究的“输出每点全部完整联合关系”不同，
不能把省掉输出称为同接口性能优胜。更一般的相关观察要携带其真实跨分量支持。

## 3. 三个必要反例

- 同一个guard生成`{(0,0),(1,1)}`。分别投影再相乘会添加`(0,1),(1,0)`，
  改变相关安全观察。共同条件和初始关系都属于支持，不只是读写字段。
- `x=1; abort; y=1`的控制次序不允许第二个写。仅按数据变量切成可任意交错
  的两块，会错误生成y=1的状态。程序计数器、可返回性及错误出口必须进入边界。
- 有外部种子指向a，a/b相互支持。删除唯一外部种子边后，单纯“仍有一个入边”
  的引用计数可留下自支持SCC；真实可达性必须从剩余根重算或使用有撤销证明的算法。

资源实际别名同样是跨分量支持。Boundary Lab原`order-apart-required`及
`nonreturn-double-destroy`在本轮原样重放，已经提供实际别名和危险prefix的近邻；
093不再写一个U/K/D模型制造重复证据。

## 4. 可执行检查与生产接入边界

`tools/research/093/structure.py`枚举两二态分量的全部16种局部关系及全部3种
非空初始集合组合，得到2304个系统。全局队列可达与独立局部Warshall闭包比较
完整集合，并核对36864个局部坏谓词组合。0–12维显式枚举确认输出计数。
这些有限检查检测实现错误；上面的论证承担任意有限分量定理的量词。

首次runner把迭代器读取两次，导致初始队列空，已修正并保留原源码与失败。
这属于模型runner缺陷，不是支持条件完整的积定理反例。

生产反馈以真实schema16源码、TypedIR、公共接口和诊断为准。
当前生产已经有写效果摘要和依赖调度，不能把Lab 0.5每调用点重复展开当作
生产弱基线。完整一般有序prefix/逐出口协议是否落地，单独按实际接口核对。
